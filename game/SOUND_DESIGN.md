# 纸上兵戈声音设计 · rc5

纸纤维、木制机构与墨印仪式：短、干、清楚的动作音，命中另用重击或纸屑反馈。使用 Godot 原生 16-bit PCM / 22,050 Hz，启动时缓存四个短样本；沿用 16 声道池、每类最短间隔、总线限幅、音量设置、后台停止和距离裁剪。

| 事件 | 声音 | 对应素材和动作 |
| --- | --- | --- |
| 弓射箭 | 230 Hz 下滑弦振，460 Hz 泛音与低通短风声 | 拉弦后释箭；区别于弩机 |
| 弩与连弩 | 机械短噪声扣机，570 Hz 木腔尾声 | 箭矢／弩矢实际发射 |
| 鼓签 | 105 Hz 膜振与短敲击 | 鼓槌落下和声波 |
| 医、祭、书、召唤、幻、火、灯 | 440／660／880 Hz 短泛音 | 法器挥动与投射／辅助效果 |
| 投矛、针、锁链、工匠 | 既有掠风音 | 投射与工具释放 |
| 刀、剑、锤、拳、冲车 | 既有挥击音与独立轻／重命中 | 前摇结束、打击与纸屑 |
| 印台、压雪车、陶灰炉 | 既有低频炮声 | 炮口、后坐与爆裂 |
| 采矿、装载、归仓 | 既有镐击、负载、金币音 | 真实经济事件 |

重攻击的动作音由 0.60 提升到 0.78 强度，命中声音仍由实际伤害调节。动作音不等于命中，不在预测、取消或友军碰撞时播放付费／伤害反馈。缓存式合成无需连续音生命周期；无头检查保留控制器调用并静音。当前原生实战与动作检查均不声称 Android 扬声器或蓝牙延迟已验收。

装备优先路由：折簧钉枪与绞盘重弩使用机械弩音，按实际装填事件播放低强度扣机音，不再按旧“投矛/炮兵”职责发炮响。整身动画释放帧与真实攻击事件同步。
