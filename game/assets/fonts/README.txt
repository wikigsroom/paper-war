Paper Warfront uses Noto Sans SC and Noto Serif SC under SIL Open Font License 1.1.

The 600-weight runtime subsets have internal family names PaperWarfront Text and
PaperWarfront Title. Original copyright and license text remain in the two OFL
files in this directory. No system font is redistributed.

Original font project: https://github.com/notofonts/noto-cjk
Google Fonts sources: https://github.com/google/fonts/tree/main/ofl/notosanssc
Google Fonts sources: https://github.com/google/fonts/tree/main/ofl/notoserifsc

Full licensed source files are retained outside the game runtime in
assets/paper-warfront/fonts/source. The optimize_fonts.py tool reads those files
or the local development cache, never cumulatively subsets an old runtime font.
