### 当前内容

- 自动行军、金币/法力经济、局内科技、手动施法、生产队列、建造和横向导航。
- 十个原创阵营，60 种作战兵、10 个纸工和 2 个召唤物，共 72 个单位条目；另有 50 个法术、30 个建筑与 42 项升级定义，按阵营/关卡规则开放。
- 十章、200 张剧情地图；路线支持择一、并行、条件汇流和回访。地图道路、桥、坡、矿线、建筑位和目标锚点影响真实行军及归仓距离。
- 摧毁、护送、截击、保护、归仓和生存等任务类型；另有六个独立计分挑战、六张地图试演和遭遇战。
- 未知 / 已探索 / 当前可见三态迷雾，分路侦察，开火揭示与建筑记忆；镜头移动不会提供视野。
- 夜战灯笼 UI、完整姿态帧、厚纸地层、投射物、纸屑粒子、命中反馈与音效。
- 本机双人分屏，以及实验性局域网对弈；跨设备真人联机仍待验收。
- 本地保存剧情完成、证据、星级、挑战分数、部署与设置；Windows 存档在 %APPDATA%/PaperWarfront/profile.json。

## English

This is the first public preview packaged from the current rc41 Windows and Android exports. The executable content retains its internal build identifier instead of being rewritten solely for the public release number. The game UI and story are primarily Simplified Chinese; the repository README and these notes are bilingual.

### Downloads and installation

- **Windows ZIP**: extract the entire archive and run PaperWarfront/PaperWarfront.exe. Godot is not required. Use Play-OpenGLCompatibility.cmd if the default renderer cannot start.
- **Android APK**: signed ARMv7/ARM64 package, application ID org.paperwarfront.game. Install from an allowed source and use landscape orientation. No physical device has been tested.
- **Source ZIP**: complete code, runtime art, data, design constraints, screenshots, GIF, and build tools. Open game/project.godot in Godot 4.7.2 and allow initial import. No image-generation service is needed at runtime.
- **Manifest and SHA256**: verify the downloads and trace the internal build, source inputs, binaries, and archives. Signing keys, API credentials, import caches, and historical QA frame dumps are excluded.

The download links in the table above are shared by both languages.

### Included systems

Automatic marching; gold and mana; in-match technology; manual spells; production queues; construction; lateral navigation; ten asymmetric factions; 60 combat units, ten workers, and two summons; 50 spell, 30 building, and 42 upgrade definitions gated by match rules.

The campaign has ten chapters and 200 story-bound maps with choices, parallel branches, conditional merges, and revisits. Road topology, bridges, slopes, mine lanes, build sites, and objective anchors affect actual travel and deposit time. Destroy, escort, intercept, protect, return, and survival objectives coexist with six score challenges, six spatial rehearsals, and skirmishes.

Fog distinguishes unknown, explored, and currently visible information, with per-road scouting, firing reveals, and remembered buildings. Camera panning never grants vision. Night Lantern UI, full pose frames, paper ground layers, projectiles, fragments, impact feedback, procedural sound, local saves, split screen, and an experimental LAN mode are included.

### Validation and known issues

Ten native Windows pages were captured. Desktop and phone-shaped UI checks each passed 49 checks; the mobile layout matrix passed 26723 checks across eight scenarios, with a minimum battlefield share of about 70.6%. The current 60-unit purchase, production, and controlled hostile-damage regression passed 370 checks.

The combined legacy simulation suite has **50 passes and seven unresolved failures** involving conversion, stamp radius/damage, fire pulses, area-spell aim, poison-source selection, root movement blocking, and guardian position. Their classification as stale assertions versus active mechanic bugs is incomplete; this is not an all-tests-passing release.

The APK passed signing, alignment, package, and ARM64 16 KB ELF static checks. **Android hardware remains untested.** The 200 map definitions are not proof of 200 complete human playthroughs. Overall faction balance, sustained power use, vendor GPU behavior, cross-device multiplayer, and stable high-density performance remain under review.
