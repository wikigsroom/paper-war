# 持续波次与开局投资窗口

## 单波攻坚收益不等于持续反扑

75中木拓四侧位完成拆城只针对三名敌斧兵的一波压力。本轮先增加三波、每波三名印甲斧兵，间隔25秒，对照只完成投资、补充失去的前排、补前排配合法术三种政策。18组均为180秒未决；只完成投资的六组全部失去工人，敌城未受伤。补前排与法术能改善部分经济保留，但还没有稳定反推。

第一协议在己方第二种配方兵实际生产后触发敌方波次，法术政策把可见敌军视为防守威胁，属于明确的保守施法选择；不是正式TacticalAI完整决策。不能与后面的固定时间协议混为同条件结果。

## 固定波次与投资顺序对照

第二协议固定在18、43、68秒开启敌方招募窗口，不读取己方兵团状态来推迟进攻。所有命令真实支付，资源不足则等收入，生产仍排队。本轮24组均实际买到九名敌斧兵；没有免费生成部队、额外发钱或跳过生产。

木拓四种政策、短/中/长图和双方侧位：

- 只完成投资：研究守卫/医师，再买前排、看仓守卫、医师、毒种。
- 补前排：沿用投资顺序；看到敌方作战单位且缺少近战前排、队列也没有前排时，实际花70金币补守卫。
- 补前排与法术：同上，使用已解锁法术、真实法力和冷却；威胁门禁按正式TacticalAI的可见敌军距基地/无前排拦截判断执行。
- 基础兵先行与法术：先购买初始已解锁的守卫、毒种，再买研究后的看仓守卫与医师；研究费用、等待、武器数据及补前排/施法门禁不变。

基础兵先行允许基础招募与真实研究并行，不免费解锁高阶兵，也不是替代所有地图的唯一开局。策略只从当前合法视野收集敌军，队列、资源和兵团判断只读自己信息。敌波次是预设测试导演，不是完整对手AI。

24组全部180秒未决，全部尚未伤及敌城。工人保留不等于反扑完成。部分政策反复补前排时，原定医师或毒种仍未买齐，说明保护经济和完成混编正在竞争同一金币预算。

这组证据确认地图长度与投资顺序的关系不能只由“长图有更多时间”概括：基础兵先行在本组短、中图保住两名工人，却在长图差于另一投资顺序。不能据单种子、单阵营及预设波次无条件修改默认AI，或宣布科技无用。下一步需记录发现威胁、前排失去、替补出仓/抵达、法术使用以及下一波接触的时间线，验证完整TacticalAI与人类能够采用的转型窗口。
