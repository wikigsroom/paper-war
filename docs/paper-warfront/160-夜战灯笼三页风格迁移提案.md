## 统一风格合同

- 色彩基线：深靛夜景、墨蓝文字、暖象牙纸、朱砂主行动、少量古金边线。
- 材质基线：纸张纤维、薄纸折角、绢布军帐、灯笼暖光；不使用发光霓虹、厚重科幻金属或写实人物。
- 文字基线：中文由 Godot 原生 Label/Button 绘制；生成图只提供材质、构图、色彩和装饰参考。
- 交互基线：主按钮为朱砂红，次按钮为象牙纸；选中/焦点可使用玉青细线，禁用状态降低饱和度和对比度。
- 战场基线：保持横向地图、纸偶层级、单位比例、地图土层和战争迷雾规则；战斗页默认收起状态仍须满足战场可见面积不少于 70%。
- 迷雾基线：右侧未知区域保持整屏高度的靛蓝纸雾遮罩；未知敌军、矿点和实时状态不能因为夜景装饰而提前显现。

## 页面落地约束

### 任务简报

保留任务标题、朱印统帅肖像、对白、路线折线图、目标/地点/胜利/战术、双方起始金币，以及“调整部署 / 展开战场 / 返回”三个动作。路线图继续使用直线主路、三角形高路和同节点汇流，不改成装饰性世界地图。

### 实时战斗

顶部保留金币、法力、关卡标题、时间、路线小地图和暂停；底部保留当前兵卡、法术和军令入口。深靛夜景只改变舞台照明和 HUD 纸材质，不改变纸城、单位、道路、地下土层或矿点位置。右侧战争迷雾要保持为信息遮挡，不得只做成普通暗角。

### 战斗结算

保留结算标题、关卡与时长、三颗星、招募/击倒/损失/归仓金币/施法/法力/治疗/召唤/反弹/打断统计，以及“重新开局 / 再战本局 / 主菜单”三个动作。背景仍显示被压暗的真实战场和 HUD，避免生成图变成独立宣传海报。
