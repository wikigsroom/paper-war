# 图标资产运行时接入与 rc39 双平台导出

## 本轮接入

本轮只更新启动图标，不改变任何菜单内容、菜单排版、菜单背景或菜单文案。

| 位置 | 接入内容 |
| --- | --- |
| 游戏图标 | 由 **02 木刻墨印·印甲统帅** 派生 512×512 象牙纸底图标，替换 `game/assets/icon.png` |
| Android 自适应前景 | 由同一角色派生透明 432×432 前景，绑定 `launcher_icons/adaptive_foreground_432x432` |
| 菜单 | 桌面与移动端菜单回滚至图标更新前版本，未接入 Banner、字标或 Key Art |
| 运行时清单 | `game/data/branding-runtime.json` 仅记录两个图标资源的稳定 ID、来源、尺寸和哈希 |

运行时副本只保留 `game/assets/icon.png` 与 `game/assets/branding/icon-foreground-432.png`。完整 Logo、Banner 和 Key Art 仍保存在 `assets/paper-warfront/branding/` 与 `output/imagegen/paper-warfront/`，不进入菜单运行时。

## 导出版本

- Godot 工程版本：`3.0.0-rc39-icon-preview`
- Android version code：`30038`
- Windows：`release/3.0.0-rc39-icon-preview/windows/PaperWarfront.exe`
- Android：`release/3.0.0-rc39-icon-preview/android/PaperWarfront-3.0.0-rc39-icon-preview.apk`

导出使用 Windows 原生 Godot 4.7.2、Android SDK 36 与 JDK 21。APK 仍需实体 Android 设备验收；当前环境没有可用设备，因此不把 Windows 注入手机形状窗口或 APK 静态检查写成真机结论。

## 验收范围

- 资源导入：游戏图标与透明前景均可由 `res://` 读取，尺寸与 SHA-256 与运行时清单一致。
- 菜单回滚：`game/scripts/main.gd` 与 `game/scripts/mobile_ui.gd` 恢复图标更新前内容，不再引用 Banner、字标或 Key Art。
- 导出包：Windows EXE 与 Android APK 重新生成，记录位于对应 release 目录的 `build-manifest.json` 与 QA 日志。
- 包级检查：执行 APK 签名、16KB 对齐、Android Manifest、Windows 启动和资源完整性检查。
- Windows 原生导出烟测：`output/qa/godot/render-runtime-rc39-icon/mobile/export/report.json` 中 6/6 场景通过，覆盖桌面菜单、桌面战斗、手机形状窗口、紧凑屏、刘海屏和平板形状窗口；菜单复核截图位于 `output/qa/godot/render-runtime-rc39-icon/mobile/export/desktop-menu.png` 与 `output/qa/godot/render-runtime-rc39-icon/menu-check/mobile-menu.png`。

图标源图仍是品牌资源；性能结论只来自 Godot 源码、编译包和 Windows 原生检查。
