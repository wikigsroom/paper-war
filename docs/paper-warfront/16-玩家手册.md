# 玩家手册 · 3.0.0-rc37-preview

普通兵与长卷地图采用更舒展的比例，厚土纸层帮助辨识地表、桥面和上下路。未知区域覆盖整个舞台；拖动镜头只改变观看位置，部队侦察才会展开地图。手机仍保留可辨识的兵体与至少70%的战场区域。满员密集场景帧率仍在优化，Android真机性能尚未验证。

界面使用折纸按钮与纸页：朱印按钮表示继续／确认，玉青框表示当前选中，灰纸与锁表示尚不能操作。按住按钮会显示压纸状态；开关显示纸框勾选。价格、队列数字、冷却和生产进度仍直接显示在兵种／法术卡上。

从“继续战役”进入当前推荐纸页，或在“新战役”选择故事战役 / 遭遇战。每章20页都有自己的剧情节点；部分地图保留单主路，部分地图提供择一、并行调查、条件汇流或回访。卡片显示“可行动”“需完成某折”“已留证”。未走的支线保留，不会凭空获得证据；已完成地图可回访，星级保存最高值。胜利后点“选择下一页”查看当前真正开放的路线，完成合印门后进入后续章节。第二至十章同样按剧情条件逐步开放，不保证只有一条固定完成顺序。

设置内的“地图试演”可直接尝试六张空间基准图。兵书可查看每院六种独特作战兵与反制，战前选择2–4种开局偏好兵；常规对战可在局内研究全院六兵，加一个纸工。剧情路线选择与战场内路标分别操作，绕行与汇流仍需真实行军时间。

军队自动行军交战，你负责金币与法力的取舍。纸工在矿口站定采金、装载并归城卸货，金币在实际归仓时入账。先招前排与远程护住经济；研究解锁本局重兵和法术。设施选卡后提交合法建造位才收费，施工中的阵地需要保护。

路标切换后续军队的道路，已上路的军队继续走当前路线。纸桥较长，能绕开近战阵地，但真实射程内仍可能被敌人攻击。远矿增收需要较长归仓时间和护卫。护送、截击、守护按任务锚点实际执行。

法术选卡后点对象 / 地面；非法目标不会扣法力。右键、取消或返回退出选择。拖动战场或点小地图导航；A/D或方向键移动，Home回城，Space跟前线，1–7招募，Q/W/E/R/T选法术，F研究，B建造，Esc暂停。手机长按行动卡看完整机制，军令内管理科技、施工与生产队列。

钉枪和重弩有装填停火窗口；游弓射后后撤；钩线能拉动实际站位；腐墨叠层，花冠师能净化；霜楔配合压雪车打被控目标；留白消矢师可删飞弹但怕沉默。用兵书中的真实机制组织组合。

纸商的断契追债镰能在一名基础卫后方收割残血，击杀真实作战兵赚取赏金；先部署基础卫保护它，观察敌人生命再投入长镰。研究和出仓仍需要实际金币与时间。

胜利记录实际完成纸页并开放符合剧情前置的关卡，未走支线不伪造完成；试演和遭遇战不改变剧情解锁。设置可调音量、减少动态和省电。后台回来需手动继续。

对战底部只有一排行动卡，招募和五个法术同时显示。手机招募区可左右滑动，开局偏好与纸工排在前面，其余兵种仍可滑到；滑动不会招募，长按查看全名与机制。右上小地图用于导航；城池、兵力、科技、施工和队列详情集中在「军令」，选中法术或建筑时该按钮变为「取消」。窗口高度不足320dp时导航与暂停移入军令，拖动战场仍可移动镜头。

镜头与缩放不能揭示敌军；侦察发现高价值敌兵时提示。小地图空心建筑是旧情报，不代表当前生命或生产状态。六个独立挑战按有效治疗、打断、召唤、反弹、设施入账或守城判定目标，最佳分数独立保存。

自动追踪按各自玩家的视野工作：未接敌时跟随最前方己方作战单位，附近交战后关注可见交锋；没有作战单位时回到己城前方。纸工和隐藏敌军不会牵引镜头。拖动地图或点击小地图退出追踪，在「军令 → 追踪交锋」恢复；同屏和联机的东、西两侧使用相同规则。

战场上的纸色雾幕表示缺少视野：从未探明区域较浓，探索后无人观察的区域较淡；退出视野的敌军不再显示。桥路与地面路分别侦察，下路单位不能直接看见桥上的敌兵。矿点状态、施工位置和现场路牌随视野显示；可在军令中提前设置后续出兵路线。新版舞台增加土层厚度和道路空间，手机纸工与兵体保留最小显示尺寸。

查看兵卡资料可看到尚需的研究与首次招募金币、最早出仓时间，以及到当前己方前线位置的总响应时间。总响应包含研究、现有队列、新兵生产和当前选路的道路行军；假设金币足额与连续研究，不包含战线移动、阻挡或控制。手机长按详情显示打开时的估算，不能把出仓时间当作已经抵达战场。

生产队列打开时战斗继续。订单出仓或队列变化后，旧取消按钮会拒绝并刷新；再次选择当前订单才会准确取消与退款。提前部署不保证有效攻击：保护经济与前排、观察敌方可见兵团，再决定是否投入高级研究。

敌军同样依赖纸工回款、科技与生产时间。安全开局会补齐采矿队，完成兵种研究后为首名新兵留钱，再考虑下一项研究和可选哨塔。远程需要前排掩护，治疗和召唤需要存活兵团；敌军受压时会优先补充防线。法力设施和关卡指定科技需要留出投资。

前排被可见远程敌人束缚、眩晕，或在武器触及外遭根缚与减速时，敌军会用实际金币补充射程足够的已解锁兵。已有反制兵或订单时会等待增援，已付研究的首次招募目标仍保留。保护本方纸工、侦察敌方矿路，观察增援到达距离后决定进攻或防守。当前版本及验收范围见 [rc25记录](134-受控前排反制与科技收益复核.md)。
