# 开火揭示与地图预警窗口

## 当前修复

正式迷雾下，长坡上投矛兵可在工人3.2视野之外、基地8视野之外攻击工人：攻击范围4.2。十二场正常付费AI观察发现三次此类释放，守方此前无法锁定来源施法。这是本作反制体验缺口；没有原作PC HD实机证据证明其具体开火揭示规则。

当前开发源码采用原创对标规则：实际攻击释放后，向受攻击方暴露来源1.5秒；来源周围仅揭示道路距离0.35，不赋予整个作战单位的6以上视野。未释放的前摇、被控制取消的攻击和友军行为不揭示。单位与攻击设施均执行；重复开火续期，停止后退雾。活来源在时限内可跟踪，死亡来源只保留最后释放位置的短暂可见区域；转成友军后清除敌情揭示。

揭示统一进入道路信息服务，因此战场、小地图、AI和合法施法使用同一状态。不增加工人天然视野，不修改伤害、费用、射程、生产或研究。每步末统一刷新，没有每发投射物额外刷新全图。

## 地图尺度与预警

必须按实际地图定义识别地图，而非关卡编号推测：W01为map.01.01，最短道路38.264；W04为map.01.04，最短40.000；W03为map.01.11，最短54.440。早期误将map.01.03视为长图，它实际只有38.158，观察文件已重命名为short-variant，不能作为长图结论。

开火揭示前的正常付费观察：印甲对木拓时，毒种兵短图14.867秒被发现、16.000秒释放；长图21.567秒被发现、22.700秒释放，两者预警均1.133秒。更长道路推迟接敌，不会自动放大局部发现到攻击的窗口。其他组合可因兵团/侦察来源变化产生不同窗口，不声称所有窗口恒定。

短图选定组合中木拓/白签仍败给印甲或灯符；长图两院对墨骸出现两侧胜利。此为同种子、特定组合观察，不是所有地图或真人平衡证据。

- 新十二场正常付费/研究/正式迷雾60秒观察来源核验通过，覆盖短中长三图、四个有向组合。warning-windows-firing271.json及warning-windows-firing-summary271.json。
- 仍有三次首发释放前未见攻击者，这是保留的突袭。三次source_visible_after_release均为true，证明释放后守方可见，不证明释放前预警、工人获救或AI胜率改善。

释放不等于命中。source_first_hit_at记录攻击者整段观察中的首次伤害，不能用作某次袭矿的命中时刻。新字段source_visible_after_release来自该步结算后的合法可见集合，不改变AI决策。

此修复与寻敌优化尚未进入rc8-preview EXE/APK；现有导出保留历史证据。下一阶段继续验证反制操作、经济恢复和长短图兵团投资收益，不能宣布全阵营平衡、Android真机或原作精确复现完成。
