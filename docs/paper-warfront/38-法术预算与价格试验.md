# 法术预算与价格试验

本篇记录37之后的开发源码增量。已交付rc7-preview没有重新导出，不包含当前AI修改。本轮不修改正式单位价格、生命、伤害、特色能力、地图道路或素材；价格试验仅由测试脚本对内存数据显式覆盖。

## 法术预算已实现

AI不再仅按当下买得起哪个法术选择：当前视野内至少两名敌军接近成团时，为已解锁、冷却结束或一秒内可用的伤害/控制区域法术保留预算；健康接战兵可复制时，也考虑复制工具。选择当前相关工具中最低费用者，避免一律储蓄最贵法术。

普通单体控制、治疗、保护若会侵占这笔预算，暂缓使用。仍允许以下紧急用途打破预算：可见重击/致死前摇的打断；正在接敌且濒死友军的治疗/保护；正在进入城防攻击距离的目标控制。多余法力可以用于普通控制，不要求整局只用区域法术。

没有可见敌军成组、法术未解锁或冷却较长时，不保留该预算。隐藏敌军不能触发储蓄。费用、冷却、视野、目标、金币和生产规则不变。

因此本轮不将降价试验直接变成正式平衡，不靠给弱院额外资源或免费兵赢得探针。后续调整仍应保留低血增伤、法术吸收/驱散、自然修复/根毒控制的机制身份。
