# 项目章程与硬约束 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

以横向军团自动推进为骨架，玩家操作招募、研究、设施投资、矿点优先、后续部队选路与手动施法。地图位置必须改变到达时间、保护压力或任务窗口。

Godot4.7.2原生GDScript与Control；战斗60Hz；2D分层纸偶、厚纸边与粒子，无外部三维建模需求。Windows原生EXE、Android离线APK，禁止Docker／WSL／虚拟环境／模拟器。生成位图使用指定sub2-image-gen与gpt-image-2.5。

3–5个生产类型含工人；战斗编组2–4兵种。400兵种是全局军库规模，不能全部塞进同一局。关卡数量与散列不能作为设计验收；六张基准图须具备可比较的取舍。
