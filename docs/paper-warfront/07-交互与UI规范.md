# 交互与 UI · 3.0.0-rc20-preview

所有正式界面采用暖纸、墨边、朱印主行动和玉青选中反馈。按钮与纸页使用已检查的 sub2-image-gen / gpt-image-2.5 位图切片，中文文字保留原生绘制；普通、悬停、按下、禁用、焦点、选中、开关、滑块与下拉样式通过共享主题统一。素材来源、加工、引用及原生检查见[折纸 UI 素材与风格调优](122-折纸UI素材与rc16风格调优.md)。折角必须位于固定切片内，不能进入拉伸中心；装饰不能扩出控件矩形或增高战斗栏。

主菜单从上到下为：继续战役、新战役、成就挑战、兵书、设置。新战役进入故事战役或遭遇战。故事卡片按实际完成ID和剧情前置开放，第一章含六处择一推进与汇合；已完成和未走的支线可回访。胜利后“选择下一页”，不假定只有线性下一关。地图试演、操作帮助、鸣谢和退出在设置中。兵书展示每院六兵种与真实机制，编组可带2–4种作战兵。

游玩 UI 保留金币、法力、任务、生产、研究、设施和手动施法。兵种卡使用新头像和可读短名，详情显示全名和规则。非法目标不收费，取消和返回遵照当前模态层级。鼠标/首指拖动捕获镜头，8dp拖动阈值防止误选，越过HUD释放可结束，取消/后台/旋转清除捕获。

对战默认收起时，扣除常驻UI后的可见战场必须占整个游戏视口至少70%。不以背景绘制范围或仅安全区内的面积冒充此比例。桌面上栏56、下栏90逻辑像素；手机上方24dp信息带、底部52dp操作带，右上48dp小地图和暂停额外扣除与战场重叠的面积。详情与主动打开的模态菜单按展开状态另计。

rc21：导航只移动镜头，不能揭雾。舞台雾幕与小地图读取同一方的当前/探索视野；未发现敌军和未知矿点不显示实时状态。路牌的绘制与触控热区共同检查视野，侦察前不得出现隐形按钮；己方生产选路仍可通过军令预先设置。纸偶缩放后同步更新点选与武器释放位置，手机作战兵至少60dp、纸工至少52dp。土层与路间高度的约束见[本轮修复](130-迷雾呈现与地图比例修复及rc21交付.md)。

底部一排同时提供招募与五个法术。手机招募区横向滚动，全院六兵加纸工可访问；偏好兵种与纸工优先排列。每张卡仍有价格、锁、冷却、队列数量和生产进度，长按显示全名与机制；8dp拖动锁定后取消点按。军令内集中科技、建筑、队列、城池与兵力、回城和交锋导航，选中法术/建筑时直接变为取消。提示复用上栏，不增加战场中的永久信息横条。

移动界面使用原生 Control、实际密度、安全区、48dp行动目标和8dp间隔、可滚动详情及横屏恢复。对战使用安全区全高；菜单保留页面边距。返回先退出选择，再关闭面板或暂停。切后台停止声音与模拟，回来手动继续。

纸页弹窗接管所在视口的键盘焦点，Tab与Shift+Tab只能遍历当前纸页内可用控件；关闭后恢复打开前的控件及其原始焦点模式，替换纸页保留同一个返回位置，页面重建丢弃旧控件引用。单人、本机分屏与网络共享控制面板采用相同规则。手机列表及招募横向栏在被弹窗遮挡、隐藏、暂停或切后台时终止拖动与惯性；纸页内部仍可正常滚动。本规则不增加默认HUD高度，折纸资源沿用rc16生成库。

打开的科技、建筑、队列与军令摘要按实际对战状态更新，连续倒计时不得重建纸页或重置滚动。科技显示缺口、前置、研究中及已完成；建筑显示类型、解锁、资金、己方占用、设施上限和施工状态。按钮判断与权威研究／施工共用无副作用规则，网络面板仅读取己方投影。单人选建筑蓝图和取消不收费，未侦察的兼容空位可以导航，实际建造必须处于当前视野。

队列结构变化时禁用并退休旧行，退款回调捕获原始队列版本、位置与兵种；出仓与按住／松开交错时不得取消替代订单。最后一项离开队列要原位显示空状态。移动及共享两行状态采用64dp最小行高，避免禁用文案撑高造成相邻按钮重叠；桌面建筑效果放在正文。关闭、视口重建和退出对局清理纸页工厂引用，详见[实时军令纸页与UI状态调优](126-实时军令纸页与UI状态调优.md)。
