# 兵种职责部署与单侧战场贡献复核

原顺序候选对所有非近战兵要求先有选路兵团。这把治疗/维修与主动狙击/沉默放在同一部署条件中，可能削弱局内转型。新增默认关闭的experimental_ai_role_deployment，只有对应侧顺序候选启用时才生效；还可单独指定角色候选侧位，而不改变对手的顺序策略。

按实际能力判断：heal_amount、repair_building、auto_clone_seconds及同时有summons/corpse_range的非近战单位保留兵团条件；其他非近战单位在这个候选中不要求先有配对。support_priority表示攻击敌方支援，不是依赖己方支援，不能据此要求友军。近战仍沿用原条件。此为本作策略假设，不是原作明确规则，也不是生存保证。

同名角色不作为分类依据：灯符复制师有auto_clone_seconds，需要可复制友军；空白“illusionist”实际抹除敌方投射物，没有auto_clone_seconds，在候选中可独立部署。自带护卫的灯符召唤师也不要求预先成团。维修工仍按协同型处理，但兵团并不能代替可维修设施；尸体召唤也需要实际尸体，不能将成团当作能力可执行证明。

双侧30项机制检查通过，包含实际147金币狙击兵付款订单、次轮清除目标、两个不同的侧位约束及候选关闭后的原规则。最终51组12948项Windows原生机制回归通过，输入哈希匹配当前源码。付款窗口候选保持关闭，下面对局没有启用额外付款条件。

## 双方候选初查

中图map.01.04、seed137、300秒、300金币、2纸工、正常研究与正式迷雾，六组双方顺序候选对照，共12场。加入双方角色候选后，金契对墨骸的狙击兵招募从242.47/257.42秒提前至172.27/156.02秒；空白的书记兵也可提前进入生产队列。但金契西—空白东胜方由空白变为金契，空白西—植纤东由空白胜变为未决。不能从双方策略同时变化归因到单侧兵种。此为补充复制能力分类/单侧参数之前的来源记录，旧AI与观察脚本均保存了原样存档。

空白东对金契西：实际付费书记兵85.82秒，88.62秒出仓，98.17秒法术复制产生第二个同类型实体，98.97秒首次命中。本体与复制体共18个hit事件、登记伤害229；不是两笔付费招募，也不是229点额外净收益。候选最后工人/订单0、基地0，控制组工人/订单3、基地1100，明确存在自身策略退化。

金契候选虽然提前招募且更早结束两场胜局，狙击兵在候选观察内没有实际命中，不能把胜利归因于高级输出。先付费、实际生产、抵达交战、有效攻击、兵团收益必须分层验收。仅去掉后排兵团门槛没有建立科技反推，更不能全局开启。

下一步应比较首次部署挤占的真实基础兵/设施投入，结合生产等待、道路长度、部队移动与接敌状态评估抵达窗口；避免为所有非近战单位保留同一硬门槛，也避免无条件优先兑现已付研究。候选默认关闭。
