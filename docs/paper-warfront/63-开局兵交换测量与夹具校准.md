# 开局兵交换测量与夹具校准

新增 probe_opening_exchange.gd，测量20种开局作战兵分别对印甲斧兵和墨骸刃兵的左右位置交换，共80组。双方用300金币预算购买整队，保留不足购买下一兵的余款；正式迷雾，关闭AI、工人、设施与法术，预组兵团不包含科技/生产时间。纯远程输给近战不能直接判定阵营弱势，反魔兵对物理兵的结果也不代表其法术反制收益。

首轮80组完成，原生记录有实际攻击、伤害、治疗和存活。分析时发现布阵夹具继承了旧预组探针的 x=14/24。地图01.01基地在2/40，中点为21；原布阵围绕19，不能当成严格镜像地形。鸢纸弓兵的节点加速可能受这个偏移影响，尚未证明侧序机制缺陷。

新夹具改为实际两基地中点左右各5单位，队尾按相同距离展开。旧木拓预组探针 probe_mu_formations.gd 的坐标也同步修正，原脚本保存为 probe_mu_formations-before-centering.gd.txt；原报告仍作为历史观察，后续需使用新夹具复测。已启动 opening-exchange-centered.json 的80组重测。原始 opening-exchange137.json、opening-exchange-summary.json 与 probe_opening_exchange-before-centering.gd.txt 保留历史；旧summary的来源验证只对应旧夹具，不代表修改后的当前探针。

analyze_opening_exchange.py 校验全部20×2×2组合、不重复、实际购买预算和来源哈希，将互死与60秒未决分开统计，不把未决视为平局。

同时 faction-ranged-current100-137.json 的正常付费100组合矩阵继续运行；它使用真实基地招募而非上述预组坐标，未受到这项夹具偏差影响。完整矩阵完成前不发布全阵营结论。

对称80组已完成并通过来源校验，见 opening-exchange-centered-summary.json。鸢纸弓兵对两种近战对手的两侧胜负及时间一致。此后正式数值在64调整，本篇测量转为修改前历史基线。正常付费100组合也已完成并核验，结果见64。
