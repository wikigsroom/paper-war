# 镜像交锋顺序缺陷定位

后续说明：[移动阶段接敌修复](59-移动阶段接敌公平修复.md)与[同帧攻击结算更新](60-同帧攻击与死亡结算更新.md)已按阶段处理本文两项缺陷。本文数值与“尚未改写”描述保留定位当时的历史含义。

继57，使用两个相同纸商近战隔离位置与命中：正式纸桥地表中心对称放置，关闭AI、工人、塔与施法，保留相同正式属性/金币；每步分别按西侧先或东侧先遍历。各组最多30秒，任一单位死亡即截止。此为隔离模拟，非完整付费开局。

射程内结果约9.9667秒、行进组约12.5秒结束。两种侧序位置和结局对照确认不是单一“先更新胜”：射程内先结算致死会跳过同帧对方还击；行进时后更新者读取已推进的对方位置，获得先启动前摇的优势。这些顺序差异可以放大纸商击杀赏金与金库伤害的反馈，但本项未证明完整镜像全部差异都由此造成。

## 必须按阶段修复

不采用交换两侧、每帧轮换或补资源作为最终解决：它们只能改变优势分配，不能保证同帧意图公平。接下来需要从帧开始的同一状态产生感知/移动/攻击意图，再按明确阶段推进位置并处理释放。对于帧开始仍存活且已完成合法前摇的攻击，不能仅因本帧另一条攻击先执行而取消；同时要保留控制打断、目标离开范围、友敌归属、反射、吸血、击杀奖励与尸体召唤的正确时序。

该改动影响模拟核心，需实际单元与兵团测试覆盖，不先用单位降价掩盖结算差异。当前正式模拟尚未改写，56矩阵/4743规则回归仍为当前源码，但不能作为此公平缺陷已修复的证明。Windows/Android未重新导出。
