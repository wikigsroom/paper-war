# 实时军令纸页与 UI 状态调优 · 3.0.0-rc19-preview

本轮把纸艺界面的显示状态与真实对战连接起来。科技、建筑、队列和军令打开后，对战继续进行；金币卸货、研究完成、建筑施工和单位出仓会更新当前控件。纸页不为倒计时反复重建，保留滚动位置与键盘焦点。当前双平台预览为 rc19，以下记录区分源码、实际编译包与硬件验收的范围。

## 已实现的交互

| 界面 | 当前行为 | 输入与费用约束 |
| --- | --- | --- |
| 单人与共享科技 | 显示真实价格、前置、金币缺口、研究倒计时和已完成标记；资金到账或前置完成后原位启用 | 不足、研究忙碌、未完成前置、未在本局编组、已完成时禁用；共享面板只读取己方投影 |
| 单人建筑蓝图 | 显示可建类型、金币缺口、空位和设施上限；金币到账后原位启用 | 选蓝图及取消不收费；未侦察的兼容空位允许导航，实际施工仍要求当前视野 |
| 共享建筑 | 每个己方建造位显示可用、需侦察、金币不足、占用和施工倒计时 | 用实际施工条件禁用，包含建筑解锁、类型、己方占用与产法设施上限 |
| 单人与共享队列 | 实时累计出仓倒计时；出仓和退款后更新行数，最后一项出仓显示空状态 | 每个退款回调捕获不可变的队列版本、位置与兵种；旧行退休时禁用并取消按下，按住期间出仓不会误退替代订单 |
| 军令摘要 | 当前金币、法力、城池、兵工数量、队列与时间持续更新 | 单人敌城生命仅在当前视野中显示；网络面板不读取对手金币或队列 |
| 纸页生命周期 | 返回位置、焦点与滚动遵照 rc18 规范；关闭、视口重建和退出对局清理纸页引用 | 队列结构变化才替换行，连续倒计时更新保留原控件；退出及旋转重建打断共享队列工厂的引用环 |

`battle_command_rules.gd` 只检查条件，不改变金币、事件或计时。权威模拟的研究与施工和 UI 使用同一条件，原有费用、命令顺序、任务预置的视野例外以及扣费流程保留。`ui_battle_sheets.gd` 负责原生控件的显示更新，单人按 HUD 的 0.1 秒节拍更新，共享面板同样限制更新节拍。

## 纸艺与排版

继续使用[已生成的 38 项折纸资源](122-折纸UI素材与rc16风格调优.md)，来源是用户指定的 `sub2-image-gen / gpt-image-2.5`。暖纸、纤维、折角、墨边、朱印和玉青主题覆盖普通、悬停、按下、禁用、焦点、选中、开关、滑块与下拉。素材库版本仍为 rc16；本轮交互版本单独记录，不伪造重新生成或变更素材版本。

按钮中的中文、价格、倒计时和禁用原因由 Godot 原生文本绘制，提示及无障碍名称跟随当前文案。移动科技与队列行使用 64dp 最小高度，共享两行状态也使用 64dp；页面支持滚动，保留 48dp 行动目标和 8dp 间隔。常驻战斗栏没有增加高度，默认收起的战场占比继续要求至少 70%。

原生检查捕获过桌面建筑按钮的三行状态导致高度从 87 撑到 111 逻辑像素、两行控件相交的问题。最终方案把建筑效果移入正文，按钮保留建筑、成本和当前限制，避免靠裁掉禁用原因解决重叠。诊断源码、实际包截图与日志保存在 `output/qa/godot/ui-rc19/overlap-before/` 和 `live-overlap-diagnosis/`；该中间包不作为交付结果。

## 原生证据
