# 交锋决策与弱势阵营复测

本篇对象为当轮开发源码，后续修改及观察见[法术预算与价格试验](38-法术预算与价格试验.md)。已交付3.0.0-rc7-preview没有重新导出，不包含本轮AI决策与此前独立随机流修改。原作精确价格、地图尺度与PC HD迷雾参数没有同条件实机测量，本轮不宣称数值复刻或整体对标完成。

## 已确认的问题与执行修正

最新独立随机流下，木拓、纸械、白签对印甲的六场正反向基准仍全部败北，分别约100–101秒、89.6秒、91–95秒结束。每15秒记录军队、生命、位置、研究储蓄、金币、工人与施法，发现以下实际决策缺陷：

| 问题 | 实际修正 | 保留的限制 |
| --- | --- | --- |
| 两名远程被当作安全军队，前排消失后继续储蓄科技 | 有可见敌军且存活近战前排为零时释放待研究预算，停止新研究和非必要扩建 | 不撤销已经付费开始的研究，不依据隐藏敌兵改变投资 |
| 前排贵于后排，重复购买廉价后排使前排一直买不起 | 无排队前排、前排已失且尚无城下紧急威胁时，为已解锁最便宜近战前排保存金币 | 工人必要恢复仍优先；城下紧急防守可购买其他可负担作战单位；不免费招募 |
| 以射程≤1.2认定前排，漏掉近战范围巨兵 | 根据实际近战攻击类型统计存活和排队前排 | 不把远程巨兵当成近战屏障 |
| 残血前排被随意献弃 | 不献弃最后一道近战屏障、低血增伤兵、无敌保护兵或任务对象；仅在可见敌军已瞄准且前摇伤害足以致死、收益至少5法力时考虑其他可献弃兵 | 保留献祭经济；正常上限、费用、目标限制与指令校验继续执行 |
| 复制最虚弱单位，或在接敌前消耗复制寿命 | 根据双方射程与道路战斗距离判断接战；复制健康、有效输出的合法单位 | 不复制巨兵、任务对象、召唤物与复制体；正常45法力等实际费用仍执行 |
| 满血前排无法提前使用保护 | 可对正在承受可见重击前摇的健康前排施放保护；白签清除控制、结束装填也计入用途 | 已有保护不重复施放；不对远处无战斗用途的单位消耗法力 |
| 重复束缚已被控制的目标 | 已束缚/眩晕目标跳过；定身同样避免重复定身 | 使用当前视野内敌军，没有额外敌情 |
| 持续场法术与普通单体控制缺少用途排序 | 敌军成团时提高伤害/状态区域价值；重击或致死前摇仍优先打断 | 实际对局仍存在法力提前花于单控而无法支付场法术的情况，预算问题未解决 |

上述改变不修改兵种价格、伤害、生命、特色能力、动作素材、道路或矿点。保留各阵营机制，再定位经济成本和机制收益，避免直接把弱院变成印甲换皮。

共同条件：双方300金币、两名初始工人、正常科技与付费生产、正式迷雾、AI预热0、60Hz模拟、150秒观察上限。每个条件包含三院对印甲的正反向六场；18场均完成观察。中图种子137，短/长图均种子271。源码指纹一致；短长图之间可以比较同种子条件，中图不能单独用于证明长度的因果影响。

## 回归与证据边界

tools/paper-warfront/check_ai_engagement.py运行五组原生Godot检查，54项通过，包含新交锋14项、原AI决策8项、投资8项、开局配兵4项、独立随机流20项。检查实际命令费用、保护与复制对象、合法献祭、前排恢复、重复制止；日志无SCRIPT ERROR，退出码全部0。新夹具首次使用了不存在的单位ID，已纠正为正式木拓巨兵，首次失败没有计为通过。

另补战役阶段导演4200项与地图决策45项，两组通过。旧地图检查首次失败8项：两项未侦察跨路攻击、六项旧3–5生产选项要求。这些夹具早于道路迷雾及六兵局内转型，不符合现行规则。失败记录保留于theatre-legacy-fixture-failures.json；新增合法侦察后验证跨路实际射程、超出射程不能命中，并新增无侦察不能跨路攻击的反例。六图生产选项检查改为六作战兵加工人七项，没有放宽正式视野、射程或科技规则。

检查器最终七组4299项通过，并验证18场记录完整且其模拟、AI、地图、科技与平衡指纹对应当前源码。报告：output/qa/godot/core-alignment-rc7/engagement-regression/report.json。4299是检查项数量，不是对局场数、真人平衡或Android硬件检查；报告passed只代表所列检查范围通过。

## 后续设计必须回答

1. 印甲45金币前排与纸械125、白签105金币前排的成本差，能否被低血增伤、法术吸收、驱散与组合收益偿还，而非只导致首轮兵量不足。
2. 木拓的自然修复需要脱离受击窗口，较慢前排和毒蚀后排是否能产生修复、控路、再交锋循环；不能只提高面板伤害。
3. AI应为关键区域/复制/保护保留多少法力，何时允许普通束缚消耗该预算；必须根据可见局势与已解锁工具箱决策。
4. 各院的研究成本、初始投资与增援距离需一起测量；先区分同资源的兵团效力与完整经济对局，再修改正式定义并同步资产版本与引用。
5. 修订后继续多种子、双侧、不同对手与短中长图检查，结合真人操作验证；当前样本不足以宣布十院平衡成立。
