# 出兵点堵截与守矿配兵修复

中图同暖机默认AI的只读工人命中时间线定位到配兵错误。两侧92.97秒转走桥路，存活守卫远在桥上。残留敌斧兵推进至基地出兵位置；东侧约132秒有足够购买毒种的62金币，但尚不足守卫70金币。即时经济威胁例外允许购买毒种，敌军占住出口，脆弱远程兵很快消失；工人继续在归仓途中被打，初始两工人及后补一工人最终全部失去。西侧则实际补到守卫，保留经济。

正式修复：已有“缺失近战前排”的恢复判断中，如果当前可见敌方近战处于基地实际出兵点的攻击距离加0.25范围，不再因迫近经济威胁放弃近战预算去买脆弱远程。仍等实际金币支付守卫，不免费出兵、不跳过生产。离开出兵点的迫近威胁继续允许原来的便宜兵应急。自定义敌方出兵入口暂不套用基地出口判断，避免把入口猜错。
