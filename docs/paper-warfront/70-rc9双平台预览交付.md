# rc9双平台预览交付

3.0.0-rc9-preview已导出Windows EXE/ZIP与Android APK。此前66–69的寻敌调优、实际开火后1.5秒来源揭示、AI守矿应急反制，以及工人遇袭文字/警报/小地图标记现在进入预览程序。那些章节的“尚未导出”描述保留当时历史范围；不是本版当前状态。

## 构建与检查

| 范围 | 证据 |
| --- | --- |
| 当前玩法机制 | 29组12307项原生机制回归与十二场正常付费来源核验通过；当前对应源文件指纹复核一致 |
| Windows实际程序 | 六个菜单/战斗/手机/小屏/异形屏/平板场景启动、截图与日志通过，菜单和小屏实际截图已查看 |
| 触控与布局 | 八种Windows原生注入屏幕/密度/安全区配置全部通过，合计23641项；不等于Android硬件验收 |
| Android安装包 | 原生导出成功，现有签名、ZIP16KB和ARM64 ELF段16KB对齐检查通过；包名org.paperwarfront.game、版本号30008 |
| 内嵌数据 | APK内19份数据JSON与构建源码字节哈希一致；asset-inventory和library-definition按既有导出规则排除 |
| Windows打包 | 最终ZIP通过CRC和内嵌EXE哈希检查，包含许可证与兼容启动脚本，未包含本地签名文件 |
| 构建来源 | 导出前后全部公开构建输入不变；最终preview-verification记录指纹及验收边界 |

通过运行模板检查没有证明Android真机输入、实时帧率或跨设备真人联机；整体阵营与200关逐关平衡也未完成。新告警属于反馈改动，十二场正常付费对局的胜负、经济统计和采样时间线未因此改变。

尝试用外部--script夹具在实际EXE内直接触发告警没有执行夹具或产出报告，60秒超时后受控进程已结束，未计通过。失败记录actual-alarm/external-fixture-result.json保留。专门告警画面仍使用此前源项目GPU检查，构建源码哈希证明其进入本版；六个标准实际EXE场景是独立通过的证据，不能混称专门告警导出验收。
