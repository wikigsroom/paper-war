# 折纸 UI 素材与风格调优 · 3.0.0-rc16-preview

本轮将纯色圆角控件替换为真实生成、加工并接入 Godot 的折纸控件。延续暖纸、墨线、纤维、朱印和玉青，战斗 HUD 沿用 rc15 的紧凑布局。菜单、兵书、战役、遭遇战、任务简报、科技、建造、队列、暂停、设置、胜负结算以及本机／局域网共享面板使用统一主题。

## 素材与加工

用户指定的 `sub2-image-gen`、`gpt-image-2.5` 实际生成三张源图：按钮、面板、图标。源图及原始提示词保存在 `output/imagegen/paper-warfront/ui-rc16/`。图标源图实际为1254×1254，另两张1536×1024；加工按实际尺寸切分，不假定服务严格遵守请求尺寸。

正式库有38项资源：8种按钮面、4种面板、16个功能图标、9个开关／滑块／箭头加工件和1个适用于红色主按钮的浅色旗帜。原图存在轻微格位偏移，按钮按经检查的空隙裁切；透明背景保留实际Alpha，恢复纸面实心区域。折角完整压入12像素固定切片，避免拉伸时出现长折痕和边缘变形。文字不写进图片，仍由原生 Label／Button 绘制。

| 资源 | 运行尺寸 | 使用规则 |
| --- | --- | --- |
| 按钮面 | 384×104 | 九宫格伸缩，折角与边线固定，中心随控件展开 |
| 纸页／卡片／墨纸／玉青面板 | 384×240 | 弹窗与卡片采用纸页，薄 HUD 带采用安静的卡纸 |
| 功能图标 | 64×64 | 菜单、资源、军令入口与结算；不增加 HUD 高度 |
| 开关 | 30×30 | 图像是状态指示，完整点击目标仍至少48dp |
| 滑块柄 | 24×24 | 保留原生 Range、鼠标、键盘与触控值变化 |
| 箭头 | 20×20 | 下拉与滚动方向匹配 |

素材定义与版本为 `assets/paper-warfront/ui/paper-ui.json`；Godot 运行副本为 `game/data/paper-ui.json`。独立 PNG 位于 `assets/paper-warfront/ui/paper/` 与 `game/assets/ui/paper/`。`prepare_paper_ui.py` 可复现加工，`processing-record.json` 记录源图、提示词、格位、切片、尺寸、稳定 ID 与哈希。网关配置和密钥不进入这些记录。

新增运行 PNG 共771832字节；未计 mipmap 的 RGBA8 解码体积约3MB。这是资源体积统计，不代表 Android 真机帧率或显存测量。

## 统一状态与交互约束

| 状态 | 视觉 | 交互 |
| --- | --- | --- |
| 普通 | 暖白纸、墨褐细边、折角 | 原生按钮、中文文字与工具提示 |
| 悬停 | 玉青边与纸角 | 保留成本与操作文字；手机使用按下反馈 |
| 按下 | 墨纸或更深朱印、浅色文字 | 实际持按状态可见；松开按现有规则执行 |
| 主行动 | 朱印、浅色旗帜与文字 | 继续、开战与确认使用同一视觉层级 |
| 已选择 | 玉青纸框／描边 | 法术进入目标选择，军令提供取消 |
| 禁用／未解锁 | 灰纸、淡头像、锁／前置文字 | 禁用原生操作；未解锁招募仍由模拟拒绝收费 |
| 键盘焦点 | 玉青／金色清晰框线 | 不依赖悬停，不移除模态控件的焦点提示 |
| 队列／冷却／生产 | 朱印数字、倒计时、玉青进度 | 数字与图形一起表达，不能只靠颜色 |

共享主题位于 `ui_theme.gd`。开关使用 Godot 4.7.2 的 `checked/unchecked` 及镜像、禁用图标接口；不沿用已不生效的旧图标名称。卡片在各布局中共用同一底材，避免原生 Button 与自绘纸框重叠。纸边、焦点和阴影全部限制在控件矩形内，不向战场扩张。滚动、长按详情、8dp拖动取消点按、军令与退款逻辑保留。

布局遵照[交互与 UI 规范](07-交互与UI规范.md)。默认收起的战斗画面扣除全部常驻 UI 后，桌面83.78%，移动已测配置70.62%–80.95%；主动展开的模态详情单独计。48dp目标、8dp间隔与安全区继续执行。UI/UX 技能的键盘焦点与触控建议作为检查依据，纸艺美术方向遵照本项目规范。

## 原生检查与交付范围

`paper_ui_qa.gd` 在桌面与手机各检查21个界面／状态，合计98项：38资源加载、键盘焦点、实际持按、禁用输入拒绝、设置开关和滑块、法术选中、真实招募付款、科技可达及战场占比。截图是原生游戏运行截图；生成素材板不作为游戏可玩或性能证据。

Windows EXE 与 Android APK 已使用 Godot 4.7.2 原生导出，并完成下表检查。Android 当前缺少连接的实体设备；密度和安全区注入的 Windows 检查不能替代 Android OS、ARM、GPU 与触控硬件验收。
