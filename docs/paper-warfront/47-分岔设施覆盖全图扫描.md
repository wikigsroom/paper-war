# 分岔设施覆盖全图扫描

继46，不假设道路风险修复必然导致改道，扫描200张正式地图的敌方合法塔位与分岔。共有60张图具有该组合，110组塔位/分岔/方向关系：全部各路都有某一段位于塔射程内，没有任一路完全不受该塔覆盖的组合。此项是实际折线/正式位置的原生几何观察，不是付费建塔、完整对局或真人体验。

这说明不能从当前塔位直接验收“通过完全避开塔火力的另一条路改道”。但各路都受覆盖不等于受击时长、道路长度或整个地图战术价值相同，不能据此断言地图缺少所有路线差异。

增加约0.1道路单位的中点采样，估算每路落在4.3射程圆内的长度，输出全部110组exposure_cases。map.01.04西侧进攻所面对的东塔，主路长度16、火力覆盖约4.3；桥路长度17.981、覆盖约4.296。不同路的绕行仍可改变遇到的守軍/控制/经济对象，不能把近似同一塔暴露误说成整个路线等价。采样有误差，不是精确射击次数。

后续应按覆盖长度、单位移速与预计承伤评估穿越成本，并在塔位、桥高和分岔距离确有差异的试验图上验证机制，再决定正式地图调整。本轮没有根据零个“完全不覆盖”案例就批量改写地图。

全图采样中18组两路覆盖长度相差超过0.5单位，最大相差约5.583单位，说明当前地图已有部分可利用的暴露差异；下一步优先让路线策略识别这些已有差异，而非先添加更多塔位。该差异仍需结合道路总长和交战阻滞解释，不能直接当作实际收益。
