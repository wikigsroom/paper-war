# 付费混编推进与攻坚验证

## 从静止靶场转为实际投资

74确认混编站位修复，但静止靶场不能证明真实研究、生产和推进收益。本轮增加纸商、白签、木拓三种实际投资配方，在短/中/长图交换双方侧位，分别对照当前阵型和测试子类恢复的旧同兵种分组算法。18组配对、36次原生运行。

双方正常300金币、40法力和两个工人，保留采矿归仓、科技前置和等待、FIFO生产、自动行军、真实武器和正式迷雾。己方不施法、不建塔、不生成免费部队；敌方在配方第二种兵实际生产后，真实付费生产三名印甲斧兵。观察上限180秒。波次由测试导演触发，不是有持续招募/反制的AI，也不代表人类对局。

| 配方 | 科技投资 | 实际购买顺序 |
| --- | --- | --- |
| 纸商 | 按前置链研究攻城兵 | 前排、攻城兵、弓手、弓手 |
| 白签 | 校书科技 | 镜卫、校书、连弩、连弩 |
| 木拓 | 守卫及医师科技 | 守卫前排、看仓守卫、医师、毒种 |

命令逐次检查真实资源和解锁，不能支付则等待归仓收入；研究全部完成后才购买配方兵团。所有配对的科技与招募支付时间逐项一致，没有通过给新规则更多钱、更早补兵或推迟敌方波次制造收益。分析器核验金币守恒、节点费用/前置/完整研究时间、实际出生与FIFO生产时长，以及三名敌兵购买数量。

## 已验证的攻坚收益

木拓配方实际支付494金币，其中研究149、部队345；初始300不足，余款必须靠工人归仓。该投资不是494金币瞬间预组开局。

| 图与木拓侧位 | 旧同兵种阵型 | 当前混编阵型 |
| --- | --- | --- |
| 短图西侧 | 180秒未决，敌城280生命 | 178.92秒摧毁敌城 |
| 短图东侧 | 180秒未决，敌城260生命 | 177.65秒摧毁敌城 |
| 中图西侧 | 180秒未决，敌城282生命 | 178.73秒摧毁敌城 |
| 中图东侧 | 180秒未决，敌城282生命 | 178.55秒摧毁敌城 |
| 长图西侧 | 180秒未决，敌城790生命 | 180秒未决，敌城406生命 |
| 长图东侧 | 180秒未决，敌城790生命 | 180秒未决，敌城406生命 |

六组木拓均保留两名工人。短图西侧医师在约72.53秒实际出生；旧规则全场只开火/命中两次，没有攻击建筑；修复后开火/命中38次，其中35次实际命中建筑。两者治疗统计同为71。收益主要体现为医师能进入合法攻坚位置并贡献输出，不能称治疗数值被提高。首次建筑命中由约116.88秒变为115.97秒，主要城伤差异来自其后持续输出。

旧规则未决仅意味着180秒观察期内没有获胜，不证明它永远不能拆城。当前长图仍未完成胜利，不能把增加城伤视为完整反扑闭环。

## 仍然存在的投资问题

白签六组新旧摘要完全一致：短图敌城剩11生命，中图剩44，长图西侧剩440、东侧仍1100，均未决。纸商同样一致：短图两侧及中图西侧败北，最后一名弓手尚未买到；中图东侧虽然购齐部队并造成城伤，但已失去工人；长图两侧未决。

因此混编修复不是所有投资配方的普遍加强。纸商部分局面尚未完成兵团投入就丢失经济，白签仍需补齐推进/攻坚投入与持续压力下的前排。下一步需要对照持续增援、手动法术反制和科技投资窗口，保留当前真实付费与迷雾边界。

## 证据与边界

- game/tests/probe_paid_mixed_push.gd：三配方的实际付费研究/招募和攻击、命中、城伤记录。
- game/tests/reference_homogeneous_formation.gd：仅恢复旧成团计算的隔离子类；不是旧EXE或全部旧代码。experimental_legacy_formation明确标记，正式来源检查拒绝该实验。
- tools/paper-warfront/analyze_paid_mixed_push.py：18组配对的投入、时序、来源及结果验证，已通过。
- output/qa/godot/core-alignment-rc9/paid-mixed-push-summary.json及paid-mixed-push-{mu|bai|yuan}-{legacy|current}.json：本轮有效证据。

第一版命中记录误将事件受击方side当作攻击方，已更正为attacker_side，并使用事件building字段记录包括致死在内的建筑命中；错误结果保存为invalid-hit-observer，不参与结论。当前36次日志没有脚本错误，相关源码/数据哈希核验通过。

本轮未改数值或AI，增加了混编修复在真实付费推进中的有效证据。74的12542项机制回归与十二场正常AI来源记录仍是该阶段正式检查；本轮脚本波次不能替代全阵营平衡、200关通关、真人对战或Android真机验收。源码修复尚未进入已发布rc9 EXE/APK。
