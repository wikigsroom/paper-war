# 战场优先 UI · rc15-preview

核对日期：2026-10-11。用户要求对战常驻菜单占比降低，让70%以上的界面属于游戏画面。单人战役、遭遇战、联机控制面板和同屏对战均已采用紧凑布局。**3.0.0-rc15-preview已原生导出并完成包级核验**，Windows便携ZIP随附与发布目录相同的预览验证记录。

默认战斗状态按整个游戏视口计算净可见战场面积，扣除常驻栏、角落小地图和暂停／返回按钮与战场的交集。重叠区域取并集，不把被不透明菜单覆盖的背景算作可见战场。主动打开的军令、科技、队列、资料和暂停菜单属于展开状态，不计入默认收起状态的70%要求。场内单位、生命条、矿口、设施与道路标记属于游戏画面。

底部只有一排招募、五法术和军令／取消。手机兵卡目标仍至少48dp，卡间8dp；招募区支持原生横向滑动，开局偏好与工人优先，全院六兵加工人均可访问。滑动锁定后撤销子按钮点按，轻点只提交一次实际收费订单，长按打开完整资料。卡片保留价格、锁、冷却、队列数和生产进度。

金币、法力和时钟留在上栏；任务、研究和操作提示复用同一信息区域。城池、兵力、科技、建筑、完整队列、回城和追踪交锋集中在军令；选中法术或建筑时按钮直接变为取消。桌面保留1–7、Q/W/E/R/T、F、B、Esc快捷键。手机使用安全区全高；资料菜单保留页面边距和固定返回，长文可滚动阅读。安全高度不足320dp时，角落导航和暂停／返回移入军令。

道路、矿口和设施的文字标签按实际战场边缘收纳，远处路标不会吸附到屏幕上。桌面点击与移动端施法范围均按新的战场矩形处理，底部菜单间隙不再作为战场落点。
