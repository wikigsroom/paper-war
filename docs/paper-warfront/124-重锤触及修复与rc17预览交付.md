# 重锤触及修复与 rc17 双平台预览

压印重锤卫的正式攻击距离从0.82调整为1.25，能够在一名折斧兵后方落印重击。原价95金、66金研究、5秒研究、2.4秒生产、34伤害、0.55秒打断与0.85范围打击继续构成它的方印重锤机制。折纸 UI 延续用户指定 sub2-image-gen / gpt-image-2.5 的38项已生成资源，资产库保留其rc16生成版本，游戏程序为rc17。

## 修复依据与正式输入

正常对手的R8采矿扩张试验中，殷折真实支付并生产出重锤，但它在城前停止，未产生攻击命中。原生位置采样显示：折斧兵在目标前约0.642处，重锤受0.54友军间距约束，接敌距离约1.182，超过0.82。

重锤已有双手举方印、落印范围重击与打断的独特装备和36格整身动作。调整触及距离使这个机制能够在第二排释放。角色位图、攻击规则与生成提示词分别保存；伤害、施法和迷雾继续由战斗模拟判定。

稳定ID为`unit.yin.hammer`。运行数据、正式定义、兵种简报、CSV、设计生成器及两份兵种文档已同步，修订记录见[rc17-hammer-reach-r1](../../assets/paper-warfront/balance-revisions/rc17-hammer-reach-r1.json)。手机资料页显示“隔着前排落印重砸，范围打断；长前摇可被控制。”，两份内置字体覆盖全部新字形。

## 三种道路、两侧的实际付费配方

每侧300初始金币和两名初始工人。重锤方实际研究、招募一名45金折斧兵和一名95金重锤，共206金；对方实际招募六名45金折斧兵。对手AI、法术和追加订单关闭，正常运输、研究、生产、自动行军和正式迷雾运行，不摆放或生成作战兵。

另有六组城前持续接敌夹具：对方城堡生命延长为50000，以观察友军屏障是否使重锤长期停手；该夹具单独标注，不用于普通对手对战成绩。正式12组配方均直接读取默认1.25资源，未注入正式范围；旧0.82和试验1.25作为24组独立覆盖对照。真实费用、研究完成、生产UID、收入账目与敌我受击事件逐组核对。

16项边界检查从正式分支2项失败变为全部通过。该检查先正常支付和生产，再用受控摆位复现记录的1.182距离，与正常行军配方分别标明。友军没有因接触或范围落印扣血。

## 原生动作与界面

桌面1280×720、注入手机布局1136×640各捕获18帧第一轮动作，包括举锤前摇、下砸、落印和收招；完整普通端点配方各有26次命中。手机资料、纸按钮和文字已目视检查。捕获按离线抽帧执行，不作为实时性能或 Android 设备证据。
