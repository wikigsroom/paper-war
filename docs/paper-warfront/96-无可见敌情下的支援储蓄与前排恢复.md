# 无可见敌情下的支援储蓄与前排恢复

一秒采样的正常付费短东候选时间线确认：31.22秒购买医师研究后仅余12金币；32.62秒附近最后前排死亡。54–55秒收入达到68–84金币，已足够70金币守卫，却因没有可见敌人、支援计划仍有效而继续保存110金币医师预算。到63.07秒才购买守卫，66秒后计划到期；医师没有招募。不能把没有可见敌人等同于己方阵型安全。

候选修正：experimental_ai_deployment_commitment开启时，非前排部署计划且己方现存/排队前排数为0，优先真实付款恢复最便宜已解锁前排，不让支援储蓄阻止该订单。只读己方阵型及合法情报，不使用隐藏敌人。正式默认仍关闭候选，原有资金/分阶段试验不受此修正影响。

双侧实际付款及出仓4项通过；原联合预算22项、分阶段部署18项仍通过。正常付费短图双侧360秒观察，守卫均提前到54.62秒招募，但最终分别179.62秒、260.53秒失守，治疗仍0。相较前一候选242.47/307.98秒更差；不同夹具快照的历史对照不作为同哈希新配对。局部等待缺陷修复没有产生整体改善，不采用候选。

这进一步说明需在购买研究之前评估可持续的兵团与部署窗口；研究后再抢救前排只会重新分配紧张现金。下一步应基于正常运输入账、前排损耗和首次高级兵生产建立投资窗口，而非无期限储蓄或直接降价。

证据：output/qa/godot/core-alignment-rc13/exchange/commitment-plan-trace.json、commitment-screen-short.json；测试game/tests/test_deployment_screen.gd、test_funded_deployment.gd、test_staged_deployment.gd。本轮没有宣称完整机制回归或全阵营平衡通过，没有导出新程序。
