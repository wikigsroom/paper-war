# 美术风格圣经 · 3.0.0-rc21-preview

暖纸、墨线、纤维与折叠纸厚片统一舞台。十院共享材质语言，身体种类与装备必须不同；不要求树、虫、四足兽、机器、人形都用相同头身比例。印甲方形、墨骸破口、灯符中空、工坊齿轮、鸢纸羽翼、金契票币、植纤根叶、霜裁规尺、烬纸陶灰、空白镂孔组成不同轮廓。背景不生成假道路，装饰避开互动节点，实际路缘和桥梁遵从地图几何。

界面是纸片舞台的一部分：暖白纸页承载内容，朱印强调确认，玉青表示选中与法力，墨色表达文字与按下。折痕与纤维保持低对比，边角固定，中心清楚；不把正文写进素材，也不靠额外厚边、阴影或装饰扩大 HUD。菜单与战斗共享材质，战斗保持轻量。素材命名、版本、切片、状态和检查遵照[折纸 UI 约束](122-折纸UI素材与rc16风格调优.md)。

战场尺度以[1.1风格参数](../../assets/paper-warfront/style-tokens.json)为准：横向112、纵向64逻辑像素/世界单位，纸偶倍率0.78；单位头顶、血条、武器释放点和点选区域使用同一高度函数。桌面地表下保留战场高度20%的剖面，手机保留17%且至少52dp；手机纸工至少52dp、作战兵至少60dp。建筑、道路和土层围绕纸偶形成可读的地形空间。
