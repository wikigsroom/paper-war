# 白签保护收益与地图投资窗口

## 保护不是空耗

对短、中、长图的印甲/白签双侧六场付费正常AI对局进行只读追踪，费用、生产、研究、法力和视野均不修改。记录八次白签保护施放时的生命、可见攻击者、已有投射物及保护期间实际抵达的攻击；去掉附加记录后，六场完整结果和五秒时间线逐项复现当前正常基线。

八次保护各实际阻挡3–4次攻击，原始伤害合计40–64。短图两次施放时目标生命49.2、阻挡原始伤害56；长图两次生命32、阻挡原始伤害56。原始伤害不是扣除所有单位减伤后的生命收益，也不是移除保护后的死亡反事实，不能据此声称精确挽救了几次死亡。但这已否定“保护未挡住攻击、法力纯浪费”的归因。

## 提前研究不能全图套用

十二场额外观察分别在开局真实支付85金币、等待5秒研究校书，保留正常AI；第二组同时暂停复制。没有增加初始资源、法力供给或免费科技。结果如下，每格依次列白签东/西侧：

| 地图 | 正常基线 | 仅提前研究 | 提前研究并暂停复制 |
| --- | --- | --- | --- |
| 短图 | 110.63 / 110.78秒败北 | 108.88 / 109.00秒败北 | 两侧103.50秒败北 |
| 中图 | 两侧150秒未决 | 两侧150秒未决 | 114.05 / 114.63秒败北 |
| 长图 | 两侧121.55秒败北 | 两侧119.42秒败北 | 两侧150秒未决 |

最后一组长图实际施放一次清线和一次保护，东侧保留一名工人，西侧仍无工人。短、中图两种政策都没有兑现清线。这说明科技回法必须与现有前排、法术预算及道路时序共同设计；提前消费金币本身会损失兵团投资，不能无条件启用。

## 基于真实道路的候选策略

新增测试专用候选：只在白签、实际基地节点最短路至少50、开局可用金币至少235且未研究校书时，于第一次AI决策真实支付85研究；235保留两名75金币开局兵的预算。已支付该投资后，仅在可见作战敌兵形成至少两人的潜在区域目标、清线已解锁且冷却不超过1秒时，临时将60法力区域预算置于45法力复制之前；法力达到105时仍可复制，单个敌人或清线未就绪不屏蔽复制。原有紧急保护和控制规则保留。50和235是本作待调优参数，不是原作数值。

测试策略只读取公开地图、自己资源及合法视野内作战单位，不读取隐藏新兵。短、中图六组中的四组未启用投资，完整结果/时间线与基线一致。长图两侧从121.55秒败北变为150秒未决，东侧仍保留一名工人；第二种子137也复现上述结果。五秒采样在25秒首次记录到清线，不能将该采样点当作精确施放时刻。

继续对墨骸、灯符、木拓交换侧位扩测六组：

| 对手 | 正常政策 | 长图候选政策 |
| --- | --- | --- |
| 墨骸 | 白签约100.73 / 100.12秒胜利，均三工人 | 两侧150秒未决，均三工人 |
| 灯符 | 两侧未决，白签0 / 2工人 | 两侧未决，白签均三工人 |
| 木拓 | 两侧未决，白签均三工人 | 两侧未决，白签均三工人 |

候选改善部分经济保留，但失去原先对墨骸的两场完成胜利，未证明普遍更优，暂不进入默认AI。未决不是平局，保住工人也不等于已形成反攻。后续应将资源准备与推进机会同时纳入策略选择，验证攻方投资节奏、控制窗口和兵团存续，而非按单一存活时间采用政策。

## 验收证据隔离已修复

check_ai_engagement.py之前仅排除价格/兵种/战斗数值试验，未识别新策略标记。现在统一排除所有非空experimental_策略字段；地图试验仍仅走原有显式许可，不能借该许可接受策略试验。14个实际策略试验文件被识别排除，三份正常对局输入仍可接受。完整30组12350项机制回归及十二场正式付费来源核验通过，源码指纹检查前后一致。

新增追踪和候选模拟仅在game/tests中，不被正式场景加载。第一版追踪夹具漏判建筑无statuses、第一版道路候选误用只支持接邻道路的近战距离得到INF，均已修正；错误记录明确保留invalid-fixture/invalid-distance名称，不参与结果或通过证据。候选现在使用真实基地节点最短路径并拒绝非有限距离。

可复现分析：tools/paper-warfront/analyze_white_investment.py，验证八个保护窗口、十二场提前研究、六场地图候选及八组其他对手/种子配对。结果在output/qa/godot/core-alignment-rc9/white-investment-summary.json；正式回归在white-policy-regression/report.json。正式AI未采用候选，已发布rc9程序保持原构建；整体平衡、逐关体验及Android真机仍未完成。
