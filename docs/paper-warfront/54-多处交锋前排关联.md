# 多处交锋前排关联

后续55已将此策略改为默认关闭的实验选项，因正式对局表现更差。本文记录当时实现与结果，不是当前正式AI默认行为。

继53，修复一处有前排就掩盖另一处裸露后排的问题。每名非近战作战兵遇到当前可见、道路距离在其射程加3单位内的威胁时，检查是否有存活近战位于该后排到该敌军的道路之间，且距离后排不超过6单位。用道路距离和三角路径关系判断，不用同一x或全场前排计数替代。0.15路径容差及6单位为本作试验值，不是原作参数。

有未保护交锋时释放研究储蓄，允许按实际费用恢复最便宜已解锁前排。其他交锋的前排以及已经越过该敌军的前排不算保护；已排队前排防止重复补充。现有近身应急规则仍允许购买便宜兵，单位不新增停走/逆行指令，不读取隐藏威胁。

新增三项关联检查：其他交锋前排无效、同一敌军方向的近处前排有效、越过敌军的前排不算拦截。交锋检查共20项。

13组当前原生回归4742项全部通过，六场正常经济观察的完整性与当前源码指纹验证通过；日志无脚本错误，退出码均0。

六场正式纸桥种子137正常经济复测：木拓与纸械对墨骸正反向仍150秒未决；白签约132.48/131.45秒败北，较上轮150秒未决更差。因此不能把正确的局部保护判定包装为总体平衡提升。它改变双方投资和压力节奏，下一步需检查白签承担前排恢复成本后的经济、护盾/复制收益及反扑工具，而非继续无限添加通用AI阈值。

保护模型仍将所有非近战兵视作需要前排，未区分独立游击、越阵或特殊任务单位；对特殊兵团的需求应另测，不能宣称所有配置都已最佳。没有修改正式价格/伤害/地图，程序未重导出。

木拓观察末期城防200/220、无工人，较53的560/540也更差。当前暴露修复增加恢复前排倾向，但基础单位投入回报仍不足，下一轮须分析付费兵团与科技转型的收益，不把回归通过等同应当扩大这种补兵偏好。
