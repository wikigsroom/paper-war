# 正常开局资金优先级与科技兑现 · rc23

当前版本为 `3.0.0-rc23-preview`，Android版本代码 `30022`。本轮接续地图比例与分侧迷雾修复，检查拉开战场显示空间后，对手的采矿、补兵、设施与科技投入能否衔接。正式修改在 [tactical_ai.gd](../../game/scripts/tactical_ai.gd)，下载与核验范围见 [发布说明](../../release/3.0.0-rc23-preview/README.md)。

标准42世界单位地图约需2.94个桌面视窗，普通纸偶约124逻辑像素高、地表纸层150.8逻辑像素；横向112、纵向64逻辑像素/世界单位，纸偶倍率0.78。手机普通兵至少60dp、纸工52dp，巨型兵保留约40.8%的高度差。横向视窗容纳的世界距离减少，因此需要更多导航空间；实际道路和行军时序仍以地图、兵速与生产数据为准。全舞台雾幕、上下路独立侦察、合法情报导航及38项折纸UI继续使用 [130](130-迷雾呈现与地图比例修复及rc21交付.md) 和 [131](131-玩家视野与前线导航修复及rc22交付.md) 的规则。本轮没有新增位图生成。

| 已定位问题 | 正式处理 |
|---|---|
| 两兵、两工时为可选哨塔预留80金币，压住第三名纸工和补兵 | 可选哨塔等待三工开局目标满足；明确更低的关卡纸工目标仍被尊重 |
| 35金币纸工被通用70金币门槛挡住 | 按真实纸工价格检查付款；队列、兵团、当前威胁和投资保留条件照常生效 |
| 降低门槛后，纸工抢先消耗法力设施预算 | 在可选扩张之前识别尚未建设、合法可见的本方法力设施预算 |
| 关卡指定高级科技路径尚未保存意图，纸工先花掉研究费 | 在扩张之前选择可用的关卡研究路径前置并保留实际研究费用；仍需正常付款和计时 |

最终公开构建输入相对rc22仅改变AI脚本、工程版本和导出版本。R8实验的启用分支与正式AI源码逐字对应，见 [源码等价与差异记录](../../output/qa/godot/ai-redemption-rc23/formal-source/equivalence.json)。其他玩法脚本及正式JSON逐字一致；资源定义、兵价、初始160金币、纸工目标、矿运、生产、道路、视野与命中规则沿用此前正式内容。

新建的 [68项开局检查](../../game/tests/test_ai_economy_bootstrap.gd) 使用真实160金币、两名已付款战斗单位、实际采矿入账和35金币纸工生产，覆盖两侧与危险/储蓄边界。同一观察器在实际rc22 EXE复现12项失败，当前源码和两个实际编译包均通过。另有 [32项投资流程](../../game/tests/test_ai_bootstrap_investments.gd)，验证法力设施的55金币付款与施工、指定科技的66金币付款与五秒研究计时；对方AI在这些隔离流程关闭，它们不表示正常对局胜率。

第一次R5导出前的完整回归揭示了设施与关卡科技的预算竞争。相关 [失败回归](../../output/qa/godot/ai-redemption-rc23/formal-reach/regression-r5-failed/report.json) 和 [非交付导出](../../output/qa/godot/ai-redemption-rc23/r5-export-not-deliverable/status.json) 已保留。修正资金规划后，原设施和研究约束通过；旧哨塔用例调整为新的开局次序，并增加满足三工目标后仍能实际付款建塔的边界。最终完整回归为68组、15,436项全部通过。

正常付费对照使用冻结rc22脚本/数据，与其发布清单逐项核对，双方160金币、240秒上限、相同地图和种子，双侧AI预热为0以便配对。R8每局只改变一侧AI；实际发布的默认AI在两侧均执行修复。因此下面是单侧策略比较，不是人类玩家胜率或全部关卡的平衡验收。六个实验关闭的控制记录逐项完全一致；原始对局、付款、研究、出仓、伤亡和决策记录均保留。

科技兑现仍是核心缺口。独立rc22控制100局、合计200侧位共完成60笔高级单位研究，研究后对应招募为0，其中35笔仍有至少30秒窗口。最终R8中图100局合计完成79笔研究，同样没有随后对应订单。研究与招募使用不同评分，且下一项研究可能在首次高级兵资金积累前占用预算；增加纸工本身不能解决这个问题。

R6首次部署候选另行隔离观察，没有进入正式源码或成品。100个中图单侧条件产生18笔对应付款、15次首次出仓，但只有3名首次单位产生直接伤害贡献；医师造成8点伤害，有效治疗为0。相对经济修复R5，纸械对纸裁的一个条件由未决转败。记录见 [R6比较](../../output/qa/godot/ai-redemption-rc23/compare-grant-r6-matrix.json)。直接贡献仅统计首次实际生产单位的伤害、有效治疗或成功召唤，不覆盖所有光环效果；出仓、抵达与实际贡献分别记录。

长镰与重锤使用同一份最终源码回归证明，只执行并统计一次68组机制检查。APK编译逻辑由同一APK字节提取后在Windows Godot执行；手机检查注入密度、安全区与原生触控事件。Android实体OS/GPU、物理触控和硬件性能尚未执行。

同屏视窗观察的首次调用误将目录作为JSON文件路径，记录保留于 [输出错误](../../output/qa/godot/ai-redemption-rc23/release-final/duel-stage/observer-output-failure.json)；修正输出参数、隔离存档并增加明确失败退出后，10项几何检查通过。旧关节版资源工具在查询帮助时触发116ID静态断言，断言位于写入步骤之前；已补安全帮助入口。当前整帧动作以3263项动作契约、正式资源版本和原生配方为证据，旧工具不作为当前资产通过证明。

最终核验为发布目录的 [preview-verification.json](../../release/3.0.0-rc23-preview/preview-verification.json)，Windows ZIP随附同一记录。规则修订记录见 [rc23-ai-economy-bootstrap-r1.json](../../assets/paper-warfront/system-revisions/rc23-ai-economy-bootstrap-r1.json)。Android真机、原作同条件逐帧视野时序、200关逐关人工通关、整体阵营平衡和真人互战仍待验收；用户已确认暂无Android设备，本轮没有使用模拟器、WSL、Docker或其他虚拟化环境。
