# 支援抵达风险策略试验

新增默认关闭的 experimental_ai_support_arrival，仅配合科技兑现候选使用。估算现有FIFO等待、新医师生产和当前选路至己方前线的基础行军；从当前可见敌军的距离、基础伤害、攻击间隔与接近速度估算这段时间的持续风险。己方近战生命须留出20%余量，才优先兑现医师。隐藏敌军和隐藏生命变化不参与判断；无法估计出兵入口/己方前线时不提供可行判断。

这不是完整生存预测：未模拟双方互相击杀、护甲、控制、群体攻击、建筑火力或未来改道，也没有证明所有被评估前排都在同一选路。当前伤害近似可能过度保守；试验开关不得视为正式平衡完成。

同暖机三图双侧，当前同一组记录来源下重跑默认AI、原兑现候选与增加抵达判断候选，共18场。真实支付、双方金币、九敌订单、三波时序及三个原生日志核验通过。

抵达判断避免长图投入医师，但释放出的预算转向看仓守卫后仍不及默认AI推进；短图医师被延后，本组累计治疗为0，尽管最终胜利较默认提前。因此不能把拒绝迟到支援等同于找到正确投资，两个候选继续默认关闭。后续需要重新判断研究目的和释放预算后的兵团构成，并独立处理中图矿线问题。

18项科技兑现及新抵达边界机制检查通过，包括已知近身压力下不投资将崩溃的前排、隐藏敌人及隐藏生命变化不影响判断。完整回归入口已更新数量，但本轮尚未重跑整套。
