# 战役与任务执行规范

**用户最新要求：单机地图必须有配套剧情；不强制地图或战役线性。** 章内解锁以`campaign-flow.json`和实际完成ID为权威，旧predecessor/next_level链保留为历史顺序与兼容字段。200张地图中按剧情需要混用单主路、择一、并行调查、条件汇流和回访；当前合同记录50个分支节点、50个汇流节点，未走支线不会凭空完成。见[单机剧情地图与章内分支](136-单机剧情地图与章内分支.md)和[单机地图剧情合同与路线分支验收](147-单机地图剧情合同与路线分支验收.md)。新增或修改地图后运行`tools/paper-warfront/verify_story_map_contract.py`，确认地图、剧情、地理绑定和路线覆盖没有断裂。下方rc1“每胜开放下一关”规则已由schema3实际完成集合替代。

当前工程交付为 **3.0.0-rc37-preview**；本页保留任务目标和兼容字段说明。原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

十章每章20关保留章节因果与英雄对话，predecessor／next_level／story_flag原ID不重排；实际开放以`campaign-flow.json`的完成集合、分支和汇流条件为准。当前空间提示根据地图重写。各任务的胜败独立于敌基地是否已毁。

攻城看敌城生命；survive看城存活到duration；protect看指定实际塔位存活到duration；deliver_gold只看stats.gold_delivered；escort看唯一对象存活且经过交接锚点；intercept在移动跨过矿线时记失败，后续同tick死亡不撤销越线。

护送不能献弃／夺印／复印。目标恰位于边终点时，用经过节点记录识别跨段到达，死亡优先于完成。纸城死亡后不能继续招募，队列不出生；非攻城任务即使毁敌城，仍需完成显式目标。胜利原子保存下一关与证据旗，试演／遭遇战不写战役解锁。
