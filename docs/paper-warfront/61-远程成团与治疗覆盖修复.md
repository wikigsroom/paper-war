# 远程成团与治疗覆盖修复

## 已确认问题与规则更新

同射程远程兵原先在最大射程处停止，后排因友军间距停在射程之外，无法形成有效齐射。短射程治疗师也会被长射程后排挡住，无法接近前排。该问题直接破坏守矿成团与反扑，不应通过增加射程或降低价格掩盖。

当前模拟按己方同道路、同兵种的邻近队列安排远程停留位置，最多考虑后续四名队友。首发仍遵守真实武器射程；完成收招后可继续靠近，给后排留出射击空间。短射程远程/治疗单位可经过更长射程后排，仍遵守近战屏障间距。视野、伤害、生产时间和正式价格不变。
