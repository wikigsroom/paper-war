# rc6 与《剑与勇士 / HD》的核心玩法差距审计

审计日期：2026-10-10。对象：已交付 3.0.0-rc6 的运行源码及正式数据。参考范围为初代及 PC HD 基础玩法，不把二代、DLC 或其他移植版独有内容混入基准。本轮不修改正式玩法或重新导出游戏。

## 结论

当前已具备自动行军、运金、法力、研究、手动施法、塔位、分岔和基地攻防的骨架。核心差距是：局内临场科技应对被战前编组限制；手动法术的时机与空间作用不足；十阵营的兵种已有独特机制，但法术仍复用三套模板，资源依赖也被通用供给削弱；地图和关卡有真实数据，尚缺完整战术循环的平衡证据。可运行与逻辑检查通过不能证明已经达到原作的战略深度。

## 原作依据与证据边界

- [Ronimo 设计师开发复盘](https://www.gamedeveloper.com/audio/postmortem-ronimo-games-i-swords-soldiers-i-)：明确舍弃停兵、拖兵微操；维京升级、阿兹特克献祭、中国可摧毁设施构成不同的法力经济；为平衡删去矿工差异；先对战再扩展战役。
- [Nintendo 官方战术说明](https://www.nintendo.com/en-gb/Games/WiiWare/Swords-Soldiers-286811.html)：基础兵与法术组合、矿工区阻滞推进并使守方远程成团、狂怒与冰锤利用巨人出手窗口、毒气区域、反射/爆炸/传送等兵种行为。
- [开发者地图与平衡文章](https://joostdevblog.blogspot.com/2011/01/many-faces-of-balance-in-rts.html)：阵营内部多种有效战术；地图影响设施型阵营；以一张中型图作为平衡基准。
- [开发者关卡制作文章](https://joostdevblog.blogspot.com/2010/12/designing-levels-without-tools.html)：矿点、塔位、地表高度是实际关卡数据，与背景分层区分。
- [HD 官方商店说明](https://store.steampowered.com/app/63500/Swords_and_Soldiers_HD/)：战役、遭遇战、多人及高分挑战。

未运行原版进行逐帧对照，故原作具体金币数、生产间隔、所有法术冷却、矿工容量、地图坐标不作数值等同判断。初代官方资料用于建立机制基准；未确认的移植差异不写作 HD 事实。原作成就条件不直接等同主胜利条件。

## 已接近的部分

1. 购买后自动行军与自动攻击，无逐兵停走操作；玩家通过招募、研究、建造、施法和路线承诺影响局面。
2. 工人实际往返、采矿、卸货；敌人能杀工人，友军穿行不会扣血。收入来自归仓，不是独立发钱计时器。
3. 地表和路径执行真实位置：长度、运输路线、塔位、分岔与汇流会影响接敌和增援。
4. 尸体召唤、投射物反射、越阵、范围攻城、控制与远程协同已经有实际机制；不能再将所有兵种描述为换色模板。
5. 研究与出兵共同消耗金币，法术花法力，扩张与维持压力存在机会成本。

## 逐项差距

| 项目 | 当前实际行为 | 与基准体验的差距 | 判断/优先级 |
| --- | --- | --- | --- |
| 局内阵容与科技应对 | 每局 2–4 作战位，未带入兵种既不能研究也不能招募 | 遭遇巨兵、后排或设施威胁时，部分应对必须重开并换部署，不能通过局内投资转型 | 明确规则差异，P0 |
| 科技结构 | 112 节点，111 无前置，只有一条单前置；开局选中前两兵自动解锁 | 大量项目是独立购买清单，依赖链和关键投资转折弱 | 明确数据事实，P1；不以原作未测节点数作比较 |
| 狂怒与攻击时机 | fury 只让伤害乘 1.4，不改变 cooldown 或 windup | 原作官方描述的抢出手、冰锤冻结巨人窗口在这里缺少对应动作逻辑 | 原生探针确认，P0 |
| 持续区域法术 | poison 只中毒当时命中的单位；没有持续区域。stamp 是固定点延迟伤害，burst 是瞬时范围伤害 | 后续敌人进区不受毒雾影响，持续封路、等敌成团、逼迫推进等空间决策弱；缺少承担持续推进/清线职责的高阶法术 | 原生探针及源码确认，P0 |
| 十院法术不对称 | 50 定义重复三组五技能组合：yin/ji/qi/shuang；mo/mu/jin；deng/yuan/bai | 各院手动操作的解题方式相近。单位差异不能替代整个工具箱差异 | 明确数据/分支事实，P0 |
| 法力路径 | 全阵营无条件 .5/s；每院都有可建的产法力设施，灯符为1.1/s，其余.3/s；另有各院事件奖励 | 灯符失去设施后仍回法，墨骸不献祭也能积法；身份成立但依赖不强 | 原生探针确认供给，体验强度待平衡测量，P1 |
| 工人经济 | FIFO矿容量、自动收益估计、矿优先级、有限资源配置；纸械/鸢纸工速度与运量不同 | 增加原创经济复杂度和阵营—地图耦合。原作团队为平衡移除了矿工差异，故不应将这些额外规则宣称为对标完成度 | 明确原创差异，P1 |
| 生产与增援节奏 | 72 定义均无 production_seconds，运行默认全是2秒；单队列容量6，军团上限60、工人10 | 已有价格与移速差，但轻兵、重兵、支援的生产时间均相同。队列可能额外推迟买兵的前线响应 | 当前事实；原作生产数值未测，不判谁更快，P1 |
| 反扑与成团 | 最近目标、友军间距、范围攻击、矿工实体、支援优先、自动后撤均已执行 | 原作明确的“攻入矿区被拖住→守方远程成团→突破→攻方投资反制”尚无专门结果验收。主动后撤/支援优先还会改变队形成团方式 | 不是缺失系统，是闭环未验证，P0 |
| 地图功能 | 200记录、193几何，长度36–60；主路、有限分岔、矿点和塔位真实存在 | 缺少各图对接敌、回本、增援、设施法力优势与逆转窗口的稳定平衡测量。几何唯一不能证明战术唯一 | 保留重做成果，补战术验收，P0 |
| 关卡导演 | 六种胜利规则；相同AI按资源、人数、威胁和固定间隔选择行动 | 目标不同，但仍较依赖统一策略循环；定制敌方开局、阶段战术切换与单关教学的人工验证不足 | 不能认定200关已等价手工关卡，P1 |
| 操作连续性 | 桌面招募和法术同时呈现；移动端要切军阵/法术，科技/建造经军令菜单，打开时战斗继续 | 时机型策略在手机上多出切换成本；可能看懂窗口却来不及操作。尺寸达标不是操作节奏等价 | 明确界面路径，体验需真机，P1 |
| 玩家对抗 | 当前人类控制side0、side1为AI；没有联机、双人控制或分屏入口 | 无法复现 HD 的真人相互试探、反制和高水平对局；也缺少真人互战平衡依据 | 明确功能缺失，P2；先完善单局骨架 |
| 挑战深度 | 六挑战中五个仍以destroy_base胜利，另一个survive | 模式数量不等于独立规则/高分循环。需检查每个挑战是否改变玩家决策 | 数据事实，P2 |

## 原生补证

补充证据校准：原作官方说明也提到自动生成法力，因此“存在基础自然回法”本身不能判定为偏离原作。上表的法力问题应理解为当前供给来源的相对重要性尚待平衡测量，不能据无设施仍回法的探针断言原作必须零回法。[官方说明](https://www.nintendo.com/en-gb/Games/WiiWare/Swords-Soldiers-286811.html)

视野和地图长度的进一步调查见 [战争迷雾与交战长度深度审计](25-战争迷雾与交战长度深度审计.md)。本篇此前没有展开信息规则，不代表已确认原作没有战争迷雾。

检查脚本：game/tests/probe_reference_gaps.gd。报告：output/qa/godot/reference-gap-rc6/native-probes.json。四个受控场景均为当前实现观察，不是原作数值测量：

- 对正在前摇的重锤施狂怒，windup .4 与 cooldown 1.0 都不变。
- 毒雾施放时已有敌人中毒；随后在同一区域生成的敌人不中毒，scheduled 数为0。
- 灯符无任何设施时 mana_rate .5/s，零法力推进10秒后为5。
- 印甲默认四兵编组之外的护仓签盾兵，研究和招募都被运行规则拒绝。

## 为什么检查通过仍不足以称为对标完成

rc6 的30,600检查验证了局部机制、数据边界、绘制、输入与导出。它们没有回答：控制能否挽救一次巨兵攻击；矿工损失多久可恢复；前排牺牲能否让4–5远程形成反扑；慢兵与快兵是否都有有效时机；领先方能否被合理反制。对标验收应围绕这些局面，而不是继续累计资产或断言数量。

十院有90种有向跨阵营对局，加上同阵营共100种有向组合；地图和规则进一步扩大空间。目前不能把某一场AI胜利当作全阵营平衡证据。

## 建议下一轮实施顺序

1. P0：在常规对战提供完整院内兵种的局内研究/转型通路。保留2–4位作为快速栏或特定关卡限制，不能成为所有模式的硬屏障；不改变用户确认的每院6–8独特兵种规模。
2. P0：完善法术解题职责与时机：抢出手、持续危险区域、打断/保命、清线与反制。逐院写明经济投入、兵团弱点、主动法术如何补弱点，避免直接复制原作名称和素材。
3. P0：用一张中型基准图验收四个战术闭环：快攻压经济、守矿远程成团、巨兵推进与控制反制、科技/设施投资后反推。分别记录失败和成功条件。
4. P1：测金币回本、法力来源贡献、生产与增援时间，再调科技依赖、经济规则和地图位置；先证明单位组合有选择价值，才扩展地图调优。
5. P1：把单关教学与AI阶段策略写成可测设计；在真实手机验证招募—施法—导航连续操作。
6. P2：独立挑战规则及真人对战。网络同步、双人UI、存档/暂停规则需要单独工程验收。

建议对标目标：保留纸艺原创题材与十院单位特色，让每一局真正出现“观察对手→经济/科技取舍→形成兵团→手动法术扭转交锋→再投资反制”的循环。本次审计只提出调整建议，没有执行上述玩法变更。
