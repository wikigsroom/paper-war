# 守矿告警与移动反馈

## 玩家反馈缺口与修复

此前侦察提示只针对较贵敌兵，工人遭便宜兵袭击没有专门告警；普通受击音在距离镜头较远时被跳过。即使攻击源已按67开火揭示，正在看前线的玩家也可能没有注意到经济区失守。

真实敌对伤害落到工人时，受击方现在收到“纸工遇袭”提示、短促警报，以及小地图红色叹号。提示4秒，位置标记6秒，每侧告警至少间隔8秒。只记录己方受击发生位置，不传攻击者身份、位置或数量。发生致死伤害且当地视野随工人死亡消失时，仍保留己方已知事件，不把它当成敌情透视。

小地图标记不随工人或敌军移动；到期删除，不永久探索新区域。屏幕缩放只影响显示，不影响合法视野。检查手机截图时发现标记会随纸偶舞台缩小，现抵消舞台缩放，并按小地图边界限制位置；减少动态效果选项使用静止标记。标记不会抢占触摸、改变镜头、取消施法或自动暂停。

告警接入单人桌面/手机、分屏两侧和局域网对应玩家的文字反馈。网络投影只向受击方发布；对手即便看得到受击地点，也不会收到其私有告警。音效仍尊重静音、后台及现有警报限频。本轮没有新生成资产。
