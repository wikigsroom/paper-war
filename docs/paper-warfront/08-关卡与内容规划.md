# 关卡与内容规划

**最新约束：每张单机地图配套剧情，地图与章内推进允许线性或非线性，按故事和玩法选型。** 第一章20关逐关叙事与六组可选汇合路线见[单机剧情地图与章内分支](136-单机剧情地图与章内分支.md)。以下rc1内容保留早期空间基线；“线性故事”不再是全项目硬约束。

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

六张基准图分别验证基本对推、前沿经济、长援军窗口、阵地绕行、矿线阻击和护送接力。其余194关来自20种显式阶段简报与10种地域布局规则，200场景／193几何／140单线＋60分岔。

单线关卡通过矿距、塔位、回款、援军及对象窗口成立；分岔须有阵地、任务或经济用途。所有桥均保留可读汇流点，没有额外高地伤害。外矿服务速度与容量可以不同，回报必须结合实际往返，不能只比较每趟金量。

六任务为攻城、守城计时、保护指定设施、真实归仓、护送活体、矿线截击。线性故事保存前后关ID及证据旗；六图試演不推进战役。详细地图坐标、经济和设计意图在world/maps及redesign-3.0目录。
