# 阵营对局基准检查

后续当前源码的交锋决策修订及18场短中长图复测见[交锋决策与弱势阵营复测](37-交锋决策与弱势阵营复测.md)。本篇分批进行中描述保留历史记录，以后续完成段落为准；不能把旧100场视为最新AI的平衡证据。

目的：先控制地图与经济条件，再区分阵营强度、AI适配和左右侧偏差。不能把单一控制器胜率等同真人阵营胜率。

`probe_faction_matchups.gd`支持100种有向阵营组合，包含同阵营；每局同一图map.01.04、相同300初始金币、种子137、非完整科技开局、正常付费与150秒观察上限。两侧AI预热均为零，避免默认敌侧等待混入基准。报告包含基地血量、工人数、战兵数、研究、生产队列与经济/战斗统计，并记录模拟、AI、科技、平衡和地图指纹。每场完成即保存结果。

第一批00–09已完成：印甲在西侧赢九场，与鸢纸对局在150秒内未结束；同阵营印甲镜像由西側获胜。不能据此直接判定地图或阵营失衡，必须对照反向组合、重复种子和实际收入。

第二批10–19已完成：西侧墨骸四胜、五负、一场镜像未在观察期结束。反向墨骸/印甲由东侧印甲在85.4秒获胜。说明当前样本并非所有西侧固定胜利，但仍不足以直接修改正式兵种价格或伤害。

记录：`output/qa/godot/core-alignment-rc7/faction-matchups-00-09.json` 与 `faction-matchups-10-19.json`。20场完成。剩余80种组合继续检查，另外仍需短长地图、不同策略与种子；正式预览二进制不因添加探针而变化。

汇总工具 `analyze_faction_matchups.py`输出对局矩阵、覆盖量、正反向组合分类及镜像经济；拒绝混合不同源码、地图或种子，未完成组合保留pending，观察超时记unresolved，不计为平局。部分覆盖的胜率不可横向排名。

另做种子271的十院镜像，十场全部完成：九场150秒内未分胜负，鸢纸镜像西侧在138.65秒获胜。与种子137的多场西侧胜利明显不同，因此不能据固定种子推断必然侧别优势或直接削弱阵营。数据：`faction-mirrors-seed271.json`。当前继续分析配兵、工人保护及储蓄行为；原100组合批次仍须等待完成。

## 100组合已完成与随机流修订

旧版种子137的100组合已全部完成，汇总保存在 `faction-matchup-summary-before-ai-streams.json`。排除镜像后每院18场，木拓与白签0胜14负4未决，纸械0胜13负5未决；这属于当前AI基准的弱势信号，不是已证实的人类阵营强度结论。

源码已改为每侧独立AI随机流，共用初始种子但互不消耗对方的随机状态。20项检查验证独立性、实际付费招募不受对方随机数消耗影响、重开可重复与不同种子仍有变化；开局配兵4项和研究投资8项回归继续通过。新的种子137镜像探针已启动，记录 `faction-mirrors-independent137.json`，与旧源码矩阵分开分析。

该修订在开发源码中，已交付的rc7-preview二进制保持其原构建内容，未宣称包含本次更新。后续平衡需要在新随机流下复测，不能把旧版100场作为修改后数值的验证。

新种子137十院镜像复测已全部完成，十场均在150秒观察期未分胜负。旧版印甲、灯符、纸棘和青铃镜像的西侧快速胜利未再出现。这是随机流修订的受控证据，不说明所有位置完全对称，也不把镜像未决视为整体平衡完成。
