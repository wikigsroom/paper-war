# 首次支援部署与基础兵团恢复

先进行104候选的单侧消融：中型图seed137、300秒、正常付费/迷雾/研究。仅白签启用：东侧205.53秒败、西侧300秒未决；仅墨骸启用：白签东侧300秒未决、西侧199.10秒胜。四场与104最终配对拥有同一来源快照，证明白签退化不能仅归因于双方同时改变对手策略。原始资料为sequential-only-bai/mo及sequential-single-side-comparison.json，属于后述修正之前的历史快照。

白签时间线：28.43秒研究完成后，30–45秒只剩一名连弩，46.82秒补镜卫；50–75秒常只剩一名镜卫，却继续维持书记部署现金预留。基础战斗订单的间隔与组合改变，不能只因没有高级兵付款就认定候选没有影响。

修正默认关闭的顺序候选：非前排部署目标下，己方已存活及排队作战兵合计少于2时，允许先真实付款恢复第二名基础作战兵；目标保留，仍不继续下一项研究。缺前排恢复、可见紧急威胁优先规则保持。不是强制近战＋远程搭配，不读取隐藏敌情；只约束最小作战兵数量，不保证同路同交锋保护。

22项双侧机制通过，新增一名作战兵时支付第二名作战兵且保留部署目标。统一46组12834项机制回归通过，sequential-formation-regression/report.json来源输入与当前源码一致。
