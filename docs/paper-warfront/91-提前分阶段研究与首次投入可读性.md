# 提前分阶段研究与首次投入可读性 · rc12开发源码

## 当前可用改进

桌面兵卡资料与手机长按资料新增解锁并招募一兵的剩余金币、尚未完成的研究数量、最早出仓时间。已付款研究不再重复计入金币；已有生产队列与研究并行，因此等待取两者最大值再加新兵生产时间。其他正在进行的研究占用唯一研究槽，必须先等其结束。

这是当前状态的有条件估算：假设金币足额、研究即时连续衔接，不保证未来收入，不包含新命令、单位阻挡或前线变化。不包含已经排队的部队费用，不代表所有费用必须一次付款。到当前己方前线的基础行军另列，不把出仓当成到场。

正式玩法价格保持不变。当前资料在开发源码，rc11 EXE/APK尚未包含。

## 分阶段AI候选

新增默认关闭experimental_ai_staged_deployment，可指定单侧。已经实际付款的基础两兵后，允许在原15秒投资门槛前启动首次科技；研究前仅要求保留首次招募费的25%，后续收入须实际归仓才可付款。复用部署计划的预留、实际出兵、急迫守备与过期释放。

这不是免费解锁或免费支援。正常规则、价格与迷雾不变。提前投资不是永远正确，需同时验证兵团前排、治疗、经济和反扑。

## 对战实测

同seed271、300金币、2初始纸工、零暖机、150秒上限、三图双侧，只有木拓采用候选；对手保持默认完整AI。当前源码默认/候选12场来源核验通过。

医师研究约1.32秒开始、6.33秒完成；正常110金币售价下，短/中图约15.62秒招募、长图约18.22秒招募。医师确实出仓，短/长图治疗0、中图23；六场均败北，低于原基线的短图两败、中长图四场未决。因此保持关闭。

另做相同协议12场90金币医师售价试验，价格仅在试验数据中覆盖，不修改正式定义。短图累计治疗46、中图46、长图69，但六场仍全部败北；短图91.53/92.87秒、中图99.70/99.70秒、长图95.90/95.80秒。产生活动或治疗量不能代替有效攻防收益，降价也不进入正式资源。

该组证据显示：首轮医师投入占用的兵团/经济预算没有被治疗收益弥补，问题不限于到场迟到。后续应比较同预算前排、毒种与支援的实际交换收益，并结合手动法术保护窗口，不能继续以提前研究本身作为成功标准。

两组实测在新增只读资料估算之前完成，后者改变helper哈希；两组运行时的来源锁定有效，但不得将这些旧哈希称为当前源码完全相同的复测。估算没有改AI使用的front_distance/queued_seconds，是否保持对局摘要仍需新的实际运行验证，不以推断冒充证据。
