# 近战攻坚停留成本接入

继51实测修正50的匀速穿越模型。接近型前排的塔风险现包括道路暴露时间，以及按塔生命/单击建筑伤害向上取整的攻击次数，乘以兵种攻击间隔加前摇的估计停留时间。考虑建筑伤害倍率与前排物理减伤。当前可见活动塔传入真实可见生命，历史情报仅使用公开满生命定义，继续半权重和30秒衰减，不查询隐藏HP。

该模型仍是单兵保守估计：不计兵团合击、巨兵控制、残血增伤、自然修复、已有塔攻击冷却或塔被其他来源提前击毁；射程圆覆盖也不保证近战能从任意平行路段直接接触塔。没有改变正式兵种价格、生命、伤害、地图或视野。后续须按真实兵团与道路可接近性改进，不能把公式当作完整战斗预测。

19项信息/路径/守矿检查通过，包括可见残血塔成本下降、减速只增加接近暴露而不使拆塔耗时翻倍、无覆盖零风险。110组路线观察与50相比仍是历史塔0改道、明确可见夹具1改道；共同汇流塔对两条路都增加攻坚成本，因此不是所有参数调整都应该增加改道数。可见夹具关闭迷雾且人工放置建筑，只证明策略响应，不冒充付费对局。

13组当前原生回归4738项全部通过，六场正常经济观察的完整性与当前指纹验证通过；退出码均0、日志无脚本错误。

正式纸桥种子137六场正常经济/研究/迷雾观察仍150秒未决，尚未证明弱院恢复。此轮完成攻坚成本实现，下一步需转向兵团投资和真实阵地恢复，而非继续以同一共享塔地图改道数量追求表面成功。
