# 战前编组与科技

军库60种作战兵，每院6种。战前2–4作战位用于快捷开局偏好，常规对战在局内可研究部署本院完整6兵加纸工；选到高阶兵不免费解锁，开局基础两种，其余科技真实付款并完成等待才解锁。旧存档经迁移表归一化。

仅明确配置 `restrict_roster` 的特殊局才将招募和研究限制在所给编组；普通局默认不限制。运行依据为 `battle_sim.gd` 的 `quick_roster` 与完整 `roster`，当前验收边界见[实现现状](120-实现现状与未完成项.md)。原rc5“每局只能招募2–4兵”的描述已过时。
