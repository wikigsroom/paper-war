# 道路设施攻击覆盖评估

继45修复AI路线对建筑威胁的几何估计。原规则只看建筑是否距候选道路中点6单位内，遗漏长边的分岔/汇流端点塔，也可能把射程外的设施算作威胁。

现在逐段检查实际道路折线，计算建筑位置到每段最近点的二维距离，与建筑正式射程比较。当前可见建筑和历史建筑记忆使用同一覆盖判断；非攻击设施不增加火力风险。实际塔攻击也采用二维物理距离，这里不是用视野半径代替攻击射程，不改变战争迷雾揭示或盲放权限。

历史情报仍只读取历史位置、ID、时间和公开定义，不查询隐藏实时状态；当前可见塔仍按可见生命估计投入风险，历史信息仍30秒衰减。地图折线、塔位、射程、伤害和价格未改。覆盖判断目前是有/无，未按覆盖道路长度、预计受击次数或单位生命估算完整穿越成本，不能称最优路径策略。

新增四项几何检查：汇流塔覆盖桥端、分岔塔覆盖道路起点、横向相同但垂直射程外不算风险、无攻击法力设施不算风险。连同历史记忆五项，共九项通过。

13组当前原生回归4728项全部通过，六场正常经济观察的完整性和当前输入指纹验证通过，退出码均0、日志无脚本错误。

正常纸桥图种子137六场再次观察，均150秒未决。该图汇流端塔可能同时覆盖主路和桥路，正确计算共享威胁不意味着AI一定改道，也不证明木拓/白签恢复经济或形成反扑。下一步需在道路覆盖确实不同的地图和当前可见/历史情报条件下验证路线选择收益，再与重建阵地和增援窗口联动。
