# 十阵营设定

当前正式运行每阵营6种作战兵，各自有机制、剪影和动作设计，另有运金纸工与临时召物。旧40种模板不作为当前招募规模。数值与能力设计属于本作，不声称是原作规则；实际定义以`game/data/balance-prototype.json`为准。

## 印甲军 / 朱印疆

统帅：赤砚，守印将军。

祖印碎裂后，印甲军封锁运输线。赤砚奉命收回失印，却发现被查封的村落仍在执行伪造王命。

选择冲突：守住秩序，还是承认自己保护的印令已经被篡改。

经济机制：upgrade；军团特性：fortified。造型：朱印、方甲、铜签、封缄。

本章结局：赤砚解除封路，把第一片祖印交给原本被视为敌人的拾纸祭司。

## 墨骸社 / 旧册泽

统帅：墨归，拾纸祭司。

墨归从废纸坑召回被抹去的守城兵，他们共同指认死亡名单先于战斗印好。墨骸社因此追查命令的来源。

选择冲突：让亡者作证，还是把他们再次当成可以献弃的兵力。

经济机制：sacrifice；军团特性：lifesteal。造型：旧纸、骨折、墨斑、尖刃。

本章结局：墨归送回被夺印的活人，留下不能再被复制的原始死亡名单。

## 灯符朝 / 青灯都

统帅：灯照，校符使。

朝廷同一日发出互相冲突的两份王命。灯照检查纸灯网络，发现真正的王印被无限复印的命令掩盖。

选择冲突：维持灯网供给，还是公开会令朝廷崩溃的副本证据。

经济机制：facility；军团特性：ward。造型：青灯、圆符、镜纸、复印纹。

本章结局：灯照切断伪令灯阵，保住供民间使用的灯网，并承认没有任何印令可以替代证词。

## 纸械工坊 / 铜折炉

统帅：榫七，总装匠。

工坊为十院制造印机，却被告知所有故障都源于工人怠惰。榫七在停转矿炉里发现人为更改的生产顺序。

选择冲突：继续交付战争机器，还是让停工的工人掌握自己的运输线。

经济机制：construction；军团特性：workshop。造型：铜色纸机、齿轮折线、卷轴车。

本章结局：榫七拆除覆写机的送料结构，将可以修复祖印的榫接图交给鸢纸行会。

## 鸢纸行会 / 雁信岭

统帅：飞笺，领信人。

唯一能串联十院的雁路被相互矛盾的通行符封死。飞笺必须把目击者和榫接图送过被截断的汇流口。

选择冲突：快速送信完成契约，还是冒险带上拖慢队伍的人。

经济机制：junction；军团特性：junction_haste。造型：蓝羽、折翼、风袋、信筒。

本章结局：飞笺公开雁路时刻表，拒绝再替任何一院秘密封锁消息。

## 金契商盟 / 契金埠

统帅：契衡，行账人。

商盟掌握矿路与债契，却发现账面上越来越多的金币来自没有运金人的归仓记录。契衡追查被印出来的繁荣。

选择冲突：保住账面财富，还是承认财富建立在被注销的名字上。

经济机制：delivery；军团特性：bounty。造型：金契、票据、秤签、结绳。

本章结局：契衡烧毁强制债契，保留真实货运账，资助难民与活纸种子的运输。

## 植纤古庭 / 活纤林

统帅：纤枝，守根人。

古庭的活纸能保存未经印写的记忆，却正在被新王命的墨液侵蚀。纤枝沿根脉寻找旧约的原始载体。

选择冲突：隔绝外界保住古庭，还是让活纸成为所有人的记忆容器。

经济机制：growth；军团特性：regeneration。造型：纤维、叶纸、木纹、根脉。

本章结局：纤枝将最后一株活纸交给十院共同保管，不再把记忆锁在古庭内部。

## 霜裁守序 / 冻页台

统帅：霜律，解封裁官。

裁院把争议证词冻结，声称这样便不会再有战争。霜律发现被冻结的不是争议，而是被反复擦除的和平协定。

选择冲突：服从永远不变的裁定，还是让矛盾公开并承担判断的责任。

经济机制：control；军团特性：control_reward。造型：霜蓝、裁刀、冰页、方框。

本章结局：霜律解冻十院旧约，撤销所有以沉默代替证据的裁决。

## 烬纸流亡 / 余烬渡

统帅：烬禾，渡纸人。

印院战争后的难民被统一记录为灰烬。烬禾带着幸存者穿过旧战场，把十院收集的证据送到祖印核心。

选择冲突：靠愤怒摧毁所有印院，还是让每个幸存者获得自己的名字。

经济机制：damage；军团特性：last_stand。造型：炭边、橙火、补丁、残旗。

本章结局：烬禾阻止报复性焚城，带着十院证据和活纸抵达留白庭。

## 空白档案 / 留白庭

统帅：白匣，末任校档官。

白匣发现归零印以消除记忆阻止战争，又以同样的消除制造下一场战争。他必须在自己的档案军追捕下解开覆写程序。

选择冲突：接受无争议的空白世界，还是保留真实且不能被统一的记忆。

经济机制：research；军团特性：arcane_resistance。造型：象牙白、灰紫、空框、删改印。

本章结局：十院拆解归零印，将祖印改为只能共同见证、不能覆写个人记忆的留名印。战场成为可读的旧页，而不是被抹去的历史。
