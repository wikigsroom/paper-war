## 玩家体验

玩家像纸偶剧场的指挥者：选择少量互补军团，投资运输/研究/塔灯，在自动行军的交战窗口使用法术，保护任务对象或突破敌方纸城。开局能直接出兵，30秒内能看到运输回款、对手压力和至少一次可改变交换的施法机会。

单局2–4个作战兵加1工人，共3–5个生产选择。工人也计入上限。规则层、AI、战前部署、存档迁移、HUD和所有200战役均执行同一限制，不能只隐藏多余按钮。四十兵的军库继续提供战前替换与后续开放，局内不扩成四十项生产菜单。

战术角色清晰：前排承伤/接敌、远程安全输出、阵营特色辅助/突击、重型破阵或攻城。战役逐步开放，法术初期聚焦救援/控制/打击，高级效果通过短研究加入。移除与本局少量兵种无关的多层兵法等待；研究必须仍有付费、时间和兵力机会成本。

## 风格与版式

选择有表情的卡通纸偶，正面大色块、明显剪影、纸边厚度、少量折线。人物头身比夸张，武器形状负责职责识别；降低写实纹理、细碎铠片和水墨背景的灰度淹没。背景饱和度与对比低于兵种，地面用真实连续切面与纸草边。

主色：纸光#FFF1D2、炭墨#292536、朱砂#D85840、金箔#FFCB4A、青釉#42A8A7、藤紫#7469B1。各院在此基础上换主要布色与造型，友敌身份另用旗标/描边和方向表达。正文用已有NotoSansSC粗字，标题用NotoSerifSC短题签；资源数字大于辅助文字，不引入无许可字体。

布局草案：

```
┌ 金币 / 法力       当前任务、时间          纸城生命 / 暂停 ┐
│             分层天空与远山；中心保留给战斗              │
│  纸城—近矿—守位—起伏主路—争夺空间—敌矿—敌城             │
│         必要关卡仅一个有实质取舍的局部分岔               │
├ 生产3–5项 ─ 研究/设施 ─ 法术 ─ 紧凑导航/队列             ┤
└────────────────────────────────────────────────────────┘
```

主标志是可读的纸路切面与活泼纸偶，周围界面服从战斗阅读。默认不开长说明或科技树。常驻UI桌面不超过约25%画面；横屏触屏生产与法术有明确分区/切换，不出现第二组隐藏生产兵种。所有状态都有费用、锁定原因、排队/冷却/研究进度和取消反馈。

## 地图结构

200图保持独立数据和故事ID，重新约束为多数连续单线地面、少量单个双出口分岔。每图有明确的基地后方经济、可保护的近矿、暴露前位、主战场和增援距离。分岔必须说明快路压力、外矿/塔位或护送的取舍，不用重复三路折线铺满屏幕。

地表起伏来自实际行军数据，坡与主路在渲染中形成实体切面；分支是可读的纸桥/台阶。地图长度、矿容量、塔位和任务锚点改变交战时机。禁止只换背景计图数，也不凭美术高差增加未定义的伤害规则。
