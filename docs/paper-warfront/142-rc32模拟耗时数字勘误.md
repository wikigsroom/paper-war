# rc32模拟耗时摘要数字勘误

rc32发布说明首段的模拟耗时降幅下限写为11.62%，应为 **11.61%**；完整范围为 **11.61%–12.61%**。原始数据和逐图表格正确，错误仅发生在首段摘要的数字转写。

| 地图 | 原始降幅 | 保留两位小数 |
|---|---:|---:|
| map.01.01 | 12.610846535218966% | 12.61% |
| map.01.04 | 11.614570890196163% | 11.61% |
| map.01.11 | 12.546058290600982% | 12.55% |

依据为[同进程模拟计时原始数据](../../output/qa/godot/contact-runtime-rc32/cpu-summary.json)。它记录的是三图各1200步、同一Windows原生进程中的交替对照，不能直接解释为实际帧率增益。

[原发布报告](141-密集寻敌与迷雾查询复核.md)、已核验程序、下载包和版本绑定记录保留原始归档字节。本补充不改变游戏、测试计数或实际帧率结果：正常场景约59.8–59.9 FPS，124单位压力场景约30.3 FPS；Android实体设备验证仍待完成。
