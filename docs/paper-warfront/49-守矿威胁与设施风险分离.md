# 守矿威胁与设施风险分离

继48发现，路线strength同时包括军队与塔风险，而守矿加权只判断strength>0。这让只有塔情报、没有实际袭矿敌军时也触发-3守矿偏好，产生看似改道但并非绕塔的选择。

守矿偏好现要求当前可见、存活、敌方单位在矿点同一道路，沿实际道路距矿点不超过6单位。历史塔、其他道路敌兵或隐藏敌兵不能触发。6单位为本作局部威胁试验值，不是原作参数；不修改生产、移速、视野、矿点或单位成本。

新增三项原生检查：历史塔不冒充袭矿者、当前可见近矿敌兵触发、失去当前视野即不触发。现建筑记忆/攻击覆盖/暴露长度/矿点威胁16项通过。

13组当前原生回归4735项全部通过，六场正常经济观察完整性与当前运行源码指纹通过验证，日志无脚本错误、退出码均0。

110组正式地图历史塔观察复跑，没有敌军袭矿时改道数由40降为0。必须据此修正48的解释：此前40组变化全部在本组输入下受错误守矿加权影响，不能把其中20组低暴露选择作为独立避塔机制成功证明。当前长度与切换代价仍压过风险权重，后续须按穿越时间和预计伤害校准，而不是重新加入错误守矿规则让测试出现改道。

正常纸桥种子137六场再观察，均150秒未决；未证明弱势阵营经济恢复。本轮只修改AI取舍，不凭这种未决宣称均衡。正式塔位、兵种与美术未改，Windows/Android未重新导出。
