# 研究生产与道路增援总响应信息

此前兵卡将首次出仓时间和基础行军时间分开列出，玩家仍需自行合算科技与增援是否来得及。当前正式源码新增reinforcement_seconds与reinforcement_notice，将尚需研究/现有FIFO/新兵生产与当前选路实际道路行军合为“到当前前线位置”的总时间参考，接入桌面兵卡及手机长按详情。未启用任何AI策略候选，未改变战斗、经济、地图或迷雾规则。

研究与已有生产并行，不将已有队列全部加到研究之后；沿用first_investment的真实前置、已付款研究剩余时间和新兵生产时间。行军段按当前选路存活己方作战兵最远位置计算，不读取敌方位置、血量或隐藏兵种。无己方前线/不支持标准出仓路线时不提供时间，工人显示采矿运输说明。

此为足额金币、连续研究、无阻挡/控制下抵达当前参考位置的估算，不是未来交锋时间。战线前进、后退、分岔改变、死亡与友军间距均可改变实际抵达；不可用此数值证明治疗有效或支援能够救场。界面明确标注“未计战线移动、阻挡或控制”。手机详情是打开时快照，不把它称为持续刷新。

双侧首次投入检查扩展至40项，通过真实FIFO下单、实际取消后的响应恢复、无己方前线拒绝、查询无副作用及敌军移动不影响信息等边界。统一51组12960项Windows原生机制回归通过，来源哈希匹配当前输入。

三配置原生GPU资料/队列UI共120项通过：桌面1280×720共26项，手机1280×720密度2共47项，紧凑手机1136×640密度2共47项。含真实队列付款/取消、旧重复订单按钮拒绝、刷新与退款，以及滚动后完整读取新估算。已目视检查紧凑手机实际截图，估算和假设文字可完整显示。Windows注入参数不是Android硬件验证。

实际验收截图中护仓签盾兵在当前FIFO下13.3秒出仓、到当前前线位置约27.3秒，清楚区分生产结束与增援参考响应。该数字只对应验收场景，不是原作数值或所有地图常数。
