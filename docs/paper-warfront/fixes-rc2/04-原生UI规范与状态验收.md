# 原生 UI 规范与状态验收 · 3.0.0-rc2

## 技能来源和采用范围

采用已加载的开源 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)、`frontend-design`、`game-studio:game-ui-frontend`。本机技能分别位于 `C:/Users/carzy/.codex/skills/ui-ux-pro-max/SKILL.md`、`frontend-design/SKILL.md` 和已安装 game-studio 插件。没有把未经核实的社区排名当作选型依据。

通用设计系统检索返回营销展示页和写实风，不适合即时策略 HUD；只采纳触控目标、反馈、焦点、可读性与游戏战区保护原则。所有界面仍由 Godot Control 绘制、布局和接收输入，未引入 React 或网页壳。

## 视觉约束

主概念是“统帅案头的军令卷”。菜单留白多、军令清楚；战场界面短、集中，中心留给对战。纸张暖白，深墨正文，朱印表示主行动，青玉表示焦点／选择，铜金表示经济。文本、禁用词、锁标记和进度补充颜色信息。

| Token | 色值 | 用途 |
| --- | --- | --- |
| PAPER／CARD | #F6EDDA／#FFF8E9 | 纸面／控件 |
| INK／MUTED | #24343C／#615B50 | 正文／次级文本 |
| SEAL | #A83C35 | 主行动、标题强调 |
| GOLD | #92682A | 可读的经济文字 |
| JADE | #31747C | 焦点、导航和研究状态 |
| CONTROL_EDGE | #978B73 | 控件边界 |
| DISABLED | #DDD4C2 | 禁用底色，继续保留文字说明 |

标题使用已有 Noto Serif SC，正文用 Noto Sans SC。按钮具备一致的纸边、轻阴影和折角。桌面按钮保留可见键盘焦点；战斗快捷键与点击共享同一公开指令，不依赖按钮抢夺焦点。文本带完整 tooltip 与语义名称，长标题允许省略而不挤出邻控件。

## 全流程界面

| 页面／状态 | 当前设计与行为 | 验收点 |
| --- | --- | --- |
| 主菜单 | 继续战役是唯一主要按钮，显示当前关名；战役／遭遇战／地图试演在上层，挑战／兵书／设置在次层 | 桌面／移动菜单所有按钮在边界内，主入口突出 |
| 战役 | 十章、每章二十关，按线性解锁浏览 | 第一与末章、已解锁与锁定状态 |
| 战前军令 | 目标、地图、军阵、预算与主行动按阅读次序呈现 | 简报页与真实路线预览 |
| 军阵 | 每局 2–4 战斗兵种，加纸工共 3–5 生产选项 | 选择、移除、保存和旧档迁移 |
| HUD | 上方金币／法力／时间／基地；下缘军阵、法术、小地图与辅助动作 | 十院 HUD、招募付费、生产进度、锁定／冷却 |
| 横屏 HUD | 军阵和法术两组切换，保留辅助动作、小地图 | 两组可操作，切换不会透传施法／招募 |
| 战场提示 | 目标或研究中出现短纸签；普通提示按时消退 | 常态 30 秒后不长期遮挡战线 |
| 纸工／矿 | 我／敌字样＋脚下色条，矿标我方／敌方、容量与等待人数 | 敌友可分辨，点矿可设置下次出发优先 |
| 科技 | 已完成、先修、价格、研究中明确展示 | 不能重复研究；其他研究进行中、资源不足或前置不满足时禁用 |
| 建造／选路 | 独立触区，合法位可见，设施付费在最终提交时发生 | 路标不误触建造，取消不扣费 |
| 队列 | 已付费项目和当前生产进度，退款动作对应实时索引 | 防队列变动造成错误退款 |
| 暂停／设置 | 纸面模态，遮罩隔离战场；音量、跟前线和减少动效 | 模态阻挡快捷键和战场输入，暂停冻结模拟 |
| 胜负 | 胜利推进；失败可直接重试或“调整部署再战” | 后者真正打开编组界面，不重复重试 |
| 兵书／鸣谢 | 独立纸面资料，减少背景视觉干扰 | 长内容不越界，返回链完整 |

减少动效关闭镜头震动和背景漂浮；采矿、攻受击与工作进度保留，因为它们传达游戏状态。移动菜单采用更大按钮和两列布局；桌面菜单增加当前军令卡。窗口横屏按 Godot canvas stretch 缩放，逻辑尺寸不是 Android dp。
