# 判定与采矿复查 · 3.0.0-rc2

## 复现与根因

没有在无敌军、普通付费纸矛手穿过纸工的基线中复现自动扣血，因此不把这次普通通行描述成已定位的单一故障。确实复现了伤害入口接受友军目标、策反后的旧弹道／旧持续伤害仍攻击新友军，以及绘制位置和判断位置偏离。修复覆盖这些真实问题，并对用户报告的普通通行补充持续回归。

| 入口／时机 | 修复前问题 | 当前规则 | 对应验证 |
| --- | --- | --- | --- |
| 最终伤害入口 | 调用方传入友军时仍可扣血 | `damage` 拒绝友军、死亡对象、非正数与非有限伤害 | 400 兵种错误友军目标、友方建筑、负数／NaN |
| 攻击与发射 | 旧目标可能成为友军 | `attack/launch` 先验证实际 `side` | 400 兵种友军拒绝与敌方纸工正向伤害 |
| 攻击前摇 | 策反后仍按旧目标释放 | 每个前摇步与实际释放重查目标归属 | 前摇中公开策反指令 |
| 飞行与命中 | 目标或发射者策反后仍按旧侧攻击 | 跟踪与命中重查归属；策反移除无效旧弹道 | 飞行中改侧、纸矛手策反后打新友方纸工 |
| 毒、燃烧与控制 | 新友军继续承受旧武器效果 | 状态存进攻侧及来源 UID，改侧后清理并逐次验证 | 受害者改侧、燃烧来源改侧 |
| 反射与范围攻击 | 间接攻击缺少统一最后保护 | 反射验证双方；范围攻击只枚举敌方，最后仍经伤害入口 | 正常反射、策反反射器、爆炸中的友军及货物 |
| 炮弹主目标死亡 | 在途范围炮弹直接消失 | 在最后有效落点爆炸；单体弹不凭空攻击其他对象 | 飞行中主目标死亡，旁敌受伤而友军不伤 |
| 矿工服务排队 | 尚未到达者的 `arrival=-1` 抢占服务槽 | 到达后参与 FIFO，时间相同按 UID | 十院等待者无服务进度／采矿事件 |
| 矿口站位 | 显示错位只在渲染层，范围落点不一致 | 模拟持有实际 `body_anchor`，战斗和显示共同使用 | 身体附近命中、空服务点不命中、弹道与飘字坐标 |
| 点纸工释放范围法术 | 预览身体，提交时仍取经济服务点 | 点击提交也使用 `physical_point`，与预览一致 | 桌面／移动布局注入真实指针，远离服务点的身体仍能命中 |
| 连锁效果 | 伤害筛选用身体，特效仍取服务坐标 | 连锁两端都使用身体位置 | 连锁伤害与两端事件坐标一致 |

友军可以穿行，不使用“碰到即扣血”规则。路径上的友方纸工不会拦截投射物。友方献祭是经过法术目标和消耗校验的独立玩法，工人不可献祭；复制体自然消失也不进入普通敌方伤害统计。

## 空间契约

`edge/s/x/y` 描述道路与经济服务位置。工人接近矿口时，模拟按照 FIFO 生成同一道路上的身体站位，平滑调整；返程恢复行进站位。`physical_anchor` 供沿路径近战距离使用，`physical_point` 供二维投射物与范围、点击画面和事件使用。桥上下保持真实图边与高度，不能通过图片重叠获得跨边近战。

矿服务锚点、身体站位和纯视觉肢体姿态各有用途。肢体摆动和几像素受击回弹不改变规则位置；队列站位会影响实际命中，因为它是模拟数据。身体站位不改变服务周期、矿容量、矿优先级或归仓入账。

## 十院运金状态机

| 状态 | 画面与反馈 | 规则 |
| --- | --- | --- |
| 赶路 | 行走双腿、工具随身体轻摆 | 沿实际边走到矿点 |
| 等待 | 立足矿后，持镐待机 | 不挥镐、不产生矿屑、不积累服务时间 |
| 采矿 | 肩臂独立举镐、快速落镐、身体弯曲、脚掌站稳、回收 | 占实际槽位，以 `job_time` 驱动周期 |
| 落镐事件 | 金／纸碎屑、短冲击音 | 由模拟 `mine_strike` 触发，不由绘制定时器发放资源 |
| 装袋 | 装货瞬间金币反馈，货物标记 | 服务完成才得到 cargo；这是短暂转换状态 |
| 回程 | 负重行走，标出载金数 | 经真实路程返回本方基地 |
| 卸货 | 弯腰放货、一秒服务进度 | 完成卸货才增加金币并记录归仓 |
| 受控／暂停 | 捆绑停止服务；暂停冻结工作相位和事件 | 不用待机动画冒充继续采矿 |

十院分别发布独立镐臂和去臂躯干，沿用原生生成的角色造型和双腿。不是十院共用一张替代角色，也不是宣称已有完整手绘逐帧动画。军队其他兵种仍沿用已有分层程序纸偶。
