# 3.0.0-rc2 修复与视觉设计约束

本次针对友军误伤、运金动作、地图质感和全流程 UI 修订。保留关卡路径、实际经济、每局 3–5 个生产选项、十院军阵与原生 Godot 架构。

## 战斗归属与空间

同侧单位可相互穿行，穿行不造成伤害。目标选择、蓄力释放、弹道落点、反射、范围伤害、持续伤害、命中附加能力均使用实际对战归属；美术阵营不决定敌友。归属变化后重新验证目标。友方献祭保留其独立规则，工人仍不能献祭或转换。

矿点 `edge/s/x/y` 是经济服务锚点；排队纸工额外持有沿同一道路的 `body_anchor`。瞄准、近战距离、范围筛选、弹道与死亡／命中事件统一经 `physical_point/physical_anchor` 读取身体位置；渲染使用同一个身体位置，不再由绘制层单独横移纸工。站位随 FIFO 顺序平滑过渡，不改变矿点容量、服务周期或实际运金归仓规则。装袋和返程恢复行走位置。

回归包括真实付费招募纸矛手与纸工的连续通行、400 兵种的无效友军目标、蓄力和弹道中的策反、毒伤归属变化、爆炸、反射及敌方正常攻击。报告记录实际伤害事件，避免把粒子覆盖友军画面当成扣血证据。

## 采矿动作

所有十院运金单位具备赶路、等待、采矿、装袋、负重回程、卸货状态。采矿动作绑定真实矿点服务时间与槽位，只有占用槽位的纸工挥镐；等待者在矿后排队。挥镐分举起、落镐、碎屑与回收四段，冲击音和矿屑来自模拟事件；暂停后动作冻结。金币仅在真实归仓时到账。

尚在接近矿口、`mine_arrived_at=-1` 的纸工不能参与服务名额排序；只有实际抵达服务锚点的纸工才按到达时间和 UID 取得槽位。

## 地图美术

采取厚纸切层舞台：远景浅、可走路缘亮、土层中性、近景深。主道路面严格来自实际路径折线。土层采用纸纤维纹理、错层纸边、断续地质片和少量根系；桥采用铺板、支架、接榫和护索。装饰回避矿点、建造位、分岔和目标旗，保持单位剪影与敌友标记可读。十地区分别使用草纸、墨岩、灯砂、机关灰、鸢丘、契绿、植根、霜纸、烬土与白卷配色；军院正式名称以 factions.json 为准。

## UI 设计体系

已读取本机 `ui-ux-pro-max`、`frontend-design` 与 `game-studio:game-ui-frontend`。前者为 [UI UX Pro Max 开源项目](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的本地技能；通用检索得到产品展示网页，与本项目游戏 HUD 不吻合，因此不采纳展示页结构。使用游戏 UI 技能的战场保护原则与经过检索的触控、反馈建议，转换为 Godot Control 实现。

视觉意图为「统帅案头的军令卷」：宣纸 #F6EDDA、深墨 #24343C、朱印 #A83C35、铜金 #92682A、青玉 #31747C、纸边 #C4B294。标题使用已有 Noto Serif SC，正文使用 Noto Sans SC。主行动为朱印按钮，次级行动为纸签；禁用、冷却、选中与研究中各有文字及形状反馈。对照图和截图必须为原生运行画面。

主菜单突出继续战役与自由对战，资料/设置归入次级区；二百关以章和关卡序列组织。战前军令优先呈现目标、路径缩略图与编组；HUD 保持中央战区开放，资源为顶部短条、军阵和法术为下缘军令、研究/建造/队列为辅助控制。新手说明和长期资料在暂停/兵书中展开，常态不覆盖战线。

桌面和横屏移动设备分别验收：触控区域、文字裁切、切换分组、输入穿透、暂停和返回、矿点优先级、路标/建筑点击以及完整的胜负/再战流程。实际 Android 设备手感与性能以真机验收为准。
