## 地形视觉分层

1. 远景沿用十地区生成纸山水，保持明度比角色高、细节比角色低。
2. 道路来自 `map_runtime.ground_y_at` 和实际路径折线，路缘以浅纸边、窄草／霜／岩帽界定。
3. 下方截面以纤维、破纸边、错层、石片和根系建立厚度，纹理 UV 跟随局部坡面，不把地图拉成平地。
4. 桥面按照真实 bridge 图边铺板；实际坡段安排接榫、支柱、护索和桥下阴影，不额外产生可走台阶。
5. 装饰保持稀疏、大小有差异，回避矿点、建造位、分岔和目标线；不以复杂前景遮挡兵种与攻受击反馈。

地图仍使用当前二百场景与 193 份几何。此次是可读性和舞台美术调整，不把同一几何的新配色计作新地图，也不声称增加了高地伤害加成。主路／桥路、矿容量、成本和距离由实际数据控制。

## 地区材质投影

| 地区 | 边缘材质 | 地面基调 |
| --- | --- | --- |
| 印甲军／灯符朝／鸢纸行会／烬纸流亡 | grass | 纸土、柔和绿边、暖铜或砂岩 |
| 墨骸社／纸械工坊／空白档案 | slate | 层叠冷岩纸、低饱和灰紫 |
| 金契商盟／植纤古庭 | forest | 苔草、纸根与中性林土 |
| 霜裁守序 | ice | 冰纸边、蓝灰岩截面、浅雪高光 |

配色以 `theatre_ground.PALETTES` 为实现依据。场景、兵种和 UI 的阵营身份各自独立：玩家可以操控不同军院；敌友判断以实际 side 为准。

## 生成与加工指导

生成提示词固定侧视正交、纸层材质、大形优先、无文字、无角色、无额外道路。纸纤维要求无显著方向、阴影或大物件，便于平铺和染色。边缘母图分四格，格内保留完整剪纸截面与透明边缘；禁止使用黑底截图替代透明材质。

[纤维提示词](../../../output/imagegen/paper-warfront/rc2/terrain-fiber.prompt.txt)与[截面提示词](../../../output/imagegen/paper-warfront/rc2/terrain-edge-atlas.prompt.txt)保存完整原文。裁切以原生 alpha 边界定位，去掉端帽避免明显拼接；每片保存 `walk_y`，路缘贴图不重复出现第二条地面。纤维压成浅灰再由运行时调色，避免原色污染十地区。

工人遮罩必须保留肩、握镐手、整支工具；躯干去除原静态工具头。全透明画布维持原 512 锚点，禁止对各部件自动居中。独立工具旋转绕各院肩枢轴，肩随躯干变换，双腿脚点稳定。
