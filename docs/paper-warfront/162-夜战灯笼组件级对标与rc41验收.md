# 夜战灯笼组件级对标与 rc41 验收

版本：`3.0.0-rc41-night-lantern-components`  · Godot `4.7.2`  · 日期：2026-10-15

本章把已选 UI 方向 03「夜战灯笼」从三张 Sub2 参考页拆成可检查的 Godot 组件合同。参考图只负责构图、材质、色彩和层级，中文文字、按钮命中区、地图路线、战争迷雾和战斗状态全部由运行时绘制。

## 统一视觉令牌

| 令牌 | 值 | 组件职责 |
| --- | --- | --- |
| `MIDNIGHT` | `#0D1C2E` | 夜幕、模态遮罩、未知区域的墨雾 |
| `PAPER` | `#14283B` | 深蓝纸场与战斗信息带 |
| `CARD` | `#FFF6E2` | 象牙纸页、顶部/底部命令轨、弹窗主体 |
| `INK` | `#1B2C40` | 象牙纸正文、标题、地图路线和按钮字 |
| `SEAL` | `#A43B2D` | 主行动、危险、敌方标记、朱印折角 |
| `GOLD` | `#D2A24F` | 资源、星级、焦点框、路线节点和装饰线 |
| `JADE` | `#4D9299` | 法力、己方施工点、辅助反馈和触控焦点 |
| `LANTERN` | `#F1A34B` | 矿点、灯笼光池和暖色交锋提示 |

`game/scripts/ui_theme.gd` 统一按钮、面板、滑条、滚动条和焦点状态；`game/scripts/paper_panel.gd` 对 `Modal_brief` / `Modal_result` 画四角金线，`surface("panel-ledger")` 和 `surface("panel-card")` 负责纸纤维、折角和九宫格拉伸。运行时文字不写入生成位图，避免生成图文字不可读或无法本地化。

## 限制与保持项

`test_simulation.gd` 的 7 个失败来自既有机制 fixture（能力转换、印记范围、火焰脉冲、范围法术落点、毒素来源、根须移动阻断、守护召唤位置），本轮只改 UI/背景与版本，不改 `battle_sim.gd`，因此不能把它们包装成已修复。Android 没有可用实体设备，移动端结论只覆盖 Windows 原生注入触控/密度矩阵和 APK 静态结构。
