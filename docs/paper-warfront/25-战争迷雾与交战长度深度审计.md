# 战争迷雾与交战长度深度审计 · rc6

历史范围说明：本文件记录rc6尚未实施战争迷雾时的审计。下文“当前”为当时源码；rc14已执行沿道路传播的正式迷雾、探索/历史情报及开火揭示，最新情况见[实现现状](120-实现现状与未完成项.md)、[核心实施记录](26-核心玩法对标实施进度.md)和[开火揭示](67-开火揭示与地图预警窗口.md)。原作HD的同条件实测缺口仍保留。

日期：2026-10-10。正式玩法没有修改。当前版本执行 200 地图的原生 60Hz 受控接敌测量，六图另测近战/远程/攻城三组镜像开局；参考游戏没有在本机运行。

## 1. 先修正证据范围

上一轮审计没有把信息规则列入主要差距，这是一项遗漏。更早研究写的是“没有证实战争迷雾”，不能据此得出“初代没有战争迷雾”。

- 初代 PS3 玩家亲身挑战攻略提到：佛像保住前方视野，毁掉后需在迷雾回收前重建。这是初代移植版的重要玩法线索，来自[玩家原始攻略](https://www.playstationtrophies.org/forum/topic/161303-swords-amp-soldiers-~-trophy-guide-amp-roadmap/)。本轮搜索索引返回相关段落，直接页403；不可称已观看对应录像或完整页面。
- [Ronimo 的二代采访](https://www.gamereactor.eu/news/308624/)明确把看不到敌方基地和出兵与心理博弈联系起来。此为开发者一手说明，但仅证明二代意图，不用作 PC HD 具体规则。
- [初代开发者美术文章](https://joostdevblog.blogspot.com/2010/12/designing-levels-without-tools.html)中的 atmospheric fog 是背景气氛，不是信息迷雾证据。
- [初代官方说明](https://www.nintendo.com/en-gb/Games/WiiWare/Swords-Soldiers-286811.html)确认遭遇战可选地图大小和布局；[开发者平衡文章](https://joostdevblog.blogspot.com/2011/01/?m=0)说明大地图和可防守设施空间有利于中国阵营，并以中型地图作为基准。

结论边界：初代 PS3 有设施/迷雾关联的实玩线索；PC HD 的揭雾来源、半径、退雾速度、地图是否永久探索、小地图与盲放法术权限，仍缺本轮原版实机确认。不能从二代或一张截图补出这些规则，也不能给原版编造地图米数。

## 2. 当前版本的信息规则：确认为全信息

| 系统 | 实际行为 | 后果 |
| --- | --- | --- |
| 战场绘制 | 遍历全部基地、矿、塔、单位；没有玩家视野过滤 | 移动镜头即可查看远方敌方对象和矿工工作状态 |
| 小地图 | 遍历全部单位与建筑绘制实时点位 | 即使不移镜头，也能获得敌方数量和位置线索 |
| 镜头追踪 | front()同时读取双方最前位置求中心 | 若以后只加遮罩，自动追踪仍可能泄露敌方推进位置 |
| 目标选择 | target_at遍历全部单位 | 没有“目标在当前己方视野内”的判定 |
| 施法 | 检查阵营、法力、冷却、目标类型和几何；不检查视野 | 可移镜头打远方敌军，范围法术可落在远方战场 |
| 建造 | 检查固定己方塔位、解锁和金币；不检查揭雾 | 远端塔位没有信息控制条件 |
| AI决策 | TacticalAI遍历全部活敌兵，按位置、速度、射程与威胁选兵/选路/施法 | 读取公开几何与资源公平不等于信息公平；当前双方全图明牌，未来加迷雾必须一起限制AI |
| 单位感知 | nearest_enemy查全场对象，部分单位在射程内优先支援目标 | 需与玩家视野分开定义；不能简单让所有单位因玩家看不见而失去近身自卫 |
| 特效、飘字、矿状态、声音 | 没有信息视野门禁 | 只盖一层黑幕仍可能通过其他渠道泄露 |

当前没有 discovered/visible/last_seen 状态，也没有战争迷雾服务。画面范围有限是镜头，不是视野限制。正式源文件：battle_sim.gd、battle_view.gd、tactical_ai.gd、map_runtime.gd。

## 3. 地图长度至少拆成六个量

1. **画布宽度**：地图length，含基地外边缘空间，用于镜头夹取和导航。
2. **基地水平间距**：两基地x差；不计坡面和绕路。
3. **实际行军路长**：沿地表线段/图路径的长度；分别列最短、最长和当前路线。
4. **首次交锋距离/时间**：受两边出兵时间、速度、射程、前摇、开局驻军、路线影响。
5. **增援距离/时间**：基地到当前战线的距离，战线变化时两方不同。
6. **信息预警距离/时间**：敌军首次被发现的位置到它能攻击或威胁目标的位置；受视野和侦察对象影响，不能用镜头宽度代替。

原版和本作单位没有统一米制。可靠跨游戏比较应使用“基地间有几个标准视窗”“主力通过全图要多久”“发现敌人后有几秒可反应”“增援相当于几个生产周期”，而不是比较不同引擎坐标。

## 5. 迷雾与长度怎样共同改变玩法

### 全信息长路

敌方出兵后即可查看，剩余路程几乎都成为我方预判时间。延长地图可能给科技与设施更多积累时间，也让慢兵投入更久不能生效；但它没有自动制造侦察、隐藏部署或伏击。当前敌人部署过程可被镜头/小地图观察，所以“地图短、缺迷雾、信息太透明”应分开归因。

### 有迷雾长路

未被发现的行军段可以隐藏兵种、数量和出兵节奏。发现越早，越能研究/生产反制；若只在双方前锋几乎接敌时揭示，能做的主要是施法，临时从基地买兵往往来不及。长图因此必须安排前置侦察和设施视野，否则只是“更长的盲等，然后突然输掉交锋”。

### 预警窗口不是总路长

在一条平路、两个前锋相向移动的简化模型：

`发现到攻击的窗口 ≈ max(0, 视野距离 - 首攻射程) / (我方速度 + 敌方速度)`

建议试验的视野6单位仅是本作假设，不是原作半径：印甲近战双方速度1.342、射程.65时，约1.99秒；投矛双方速度1.281、射程4.2时，仅约.70秒。若远程射程超过视野，可出现未显示的攻击来源，必须明确开火揭示、目标感知与投射物显示规则。

固定视野和相同单位下，把全图加长不会改变这两个局部预警窗口。真正决定反制能力的量是：

`反应余量 = 发现后的剩余威胁时间 - [判断/操作 + 排队 + 生产 + 增援行军]`

余量小于零不意味着自动失败，但意味着不能靠新买兵救场，需要提前侦察、已有前排、手动控制或预置防守。

### 战线推进的长度效应

某条54.44单位道路，前线位于自家到敌家的75%处。若相同近战从基地增援、速度1.342、空生产2秒：攻方需要约32.42秒，守方约12.14秒，相差20.28秒。这是道路比例模型，不是完整交战实测。它说明守方距离优势如何制造反扑窗口：地图越长，攻方深入越可能遇到补兵脱节。迷雾会进一步影响攻方能否看到守方后排正在成团。

因此“更长”不自动等于“更有战略”；要同时验证经济回本、设施积累、慢兵抵达、控制时长和守方反扑。

## 6. 设施与分岔的深层意义

- 产法设施若同时提供视野，其价值应拆成法力、预警、维持可施法区域与延缓波次；毁掉设施就能同时切断资源和信息，而非只减少回法。
- 侦察兵走过不是永久获得敌军实时状态。应明确未探索、已探索但当前不可见、当前可见，已知设施只显示陈旧信息，不跟踪迷雾里的单位。
- 分岔不能只按x揭雾。高架路的部队是否揭示下路，需要按路径距离、跨层距离或节点规则定义；不能从同水平坐标穿透整个上下路线。
- 镜头可以移动到已知地图，仍不能揭示敌军；禁止把拖镜头误当侦察。
- 如果小地图保持全敌军实时点位，战争迷雾的兵种隐蔽仍会被数量和移动速度泄露，必须与战场共享同一信息模型。

## 7. 移动端还会改变“看起来有多长”

手机fit_stage为容纳高低道路和纸偶而缩小整个舞台。1280×720、密度2、无安全区、默认院内编组的公式推导显示：一次横向世界范围约20.51–30.64单位。高差较大的地图可能一次看到更多路段，最短道路相当于约1.56–2.64个手机视窗。此项是公式推导，不是200图逐图原生截图。

缩放可以帮助容纳舞台，但当前全信息下也增加一屏信息量，削弱距离的视觉感受。迷雾揭示必须使用世界规则，不能随屏幕、缩放、分辨率扩大。否则同一对局在手机上会拥有不同的合法情报和施法区域。

## 8. 下一轮的可实现约束建议

P0：先建设统一的玩家信息服务，而不是加一层黑色遮罩。战场、小地图、目标命中、施法、建造、镜头追踪、敌情标记、事件/声音及AI读取同一视野状态。观察者/调试模式允许全信息但正式玩法不能借用。

本作候选规则需独立试验，不宣称等同原版：基地提供安全区视野，战斗单位提供随行视野，塔/法灯提供固定视野；地形可知，敌军只在当前视野中实时可见；离开视野后不保留移动追踪；失去设施收回实时视野。盲放范围法术是否允许、施工阶段何时揭雾、目标丢失是否退费、AI记忆多久，都必须明确定义。

P0：把地图调优统一成视野半径/射程、首次接敌/生产周期、前线增援/控制时长、前置侦察提前量/研究时间等比值。先用现有短、中、长基准图测试，不一次拉长全部200图。

建议验收场景：

1. 镜头移到敌城不能泄露兵种，小地图不能透露未揭示的敌军；非法锁定拒绝且不扣资源。
2. 侦察推进后发现巨兵，守方获得明确反应窗口；失去侦察后不得持续跟踪。
3. 法灯被毁，法力与当前视野同步变化；陈旧设施标记不冒充实时情报。
4. 上下路分别探路，遮蔽规则在分岔/汇流处一致；无法隔路透视。
5. AI不根据不可见新兵即刻换克制单位；记忆必须有时间戳。
6. 同一世界状态在桌面、手机及缩放变化下具有相同可见对象与合法施法集合。
7. 短、中、长图都能形成两种以上有效开局，慢兵有合理投资回报，守方有可理解的反扑窗口。
