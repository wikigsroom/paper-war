# 移动端适配 · 3.0.0-rc3

Android 改为按屏幕密度布局的横屏游戏界面。已实现安全区、48dp 控件、手机与平板布局、独立触摸、原生滚动和滑杆、长按资料、返回层级、后台暂停和省电档位。
