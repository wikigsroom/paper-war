# 按实际选路识别存活支援兵团

新增RecruitmentReadiness.deployment_group，只观察己方存活作战单位，沿基地出仓点与当前分岔选择计算道路进度。排除工人、死亡单位、其他支路及未出仓订单；要求实际选路上有前排及距其道路距离不超过6的另一名存活作战兵。若有多组，取沿选路离基地最近的合格前排兵团。

6是本作兵团观察阈值，不是原作实测、治疗半径或生存保证。查询不读取敌方位置或生命，不改变军队、资源、队列或选路。自定义enemy_entries不能假定标准基地出仓路线，返回不支持；候选在该类配置保留原人数条件作为回退，不宣称已经解决特殊入口的空间判断。

默认关闭的顺序候选接入该查询：已付款非前排兵种的首次部署，要求存在当前选路上的存活兵团；缺少该路前排时允许真实现金恢复前排，缺少兵团时允许先恢复基础作战兵。普通评分与强制选择使用同一资格条件，不能重新绕过门槛。正式默认未改。

双侧22项检查通过：同路近邻、查询无副作用、同路但远处分离、死亡/工人/订单不算兵团、隐藏敌方不影响、自定义入口不冒充标准出仓、其他支路排除、实际换路后纳入，以及现金足额时实际AI仍拒绝远处分离的医师目标。统一48组12888项机制回归通过，报告来源与当前输入一致。

当前规则仅证明支援条件来自实际存活/选路/间距，尚未预测生产后战线移动、前排死亡或支援抵达，也未证明治疗/高阶输出带来稳定反推。候选继续关闭，下一步应对全阵营候选矩阵及多seed检查后再决定正式默认采用范围；不得把20场局部结果推广为完整平衡。
