# 真实付费前哨接触测量

继50，使用正式迷雾与合法塔位测塔接触。墨骸先实际购买40金币刃兵侦察东侧塔位，揭雾后支付80金币建塔并等待施工完成；随后移除已付费侦察兵以隔离塔交锋。西侧按真实价格与生产时间购买一名印甲斧兵/木拓守卫/纸械狂战士，分别承诺主路和桥路，共六场。双方300金币，关闭AI，清空工人；全科技不含研究投入，无施法或后续补兵。这是付费隔离交锋，不是完整正常开局。

六场均拆塔，但承受长期阻滞。木拓从首次塔命中到拆塔约37.83–37.85秒，并非按覆盖长度匀速穿行的约数秒。自然修复在交锋中执行，不能把攻击次数乘12直接等同净生命损失；印甲也存在物理减伤。记录保留每次实际命中amount，而非只用纸面DPS推断。

这证明50的匀速穿越模型不能直接代表近战拆塔成本。当前策略暂保留该模型用于几何暴露比较，但明确欠估交战停留；下一步应区分远程接敌、近战拆塔与完全绕过攻击覆盖，按单位伤害、攻击间隔、建筑生命和预计阻滞估计攻坚成本。不能只增加权重或给塔更高伤害来迎合想象的结果。

同一汇流塔覆盖两条路，单兵最终交锋结果基本相同，桥路分别推迟首次命中约1.47、1.83和1.50秒。这是本作此图此开局的测量，不代表所有分岔只有延迟价值；它还可能改变沿途兵团接敌、法术封路与情报。
