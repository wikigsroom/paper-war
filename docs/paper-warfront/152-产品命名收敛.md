# 产品命名收敛

当前产品的正式展示名统一为：**纸上兵戈**。

“十院留名”保留为战役世界与剧情终章中的故事概念，不再作为产品主标题；`PaperWarfront` 保留为仓库、Godot 技术标识、Windows 可执行文件名和 Android 包名的一部分，以避免破坏构建脚本、存档路径和既有发行工具。

已同步的当前展示入口包括：

- Godot `application/config/name`。
- 根目录 README、Godot 工程 README 和文档索引。
- 桌面端与移动端“鸣谢与许可”页面。
- Windows 发行包 README 生成模板。
- 当前运行故事数据的产品标题与素材图库标题。

历史研发记录、旧版本发布文档和剧情中的“十院留名”专名保留原文，作为可追溯记录或故事内容，不代表当前产品名。

RC38 重建后，Windows 与 Android 包均已通过原有 38 组、195115 项逻辑检查；Android Manifest 的 `application-label` 已实际解析为“纸上兵戈”。
