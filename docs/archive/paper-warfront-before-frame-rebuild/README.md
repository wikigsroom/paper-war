# 纸上兵戈：十院留名 · 3.0.0-rc3

当前为 **3.0.0-rc3 移动适配版**：[移动适配入口](../../paper-warfront/mobile-rc3/README.md) · [当前下载](../../../release/3.0.0-rc3/README.md)。rc2 判定／采矿／视觉报告保留为基线，当前移动交互和构建以 rc3 为准。

当前版本重做地图的空间取舍：归仓与前沿经济、援军距离、分岔阵地、矿线截击、护送接力。Godot原生纸偶舞台，每局2–4个战斗兵种加一个工人，生产选择合计3–5项。

**3.0.0-rc2 修复与视觉基线**，已修订友军判定、采矿动作与FIFO、地图美术和原生UI。旧地图研究与rc1报告是历史基线；该版判定、采矿和素材记录保存在[rc2文档体系](../../paper-warfront/fixes-rc2/README.md)，移动 UI 与发布包以 rc3 为准。
