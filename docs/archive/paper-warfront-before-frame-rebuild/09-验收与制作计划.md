# 验收与制作计划 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

证据分层：原作公开来源、当前参数审计、受控模拟决策、全图运输、完整自动对战、原生指针与GPU画面、导出程序、Android包结构、人工／真机体验。不同层不能相互代替。

规则检查用真实消费与对象结果，避免只检查字段存在。当前运输包含每座无限矿双侧300秒、预计周期与最后完整周期回款；长图不会套用短图每分钟十趟要求。护送边界、截击越线事件、死基地生产及任务严格结算需单独回归。

后续优先做六图两种人工打法、工人骚扰回款、地图首次接战窗口、十院默认编组和Android真机，再扩展全战役平衡。未验证的原作PC路标权限、跨路数值和坡面移速仍留缺证据项。
