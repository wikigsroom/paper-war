# 规模扩展与实施进度 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

200场景与故事链、十院各40战斗兵、50法术、六挑战保留；当前200场景有193实际几何、26种空间问题文本。基础库容量与本局编组严格区分，不能以规模替代地图体验。

已实现六手工基准、194显式空间简报、真实回款、阵地绕行、任务锚点、纸桥实体、工人容量、独立指针触区与新版小HUD。新素材为40专属核心与40角色母版派生，不冒称400张独立生成原画。

后续体验评审项仍为六图多打法、工人骚扰、全战役默认难度、窄屏／真机触摸、音频与性能。当前交付是可运行评审版，未宣称与HD品质相等。
