# Godot纸偶与动画规范 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

脚点是移动和命中坐标；纸偶整身围绕固定脚点变换。body与前后腿交替转动，炮车转轮；行军节奏关联模拟walk。待机轻微呼吸，攻击前摇倾身压缩，释放回弹；受击闪白并短暂停留、纸屑飞散，死亡落纸或碎片后清理。

当前是分层纸偶程序动画。武器随主体动作，尚未逐兵种制作独立肩肘武器骨骼或手绘连续帧。重兵缩放更大，桥上与桥下脚点不同；单位美术高度不替代规则射程。

投射物、技能预警、粒子和飘字来自真实事件。减少动态开关使绘制不施加相机震动。原生7组姿态夹具只检视枢轴／剪影；完整合法对战录像检视事件反馈。
