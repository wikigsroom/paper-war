# 美术风格圣经 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

主视觉为暖纸色、墨线与剪纸厚片；角色大头短肢、武器剪影鲜明，纸纤维留在大色块中，细碎纹理不占据读敌所需空间。十院主色沿用阵营定义，拥有方还由蓝／红标识和前进方向表达。

背景是远景，不生成假道路。地面连续填充纸层实体，脚点贴实际路径；纸桥有坡面、平台及桥墩。装饰避开基地、矿点、设施，主要互动标牌必须靠近实体并可点击。HUD保持上下纸带，中部为完整战场；特效短而明确，受击闪白、纸屑和重击震动分层。

生成画不充当运行证明。基础角色采用40张专属核心造型；角色家族复用需在素材库注明来源。部分彩色变体会保留供体装饰，不宣称所有角色均为独立原画。
