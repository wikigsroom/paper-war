# 玩家手册 · 3.0.0-rc2

> 当前移动适配为 3.0.0-rc3：[实现与验证](../../paper-warfront/mobile-rc3/README.md) · [双平台下载](../../../release/3.0.0-rc3/README.md)。下文保留原系统规则；移动界面以新文档为准。

当前为 **3.0.0-rc2 修复与视觉版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

建议从“地图试演 · 六张基准”的归金坡开始。阅读问题与地图，招前排＋远程保护工人；金币要等工人归城才增加。采矿可见举镐、落镐、回收及矿屑，等待者不挥镐；装袋回程后在城内卸货才到账。近矿排队时可增工往外矿，但更远的收入需要护卫。

生产卡上显示费用、锁定和排队。兵种由战前2–4个战斗位选择，另有工人。研究只解锁当前编组内兵种及五个阵营法术／升级。灯和塔各有允许位置：点牌选设施，合法位置发亮，再点位付费；施工时要保护。

岔口蓝牌“我主路／我纸桥”切换后续部队，已进入路线的军队继续前进。桥路更长，但可绕开主路近战阵地；敌远程在真实范围内仍能射到。法术选卡后点对象／地面；非法目标不会扣费；右键或取消退出。

拖战场／点小地图导航；A/D或左右键平移，Home回城，Space跟前线。数字1–5招募，Q/W/E/R/T施法选择，F研究，B建造，Esc暂停。移动横屏在“军阵／法术”切换，Android返回键关闭选择或暂停。

任务以顶部文字、矿线和目标标记为准：护送必须活着到交接点，截击必须越线前打倒，守护必须守满时间。胜利解锁故事下一关，试演不记战役进度。暂停可调音量、减少动态、跟前线；继续／重试／返回均有菜单。
