# 战前编组与科技规范 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

每局2–4个战斗兵種，加工人共3–5项生产。关卡default_roster决定首次默认阵容，已保存的自选编组在available_roster内规范化；旧8兵存档迁移到最多4战斗兵种。科技面板过滤未选兵种；完整科技也不能直接招募编组之外的兵。

生产队列最多6，工人上限10，战斗人数上限60；人数上限包含待生产订单，取消未出生订单全额退金。军库400种仅用于战前选择与资料浏览。移动HUD只军阵／法术两组，废止units2。

选择建筑不扣费，提交合法施工才收费。基础建筑无需虚构科技前置；当前阶段剩余兵种科技以technology.json的真实id、requires和seconds为准。选中前两种开局可用，其余科技在真实完成时解锁。
