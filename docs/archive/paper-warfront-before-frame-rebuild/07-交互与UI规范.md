# 交互与UI规范 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

入口含线性战役、六图试演、遭遇战、编组、军库、挑战、设置、帮助与鸣谢。战前简报显示整张真实路线、矿容量、设施、目标、空间问题及预算；可在可用军库范围内选择2–4战斗兵种。

桌面底部左侧3–5生产卡，右侧五个法术，中间小地图、研究、建造、队列及导航。移动横屏仅“军阵／法术”两组切换，不另分页展示一整套军库。顶部为金币、法力速率、目标、城生命及暂停。

点矿设置下次出发优先；点独立蓝色路标切换后续部队路线；点空设施牌打开当前位允许的塔／灯。选择建筑不扣费，点合法位后才付费施工。路标与设施不共用触区。施法先选卡，再点合法角色或地面；右键／取消／返回键退出选取。小地图、拖动、左右键均可平移。

原生注入指针检查覆盖招募、退款、设施、路线、矿、导航和研究；50法术UI用信号夹具，不声称全部由真实触摸完成。Android触摸与dp尺寸仍待真机。
