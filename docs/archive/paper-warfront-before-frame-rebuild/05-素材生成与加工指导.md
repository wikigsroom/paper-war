# 素材生成与加工指导 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

图像生成严格使用用户指定sub2-image-gen／gpt-image-2.5；提示词与原PNG保留在output/imagegen/paper-warfront/theatre-v3。透明原生alpha，整件轮廓留足边距，武器、脚、旗帜不得切到格边。

整身、建筑、背景分批。切格后按连通alpha取完整主体，去除远离主体的小杂点，统一512画布与脚底基线476；头像按头部焦点裁切。body／前后腿或车轮分件由加工脚本生成，枢轴入manifest。微弱洞口辉光裁掉，金矿轮廓仍完整。

原props-yin存在裁边，已拒用并由repairs/props-yin.png替代；common-mine为独立修复源。16缺失角色用三张3×2板补齐；再与核心供体共同形成40角色母版。派生色仅处理有彩度区域并保留alpha／墨线，供体细节复用需披露。
