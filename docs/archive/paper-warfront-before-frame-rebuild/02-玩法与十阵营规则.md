# 玩法与十阵营规则 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

金币在工人实际归仓时入账。容量指同时服务工人数，队列按实际到达排序。士兵自动推进与搜索二维射程目标；投射物有飞行、延迟技能有预警。

招募、研究、设施共享金币；法术消耗法力与冷却。基地产法每秒0.5，完成产法建筑／科技及阵营事件提供实际增益。建筑施工期间不产法、不攻击。每局仅研究选中兵种及阵营法术／升级；基础选中前两兵种可用，其他选择仍要科技。
