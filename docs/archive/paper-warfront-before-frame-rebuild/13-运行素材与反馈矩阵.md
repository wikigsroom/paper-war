# 运行素材与反馈矩阵 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

军队：body＋双腿／车轮、脚点、武器剪影、前摇、命中、受击、死亡。建筑：底座脚点、施工填充、完成事件、二维攻击圈、停用与摧毁。经济：矿洞、容量／排队、工人来回、实际归仓金币。路线：独立路标、第一段方向提示、桥与汇流、阵营箭头。

法术：选中卡、合法对象／地面、资源校验、冷却、预警、特效、真实效果事件。任务：指定对象的真实生命与距离、实际矿线／交接点、可见敌入口、独立严格胜败。

音频为原创程序合成：战斗纸步、斩击、投射、重击、炮响、死亡、建成、路标、危险和阵营循环音乐。音频限流与16声部池；远离镜头的局部战斗降低输出。录像为静音离线画面，不冒称已录制原生声音或测量帧率。
