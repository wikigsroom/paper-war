# 路径与经济执行规范 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

节点与边都是实际战斗坐标，矿、设施和任务锚点有edge／s／x／y；长度沿折线累计。工人路径选择将当前位置与目的地的边纳入首尾，避免同边立即回接形成零距离循环。ground_y_at只用指定地表边，桥高不会替代地面。

容量为同时服务数量，工人在抵矿FIFO队列等待，等待不推进采矿时间；运回基地完成deposit后才入账。每趟8金，外矿通过真实服务周期／容量扩展收入；指定优先矿影响下一趟，在无剩余吞吐时才另选。有限矿枯竭时换目标。

AI经济估计包含去程、服务、回程、1秒归仓与已有工人负载；玩家点击命令优先级高于自动选择。法术和塔用实际二维距离，不给坡面或桥自动加伤／无敌。两侧运输与长坡援军时间有镜像检查。
