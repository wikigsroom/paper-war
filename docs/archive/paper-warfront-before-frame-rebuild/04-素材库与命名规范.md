# 素材库与命名规范 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

正式绑定以game/data/assets.json为准，稳定ID区分unit／spell／building／background／prop／resource。整身切图512×512，头像192×192；绑定含content_box、world_height、animation.parts及脚点。当前473条新来源加工记录；40专属核心兵、360按角色母版派生的阵营变体，加2个召唤别名，另有工人、建筑、背景和装饰。

40种角色母版并不等于400次独立生成。来源、母版、供体阵营、目标调色与文件散列在theatre-role-library.json及theatre-art-provenance.json中。状态字段是制作成熟度；详细人工目视及原生代表覆盖另记visual-review.json，不把headless招募检查视为每个角色的画面验收。
