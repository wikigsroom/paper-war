# 十院素材与动画规范 · 3.0.0-rc1

当前为 **3.0.0-rc1 地图重做评审版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

十院各四个专属核心造型、工人、基地、塔、产法设施、地域远景与两类装饰；40角色家族覆盖360个其余军库单位的阵营调色。两召唤体为明确别名复用。

原生十院核心战斗夹具、400全局军库浏览、7姿态及合法完整对局互补。全部调色联系板已目视，角色母版及修复源已检查，alpha裁切与边距由加工脚本检查。仍有供体装饰复用和彩色肤部位，不能称400独立美术。

角色主体、双腿／车轮有枢轴；独立武器关节未逐兵种制作。所有动作和特效需以原生过程验收；整身切图、头像和源图不等于独立手绘帧动画。素材表／来源／规则位置可从离线theatre-v3-gallery.html查询。
