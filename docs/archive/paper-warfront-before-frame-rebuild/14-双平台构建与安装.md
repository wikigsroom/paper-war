# 双平台构建与安装 · 3.0.0-rc2

> 当前移动适配为 3.0.0-rc3：[实现与验证](../../paper-warfront/mobile-rc3/README.md) · [双平台下载](../../../release/3.0.0-rc3/README.md)。下文保留原系统规则；移动界面以新文档为准。

当前为 **3.0.0-rc2 修复与视觉版**。自动规则与原生代表画面已有证据；原作 HD 未在本机运行，200 关人工平衡和 Android 真机尚未验收。参数以 `game/data` 为准。

Windows程序资源内嵌，解压Windows ZIP后双击EXE。支持原生窗口；旧显卡可用附带兼容启动脚本选择gl_compatibility。当前本机Win11／RTX3060执行新包画面检查。

Android签名APK包含arm64-v8a与armeabi-v7a、离线无INTERNET权限、横屏，版本3.0.0-rc2／versionCode30001。本地安装后允许系统的“安装未知应用”；存档在应用私有目录。无真机连接，不保证特定手机触控、热量、音频焦点与帧率。

build_game.py使用原生Godot导出模板、Java21及本地AndroidSDK工具（模板compile SDK36）构建，校验签名、zipalign16KB与arm64 ELF加载段对齐。私钥／口令位于项目外.keys，仅构建时通过环境传递，不进入源包。升级保持包ID和本地签名；清除应用数据会删除进度。
