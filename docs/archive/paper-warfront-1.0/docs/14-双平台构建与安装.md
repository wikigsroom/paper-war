# 双平台构建与安装 · 1.0

可执行交付入口：[release说明](../../../../release/README.md)。所有构建在Windows原生环境执行，不使用虚拟化或Android模拟器。

## Windows

Godot 4.7.2官方Windows x86_64 release模板，PCK嵌入EXE；无需安装Godot即可运行。复制/解压后双击PaperWarfront.exe。默认1280×720窗口，设置可全屏；使用Vulkan Mobile渲染。保存位置 `%APPDATA%\PaperWarfront\profile.json`，复制该文件可备份进度。

EXE使用本地release导出，未配置Windows商业代码签名。游戏资源内含原创图标；程序资源修改未依赖额外rcedit工具。最低窗口960×540为布局设计范围；未进行多GPU/旧驱动兼容矩阵，不承诺所有旧电脑均运行。

## Android

包名org.paperwarfront.game；version1.0.0/code10000；ARMv7+ARM64，横屏/沉浸式；无互联网权限。以本地专用release密钥签名，非Android debug默认密钥。ABI、最低/目标SDK以APK原生badging实际输出和交付清单为准。

把PaperWarfront-1.0.0.apk复制到手机，使用文件管理器打开；系统提示时允许该文件管理器安装应用，然后安装。应用内点按招募与施法，拖动战场和战线图。系统返回优先取消/关闭/暂停；切后台自动暂停。未连接Android真机，本次不能声称已完成手机安装启动、触控、音频延迟、发热或FPS验证。

升级需要保持同一签名；`.keys/`只保留在本工作区，不加入源码包、资源或文档。重建者首次新密钥导出可安装为独立测试，但若与已装APK签名不同，系统会拒绝覆盖，应保留原签名用于未来升级。

## 原生重建

依赖：Godot4.7.2及同版本模板；Python3+Pillow+numpy+fontTools；Android SDK与JDK（本次JDK21、SDK build-tools35.0.0）。Python路径和SDK可按本机在build_game.py调整。打开game/project.godot也可直接从编辑器运行。

```powershell
python -X utf8 tools/paper-warfront/prepare_godot.py
python -X utf8 tools/paper-warfront/optimize_fonts.py
& .tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path game --script res://tests/test_simulation.gd -- --campaign
python -X utf8 tools/paper-warfront/build_game.py
```

已有运行资源与子集字体可直接开工程，不需要重新生成图片。完整原字体随源码放在assets/paper-warfront/fonts/source，optimize_fonts.py会优先使用本机.tools/fonts缓存并回退到随包原字体；来源与OFL一并保留。新增文案后重新子集，否则遗漏字可能无法显示。

构建脚本先原生import，再export-release两平台；校验APK签名、16KB页对齐、badging与ABI并写SHA256清单。Windows旧aapt无法识别Unicode路径时，仅复制APK到ASCII临时路径做校验，然后清除副本；不改游戏包内容。

## 许可与安全边界

Godot MIT和引擎第三方通知随资源/交付包；Noto子集字体保留SIL OFL1.1许可并改内部名。图像保留Sub2生成源与处理溯源；配乐/SFX为本项目程序化合成。使用 `sub2-image-gen` 技能的网关配置在技能环境内，不进入工程。源码包排除.keys/.tools/.godot及本机构建凭证。

Android的签名/结构验证与实际手机运行是两层证据；Windows实际运行与Android包导出不可互相替代。测试报告只记已发生的结果。
