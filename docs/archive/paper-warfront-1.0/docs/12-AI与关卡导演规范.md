# AI与关卡导演规范 · 1.0

地图专项复核（2026-10-08）：1.0 的三个场景共用一套机械地图，十五个战役关卡全部以拆基地结算；现有功能/导出验证不代表原作地图对标已完成。后续地图方向以 [地图研究与重设计约束](../../../research/swords-and-soldiers-map/README.md) 为准，其中的新方案尚未实施。

实际入口 `battle_sim.gd:ai_turn`。AI只能发与玩家相同的招募、研究、建造和施法请求；合法性/付款/队列/名额/冷却相同。敌我整条战线公开，无战争迷雾；对手金币、研究内部进度、未出生队列不作为免费战术情报。

## 决策步骤

1. 检查本关公开开场宽限；收集可见双方作战兵与本方经济/法力状态。
2. 敌兵进入本方基地9距离内视为威胁；停止攀科技，优先补基础前排。
3. 安全且有70金储备时补工人：早压/反制倾向3名，经济4名；工人仍受6名总上限。
4. 灯符在12秒后、≥100金币时尝试固定槽建灯；不覆盖已有建筑，失灯后可重建。
5. 已有至少3作战兵、暂无威胁、研究空闲且到攀科技时刻，则按前置选可研究节点；保留预算而不是每次把钱全部花在廉价兵。研究尝试间隔约26秒。
6. 待产少于2且未达本关军团限制时选出兵；至少2前排后才补已开放的远程/支援/重型。祭司比例控制为每5兵约1名，避免无兵护祭司。
7. 评估已解锁法术，合法且有意义时最多施放一种，再等待下轮。

## 三种策略与难度

早压偏基础前排与较少工人；经济增加工人再攀军种；反制在合法科技候选中使用种子随机，同时按高价值敌军与团簇放法。三策略不改变单位数值。难度为决策周期1.25/0.65/0.35秒，不增加金币收入、攻击或法力。

公开不对称只存在战役/挑战开场配置，例如教学110敌金、15秒宽限、敌军上限3；战前说明公开金币差，关卡文档登记宽限和上限。遭遇战双方230金对等开局。

## 施法意图与反制

| 法术类型 | AI用途 |
| --- | --- |
| 补纸 | 队内受伤单位已损至少55生命 |
| 献纸 | 剩余<22%、法力<65且处于敌攻击范围附近，避免过早吃掉整条前线 |
| 护符 | 已受伤到60%以下的单位，争取生命交换 |
| 复制 / 振甲 | 友兵接近敌阵且有交锋，仍需通过来源/名额校验 |
| 雷印 / 墨缚 / 夺印 | 优先高价值敌兵；威胁、成群或价格≥95时使用 |
| 定字 | 敌人尚未进入最近友兵的攻击距离，且距离<6，避免徒耗法力定住原已站定的前排 |
| 区域伤害 / 寒风 | 区域至少2敌兵，避免把高费范围法砸空 |
| 纸卫 | 家门受压或有多敌军；合法位置仍限制敌基地区域 |

AI不是最优解求解器；它提供可反制的节奏和兵种变化。玩家可通过精准单体救援、前摇打断、资源储备和侧重兵种胜出。敌军也可能使用不划算技能，不能将自动对局胜率当人类通关率。

## 验证与调整

规则回归检查每笔AI命令均经过共享API。十五关自动双方指挥用于检测无法结束、复兵循环和单位卡死；合法玩家指挥策略另外用于检测是否存在可胜路径。若关卡不可胜，先检查费用/法力/兵种与AI决策，禁止通过测试中直接杀基地或给玩家临时无限金币来伪造通关。

内容导演为配置驱动的初始解锁、资源、策略与目标；1.0不包含隐藏剧情刷兵、波次编辑器或战中对白弹框。增加波次时必须公开预算、队列规则与胜负条件。
