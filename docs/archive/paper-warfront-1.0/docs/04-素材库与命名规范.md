## 文件责任

`assets/paper-warfront/library-definition.json`记录名称/功能/生成要求；`library-manifest.json`记录源图、裁切、尺寸、散列与静态审核；`runtime-manifest.json`为源库导出ID映射。`game/data/assets.json`是Godot实际res://路径、世界高度、头像和动画绑定；`asset-inventory.json`记录运行文件大小与SHA256。

生成源与提示词：output/imagegen/paper-warfront。运行分件：game/assets/animation。新音乐：源库audio/music → game/assets/audio/music。脚本不复制技能配置或签名密钥。Godot导出依赖运行文件，不加载源图板、检查板、旧3D rig和CSS。

旧17份rig JSON保留历史造型蓝图；它们不是当前运行动画定义。神态/面部/独立手部并未被虚构成已经实现的动画。

## ID与版本

稳定语义ID `unit.yin.axe`、`spell.mo.sacrifice`、`building.deng.mana`、`background.ink-marsh`。文件以点转短横线；分件后缀body/leg-back/leg-front/wheel-back/wheel-front。路径、头像与分件通过manifest引用，不能硬猜文件名或混用源/运行坐标。

大改轮廓、基线、分件或用途需升版本并记录旧图、源任务、加工参数和影响。源图保留；普通裁切可重新导出。Godot数据版本1.0；源库0.1静态来源记录不因运行接入被伪改成真机通过。

## 成熟度与证据

| 状态 | 意义 | 证据 |
| --- | --- | --- |
| design-ready | 定义完整 | ID/用途/提示词 |
| source-generated | 源图可解码 | 源任务与实际文件 |
| derived-candidate | 加工候选 | PNG/WAV/头像/裁切信息 |
| visual-reviewed | 静态造型/边缘看过 | 源库QA记录/分类检查板 |
| runtime-linked | 已在Godot绑定 | res://存在、分件/ID关联检查 |
| scenario-verified | 对应规则或场景实际验证 | 模拟测试、导出程序截图、实际输入 |
| device-verified | 指定设备上实际运行 | 设备/系统/输入/音频/性能记录 |

Windows场景截图不能自动把Android标为device-verified；加载成功不能批准未使用纹理的战场重复效果。具体记录见 [13反馈矩阵](13-运行素材与反馈矩阵.md) 与 [15交付报告](15-运行验收与交付报告.md)。

## 导出与性能规格

整身/分件512² RGBA、足底256/476；头像192²；图标192²；特效256²；建筑/道具512²；纸材512² RGB；背景读取真实源宽高。人物缩放用各自世界高度，不能把巨人与工人画成同样高。左右翻转只对纸偶/建筑表现，头像和图标不翻转。

SFX44.1kHz/16bit/mono；正式音乐22.05kHz/16bit/mono、40秒循环；警报在Godot运行时生成。纹理import由Godot管理，Windows导出S3TC/BPTC、AndroidETC2/ASTC。不要把音频格式转换与肉眼图像检查混成同一批准状态。
