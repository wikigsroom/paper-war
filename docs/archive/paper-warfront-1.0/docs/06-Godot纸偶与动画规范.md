# Godot纸偶与动画规范 · 1.0

实际代码：[battle_view.gd](../../../../game/scripts/battle_view.gd)；资源桥接：[prepare_godot.py](../../../../tools/paper-warfront/prepare_godot.py)。固定Canvas2D侧视，不加载外部模型或3D刚体。

## 锚点、分件与层级

1600×900设计视口，地面Y=0.81×900；每逻辑单位78px。纸偶显示高度=素材世界高度×78×1.35，普通兵约190px、巨人约360px。素材归一化512²、足底(256,476)。左右翻转围绕足底，不改变逻辑位置与命中距离。

17单位拆为躯干、后腿、前腿；炮车增加双轮，共53张运行分件PNG。髋点=实际内容高度68%位置，躯干/腿在髋点重叠28px，防止摇摆漏底。头、手、武器保留在同一上身图中，以身体前摇和出手角度呈现攻击；1.0不声称已具备独立面部表情或逐指骨骼动画。

纸边用偏移阴影与较暗层表达；材质哑光。士兵绘制主体相对逻辑接触点后移25px，减少敌我大图贴脸重叠；视觉排次偏移4px，不改变射程。目标预览、鼠标点选和死亡位置使用同一显示变换。

## 动作协议

| 动作 | 模拟触发 | 表现与约束 |
| --- | --- | --- |
| 待机 | 无合法目标或冷却等待 | 轻身体摆动；无大幅上下飘 |
| 行走 | X位置推进/纸工往返 | 双腿反相约±0.2弧度、上下约4px；速度对应移动；炮轮旋转 |
| 攻击前摇 | windup状态 | 身体后仰约0.17弧度；重击更长，允许玩家读到控制窗口 |
| 攻击结算 | attack/launch事件 | 身体前摆、短弧/炮口纸屑；飞弹与直接法术分开 |
| 受击 | 有效hit事件 | 0.13秒闪白、约3px视觉震动；55ms局部步态停顿 |
| 控制 | stun/bind/root/cold状态 | 墨缚/定字符/寒纸环；前摇打断有文字与声音 |
| 治疗/保护 | heal/blocked事件 | 绿色增益数字、纸边合拢/短金符；生命条对应实际量 |
| 越线/跃袭 | dash事件 | 短折影残线，清楚显示前后位置，不移动相机伪造位移 |
| 阵亡 | death事件 | 0.44秒折倒、有限碎纸；纸标由模拟单独生成 |
| 建筑破坏 | building_death | 更大纸块散落与短震动；产法/防御当步停止 |

55ms受击停顿只作用于视觉步态，不暂停任何队列、技能、AI或资源。降低震动设置关闭镜头抖动，保留攻击、命中和状态必要信息。

## 特效、粒子与伤害阅读

印甲：补纸绿点、雷印直线、寒纸圈、振甲边弧、落印预告方章/压落。墨骸：献纸散页、墨缚纹、腐墨印、夺印关系标、泼墨短爆。灯符：护符环、双纸复印、三段落签、定字短符、纸卫展开。静态母题仅是图案，不决定伤害范围或寿命。

普通命中3片纸屑，重击6片，死亡15片，落印/范围冲击25片，建筑碎35片。纸屑重力约480px/s²，寿命约0.23–1.2秒；最多650粒、161以内瞬时特效（追加前淘汰旧项）。区域圈按实际radius×78绘制；短伤害数字约0.7秒、恢复1秒、金币0.8秒。普通命中数字低于4不显示，避免毒伤遮场。

相机侧向平移、指数插值，中心限制10..46；不绕场、不自由缩放、不因打击改变逻辑坐标。三背景/道具按低对比视差移动。战线图显示双方军团与视窗，始终是导航参考。

## 验收情境

每类人物检查待机/走路/前摇/命中/死亡/左右翻转；三军各一组密集交锋截图。检查腿无显著漏底、巨人高度差、轮子转动、生命条/伤害数字、复制与转换关系标。实际导出截图见 [15运行报告](15-运行验收与交付报告.md)，Android触控/帧率另行真机验收。
