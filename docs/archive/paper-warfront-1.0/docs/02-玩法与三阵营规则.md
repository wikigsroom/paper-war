# 玩法与三阵营规则 · 1.0

地图专项复核（2026-10-08）：1.0 的三个场景共用一套机械地图，十五个战役关卡全部以拆基地结算；现有功能/导出验证不代表原作地图对标已完成。后续地图方向以 [地图研究与重设计约束](../../../research/swords-and-soldiers-map/README.md) 为准，其中的新方案尚未实施。

以下是已接入Godot的原创规则，来源为 [运行平衡数据](../data/balance-prototype.json) 和 [科技数据](../data/technology.json)。原作对标的是决策骨架，不复制原作资产或声称这些数值来自原作。

## 公共经济、生产与结算

金币在纸工回基地交付后入账。每方开局2工人、40法力；普通配置160起始金币，遭遇战230，战役/挑战用战前公开数据。工人35金、55生命、速度1.25，容量8金；采1.2秒、交1秒。死亡丢失未归仓货物。矿点无限，不出现额外采矿资源。

法力上限100，基础回法0.5/秒。印甲回法一阶+0.9、二阶再+1.0；墨骸合法献祭获得剩余生命×0.18向下取整；灯符每活灯+1.1/秒，55金、230生命，最多两个固定建造位。设施死亡立刻停止贡献；不用灯的动画颜色决定增益。

每方上限6工人、60作战单位；召唤、复制、转换及待产订单预占名额。一个6格生产队列，间隔2.4秒。合法招募先扣金入队；未出生订单取消全额返金。研究/建造确认后不退款；研究单槽，关闭科技图仍继续。

战线长度56，基地X=2/54，矿点6/50，建造位为我方3.5/8.5、敌方52.5/47.5；每基地1100生命，无自动攻击。普通胜利是敌基地归零；双基地同一步归零为平局。守城挑战活到150秒获胜，先被拆则失败。胜负后停止新命令。

## 归属、状态与复兵边界

- 夺印改变归属而不改单位ID/原始能力、生命和纸偶造型；脚下关系标和生命条随新归属变化。巨人可被高费夺印，巨人不可复制；两法术的反制边界不同。
- 相同状态刷新较长剩余时长、保留较高强度；毒伤采用最强来源，每0.25秒结算，浮点边界用容差；不得指数叠毒。护符免伤不自动解除墨缚/定字。
- 正常非工人、非复制、可留标作战兵死亡后生成8秒纸标。献祭/复制/召唤兵不留可复用纸标。祭司每次只消费一个；没有空名额时不消费。
- 复制体保留当前生命和原单位能力，10秒消失；不可被献祭/转换/再复制。召唤纸卫8秒消失。寿命与纸偶死亡动画分开。
- 反弹次数最多1；归属改为反弹者、攻击原来源，原来源已死则不能继续反弹。直接法术无反弹事件。
- 命令包含每方递增序号；重复/过期序号不能第二次花钱、献祭或消费纸标。

## 节奏与可玩性判据

目标局长约2–7分钟，教学开局更短；星章时间是加分条件，不是普通关卡强制失败倒计时。投资更多工人会推迟第一波，研究会推迟出兵，保护/恢复会推迟输出法术；玩家必须在前线交换与后方现金流之间取舍。

价格、伤害与AI取舍已通过模拟对局迭代，仍可继续平衡。任何数值更改必须重新跑规则/通关/界面检查，并记录为本作变更，不能更新原作事实研究。
