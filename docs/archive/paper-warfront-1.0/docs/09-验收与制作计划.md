## 必须保持的回归情境

费用：重复序号/非法目标/资源不足不重复扣费；招募退款；研究前置/短时完成；队列预占人口；工人死亡丢货；设施死亡停止回法。技能：实际治疗量、控制打断、定字仍可攻击、最强毒伤、落印延迟半径、三段火、炮车建筑倍率、反弹一次、召唤寿命和纸标消费、复制链禁止、转换保留原能力、同时拆城平局。

界面：主菜单到战前/对战/结果/下一关闭环；科技图时间继续、暂停时间冻结；设置返回不留下遮罩；Space不能误招兵；指针按下/释放同一目标；拖动不施法；任务失败可重开；挑战灯目标不能由纸哨充数；存档恢复不降低进度。

## 视觉与资源验收

浅纸/暗墨/透明底检查裁切；实际尺寸看头像与武器、巨人与工人比例、左右翻转与关节。三军密集交锋看特效寿命、伤害数字、生命条、背景对比、选取位置与视觉偏移一致。科技最后一排、锁定文字、长关名、许可滚动、最低窗口均需捕获检查。

## 性能与后续顺序

上限每方60作战兵+6工人；650纸粒，16音源池，命中/脚步声音限流，纹理缓存，字体子集。预算不是实测帧率。性能记录必须有设备、GPU、分辨率、人数、粒子数量、FPS/帧时与运行条件。

收到Android设备后先安装/启动/横屏/切后台/返回/触控施法/拖动，再跑完整对局与音乐混音；随后测15分钟稳定性、热量、不同宽高比与最低布局。发现问题优先修输入/卡死/结算，再调对比/帧率，最后迭代对局平衡。未测项目不得改成通过。
