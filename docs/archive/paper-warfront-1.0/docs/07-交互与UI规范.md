# 交互与UI规范 · 1.0

实际UI：[main.gd](../../../../game/scripts/main.gd) 与 [action_card.gd](../../../../game/scripts/action_card.gd)。Godot原生Control，CanvasLayer固定HUD；无DOM或浏览器运行依赖。

## 完整页面与流程

主菜单 → 继续战役/十五关列表/遭遇战配置/六挑战/三军兵书/设置/许可/退出。战役和挑战进入战前说明，再展开战场。对局 → 科技/建造/兵书/暂停 → 胜负统计 → 重开、下一关或返回。失败不解锁下一关；最后一关胜利可回兵书。

战役列表显示当前开放关、锁定理由和最高星章。遭遇配置含双方阵营、三地图、三难度、三AI策略、完整科技开关。兵书展示原型切图、招募价或法力价、生命/攻击/射程/速度、能力与反制。设置保存音乐/动作音量、减少震动、开局跟随交锋，桌面可全屏。许可页滚动展示Godot及第三方与字体许可。

## 设计尺寸与战场保护

逻辑1600×900，桌面默认1280×720，最小960×540；Android横屏。固定等比缩放保留宽高比，超宽/异形屏会留边；留边不产生可施法的区域。

上HUD178px：资源/队列一行；5招募卡与5法术卡96×113，桌面科技/建造/暂停/兵书50px高，移动布局改为四个99×113入口。下导航90px：看家、追踪交锋、战线图、前后、取消。持久面板约29.8%视高；替代旧20%概念预算，以十个完整入口与触控可达性为先。中间632px保留交锋，普通单位约190px高。文字18–24px，标题30–48px，主菜单更大。

移动主菜单使用2列×4行、每项690×122逻辑px的按钮，隐藏统帅纸偶以避免透过按钮间隙遮挡。遭遇配置选择器104px高，战前开战入口92px高；这些是等比缩放前的设计尺寸，实际屏幕触控尺寸仍需真机核验。

字库为Noto Sans SC/Serif SC的600字重子集；OFL许可随包，子集内部名称改为PaperWarfront Text/Title。生成图不承载正式文字。禁用文字深灰，冷却、锁、进度和选中边框由运行状态驱动；不把白字放在亮纸上。

## 输入

| 动作 | Windows | Android/触控 |
| --- | --- | --- |
| 招募 | 点卡 / 1..5 | 点卡 |
| 法术选择 | 点卡 / Q W E R T | 点卡 |
| 确认施法 | 在合法目标/区域按下后释放 | 轻点目标/区域 |
| 取消 | 取消按钮、右键、Esc | 取消按钮、系统返回 |
| 科技 / 建造 | 按钮 / F / B | 按钮 |
| 平移镜头 | 拖动、A D/方向键、滚轮 | 拖动战场或战线图 |
| 看纸城 / 追踪交锋 | 按钮 / Home / Space | 按钮 |
| 暂停 | 按钮 / P / Esc | 按钮 / 系统返回 |
| 队列退款 | 点击待产头像 | 点击待产头像 |

选法术不付款，第二次点同卡取消。单体目标在按下时捕获稳定UID，释放时仍用该UID，期间死亡则反馈失败、不扣费；不会悄悄切到另一兵。按下到释放移动≥14逻辑px作为拖动，不施法。战线图拖动不与施法同时生效。建筑只允许我方两固定位。

重叠目标优先选择当前单体法术的合法对象，再按指针与显示身体的距离选择；如果附近没有合法对象，保留最近对象以反馈拒绝原因，最终仍由模拟校验。范围法术始终使用实际点击的地面坐标，不吸附附近单位。1.0未实施Tab候选轮换或快捷键重绑。任何新增选择机制需保持按下/释放目标身份一致。

## 状态、暂停与焦点

卡片表达锁定、可用、资源不足、冷却、选中；队列表达已付款待产。科技节点表达前置、金价、研究秒数、未开放/研究中/已完成；说明由tooltip或兵书提供。研究时战斗继续，打开科技本身不暂停。

暂停/兵书/设置冻结模拟及粒子寿命；关闭暂停后继续。Esc/系统返回依次取消瞄准、关闭上层、暂停/恢复，结果返回菜单。Android切后台自动暂停。界面点击被Control消费，不穿透到战场；战斗按钮关闭键盘focus以免Space激活招募。

UI成功用纸签短音，非法操作用短低音及具体原因（金币不足/前置未研究/名额不足/目标不合法）。文字原因与资源变化都来自命令结果。暗色遮罩只在菜单使用，科技面板较轻，仍能看见交锋。

## 星章与存档

战役3星：胜利、基地≥50%、建议时间内；最高星章保存。挑战同样保存最高星章，挑战2第三星要求至少3次补纸，挑战6第三星要求真正建过产法纸灯（纸哨不算），其余挑战第三星为时间。星章时间不是硬失败条件。

Windows保存目录 `%APPDATA%\PaperWarfront\profile.json`；Android私有user目录。保存用临时文件再重命名；只保存进度、星章、设置，不保存对局中途快照。损坏/缺失JSON回到默认档；数值范围夹紧。旧工程默认Godot目录内的存档可迁移。
