# 已实施关卡与内容 · 1.0

地图专项复核（2026-10-08）：1.0 的三个场景共用一套机械地图，十五个战役关卡全部以拆基地结算；现有功能/导出验证不代表原作地图对标已完成。后续地图方向以 [地图研究与重设计约束](../../../research/swords-and-soldiers-map/README.md) 为准，其中的新方案尚未实施。

权威配置：[campaign.json](../data/campaign.json)。十五关固定线性顺序，三章各五关；第N关胜利后才开放N+1。重打不减少星章；战役资源、敌方预解锁和出兵宽限均是关卡公开设定，不是隐蔽作弊。

## 遭遇战与可胜性

任意三军组合含同阵营内战，三地图、三难度、三策略可选；可使用基础或完整科技，起始230金对230金。AI的研究与出兵都付款，普通模式不用固定强制结束时间。

十五关已跑合法双方自动指挥对局，用于发现僵局、经济循环和缺兵；这些结果不能冒称玩家十五关均已手动通关。额外合法命令通关验证、实际Windows操作与包检查的具体证据见 [运行报告](15-运行验收与交付报告.md)。
