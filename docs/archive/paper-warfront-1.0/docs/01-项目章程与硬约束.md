# 项目章程与硬约束 · 1.0

地图专项复核（2026-10-08）：1.0 的三个场景共用一套机械地图，十五个战役关卡全部以拆基地结算；现有功能/导出验证不代表原作地图对标已完成。后续地图方向以 [地图研究与重设计约束](../../../research/swords-and-soldiers-map/README.md) 为准，其中的新方案尚未实施。

工作名：《纸上兵戈》 / Paper Warfront。玩家用经济投资、兵种组合、科技时机与手动施法，改变一条横向战线上的自动军团交锋。纸甲折损、补纸、拾纸成兵、复印和盖印重击必须在实际规则中兑现。

三位统帅争夺能把愿望盖成现实的印章：印甲军追求不破的甲，墨骸社想把退役军队折回来，灯符朝要复印朝廷。剧情用短纸签与三张统帅像；玩家不操控英雄，不逐个下行军指令。

## 必须成立的体验约束

| 编号 | 约束 | 验收观察 |
| --- | --- | --- |
| G01 | 单位自主行军、接敌、攻击、再推进 | 招募后无需微操即可攻向敌方 |
| G02 | 主资源只有金币和法力 | 科技/兵力/建筑争夺金币；法术争夺法力 |
| G03 | 三军同采金、异回法 | 印甲金币回法升级；墨骸献祭；灯符可拆灯台 |
| G04 | 局内科技有前置、费用和研究时间 | 出兵与解锁分别支付；重开重置科技 |
| G05 | 玩家瞄准施法 | 选择/预览/确认/取消/失效目标均有明确结果 |
| G06 | 战线长于一屏、侧向阅读 | 看家/看交锋/拖动/战线图导航均可用 |
| G07 | 强力能力可反制、无无限资源循环 | 控制打断巨人；复制不连锁；纸标仅消费一次 |
| G08 | 对局完整闭环 | 普通模式拆基地；守城挑战到时胜；平局、失败、重开成立 |
| G09 | 素材服务战术可读性 | 方/尖/圆剪影；单位可点选；特效不持续遮场 |
| G10 | 对手用相同命令和付款规则 | 不隐藏发钱、不无冷却施法、不免费窥探敌钱包 |

纸纹、折痕、墨卷为表现；不增加纸材库存、湿度、染色领土或印章连击资源。灯台只产法力，无隐性区域增益。

## 工程与美术限制

Godot 4.7.2，GDScript，原生Control。模拟与画面分离；固定60Hz。Canvas2D分层纸偶、关节摇摆和纸边阴影构成纸舞台，无外部3D建模、复杂蒙皮、动作捕捉或刚体战斗依赖。图片仅负责造型与主题符号，文字、生命、费用、冷却、状态和命中都由代码驱动。

素材生成使用用户指定的 `sub2-image-gen` / `gpt-image-2.5` / high / PNG；不得复制网关密钥。所有工具均为Windows原生；禁止Docker、WSL、虚拟机、容器和模拟器。浏览器使用后关闭本次不再需要的标签。

构图、图像和导出成功不能代替游戏证据。规则测试、实际Windows运行、菜单交互、密集战场、Android包结构与签名分别验收；没有Android真机时明确记录未实测，不填造帧率、触控和耗电结论。
