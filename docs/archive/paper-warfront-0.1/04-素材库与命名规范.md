# 素材库与命名规范

本库包含 116 个基础资产定义，并为人物补充头像导出和 17 份程序化关节蓝图。状态按项追踪，覆盖范围完整不等于每项已在游戏里验证。

## 分类与用途

| 分类 | 基础项数 | 交付形式 | 用法 |
| --- | --- | --- | --- |
| 人物与统帅 | 20 | 整身透明 PNG、头像 PNG；17 个单位有 rig JSON | 造型参考、原型占位、招募头像；最终纸偶由几何部件呈现 |
| 法术 | 15 | 独立透明图标 | 三阵营各五个手动法术，按钮状态由代码叠加 |
| 建筑与矿点 | 9 | 透明参考图 | 三基地、三纸哨、产法纸灯台、矿点、运金车 |
| 通用 UI | 16 | 透明主题符号 | 资源、科技、取消、导航、暂停、音量、胜负等 |
| 纸材纹理 | 9 | 不透明方形 PNG | 纸底、阵营纸、侧边、纸木纹、路径、墨粒 |
| 场景道具 | 9 | 透明 PNG | 纸林、岩、芦苇、牌坊、桥、三军旗、装饰灯 |
| 特效母题 | 12 | 透明静态参考/贴片 | 印、纸屑、墨卷、符圈；动作与寿命由代码生成 |
| 背景 | 3 | 宽幅 PNG | 印原、墨沼、灯岭的低对比远景 |
| 声音 | 23 | 44.1 kHz 单声道 PCM WAV 与事件定义 | 20个事件SFX、三个阵营节奏草稿 |

17 个图片生成任务包括以上源图板，以及风格板和灯符交锋补充图。源图的实际返回尺寸不同，裁切始终读取真实尺寸，不能写死请求的 1536×1024。

## ID、命名与版本

ID 采用 `类型.阵营.用途`：`unit.yin.axe`、`spell.mo.sacrifice`、`building.deng.mana`。公共资源可用 `ui.gold`、`background.ink-marsh`。ID 表示游戏含义，不含生成时间或文件尺寸，代码通过 manifest 查路径。

文件名由 ID 的点替换成短横线，例如 `unit-yin-axe.png`。不要改成“最终版2”“新版最好看”。图像大改、轮廓变动、尺寸/锚点变动、用途变动需要升资产版本并留下记录；不改变 ID 的语义。删掉功能时记录替代或弃用 ID。

同一源图共享生成任务。manifest 保存 `source_path`、`source_job`、网格行列、裁切、内容框、导出尺度和校验散列。人物同时保存 `portrait_path`；单位还保存 `rig_path`。可重新导出，不必重新生成。

## 状态定义

| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| design-ready | 功能与生成要求已登记 | ID、用途、尺寸/路径已确定 |
| source-generated | 有已解码的源图 | 文件存在、PNG 可读、任务对应 |
| derived-candidate | 已裁切和导出，等待视觉确认 | 透明处理、边界、尺寸与元数据完成 |
| visual-reviewed | 本轮看过并通过静态检查 | 母题正确、无串格、轮廓与边缘符合规范 |
| runtime-verified | 已通过游戏中的相应情境 | 加载、操作尺度、动画、目标和状态验证 |

本轮最多推进到静态素材检查。纸材表面、静态母题和原型声音即使已导出，也需在真实战场中检查重复、混音与对比。生成板的漂亮程度不会自动提升运行状态。

## 导出规格

| 资源 | 候选规格 | 锚点与限制 |
| --- | --- | --- |
| 整身纸偶 | 512×512 RGBA | 底部基线 y=476，横向中心；世界高度由定义决定 |
| 头像 | 192×192 RGBA | 从角色上部提取头肩；独立检查武器是否误入 |
| 法术/通用 UI | 192×192 RGBA | 保留透明边距，运行按钮至少 44px |
| 建筑参考 | 512×512 RGBA | 底部基线；实际建筑宽高在几何中定义 |
| 道具 | 512×512 RGBA | 底部基线；装饰不可代替命中对象 |
| 特效母题 | 256×256 RGBA | 中心锚点；不把生成的静态图当完整动画 |
| 材料 | 512×512 RGB | 无透明，不默认承诺无缝重复 |
| 背景 | 保留源宽高或受限缩放 | 不产生地形碰撞，避免高对比前景 |
| 声音 | 44.1 kHz、16-bit、mono WAV | 淡入淡出，峰值限制；每类有播放限流 |

角色数据里的世界高度必须参与缩放，避免将所有归一化 PNG 画成同样高。左右翻转围绕足底中心；图标不翻转；文字纹样独立处理。
