# 关卡与内容规划

完整内容目标为三阵营战役、AI 遭遇战、规则明确的挑战与 1v1。先用对战原型验证规则，再把已成立的战术组织为关卡，避免先堆剧情和地图。

## 三类地图素材

| 地图 | 共用逻辑 | 美术资产 | 设计用途 |
| --- | --- | --- | --- |
| 印原练兵场 | 基地、矿点、固定建筑位、可滚动战线 | 淡纸山、纸松、朱印军旗、纸路 | 学资源、招募和恢复 |
| 墨沼旧纸场 | 同样坐标规则；调整长度和资源节奏 | 墨芦苇、旧纸牌坊、灰纸雾 | 学控制、尸体利用和支援位置 |
| 灯台纸岭 | 同样规则；突出设施可被进攻 | 青纸山、装饰灯、灯符军旗 | 学设施安全、反弹、保护与复制 |

墨雾是背景效果，不自动提供战争迷雾；桥是侧视场景构造，不新增多线水战。关卡特殊规则通过配置明确宣布。所有背景低部留给角色，基地由独立几何/资源呈现。

## 教学战役规划

每阵营五关，共十五关作为内容规模上限起点。关卡顺序以对局验证结果调整；每关只新增一到两个决策，不长时间冻结画面读说明。

| 关卡 | 玩家学习 | 配置或事件 | 主要验收 |
| --- | --- | --- | --- |
| 印甲 1：第一道印 | 采金、招募、自动推进、导航 | 基础折斧与工人，简弱敌队 | 能找到基地和交锋，完成一次胜负 |
| 印甲 2：补好这张甲 | 单体恢复、取消与费用 | 给恢复入口与可救前排 | 恢复确实保住单位并改变结果 |
| 印甲 3：先买矛还是先买印 | 科技与即时兵力机会成本 | 允许纸矛科技，早期敌压 | 至少两种开局均有合理路径 |
| 印甲 4：大锤有空隙 | 重击打断巨型前摇 | 逐次加入巨型威胁 | 控制时机可读、错用有后果 |
| 印甲 5：攻到家门口 | 补充距离、经济与攻城 | 完整印甲核心，对方反扑 | 攻守位置改变生产与施法需求 |
| 墨骸 1：纸也是法力 | 献祭与剩余生命 | 合法目标限制清楚 | 不重复回法，不把工人当提款机 |
| 墨骸 2：针墨留在纸上 | 持续伤害与控制组合 | 墨针、墨缚和有限近战 | 延长输出时间能改变交换 |
| 墨骸 3：把他们折回来 | 祭司位置和标记消费 | 拾纸祭司、有限阵亡标记 | 每标记只消费一次，祭司可反制 |
| 墨骸 4：大纸人也会摔 | 巨人支援与对方打断 | 引入纸巨人和控制对手 | 巨人强但存在明确弱点 |
| 墨骸 5：这道印归我 | 归属转换与高消耗机会 | 开放夺印与范围打击 | 选择高价值目标、保留应急法力 |
| 灯符 1：先保住灯 | 建造位、设施回法与安全 | 产法纸灯台、基础兵 | 设施被毁后回法立即下降 |
| 灯符 2：把矛送回去 | 投射物反制与属性区别 | 镜符对投射物和直接伤害 | 反弹一次、能换攻击类型反制 |
| 灯符 3：同一张纸两份用 | 保护与复制来源限制 | 开放护符、复印 | 无复制链、选目标可解释 |
| 灯符 4：从这一折过去 | 有限越线与后排安全 | 折影、定字与脆弱后排 | 突击不任意越全图，落点受限 |
| 灯符 5：印章不肯盖两次 | 完整三阵营组合 | 完整树与不同敌方组合 | 多种开局、反制和反扑都能成立 |

统帅对白用三张叙事头像和短纸签。示例语气：印甲“把裂缝补上，庆功宴再说。”；墨骸“退役只是另一种折法。”；灯符“先印两份，再谈公平。”不在实时交锋中央弹长段剧情。

## 遭遇战和挑战

遭遇战选择玩家阵营、敌阵营、地图和 AI 难度。AI 风格为早压、经济攀升、法术反制三种策略倾向；难度先改变决策频率和识别能力，不能隐藏发金币或跳过费用。当前战线无战争迷雾，敌方隐含金币和待产队列不作为 AI 免费情报。

六个挑战作为机制验收扩展：有限预算守线、精准补纸、打断巨人、祭司争标记、投射物改阵、保护设施反扑。挑战有明确胜利、失败和重开条件。目标例如“规定波次结束时基地存活”，不能只靠分数增长来假称胜负闭环。

## 1v1 工程边界

先完成本机可重放双边命令与 AI 遭遇战。在线阶段再处理共同模拟、输入时序、状态摘要、断线恢复和匹配；网络随机必须可复现。复制、控制、标记消费和资源命令需要稳定 ID，早期保留这些边界。

局部相机和 UI 状态不影响共同模拟；在线暂停需双方协议。本阶段未创建网络服务或可联机游戏，不把素材库完成当作多人功能完成。
