# 素材生成与加工指导

唯一指定图片路线：本地 `sub2-image-gen` 技能脚本，模型 `gpt-image-2.5`，质量 `high`，PNG。直接 HTTP；不调用 Docker、WSL 或浏览器，不在项目中复制网关密钥。

## 工作流程

定义功能与 ID → 读风格参数 → 写完整提示词 → 保存源图 → 检查构图与真实透明通道 → 按任务网格裁切 → 导出候选 → 生成检查图 → 逐类视觉确认 → 接入游戏验证。

入口命令见 [工具说明](../../../tools/paper-warfront/README.md)。生成按一项请求顺序进行，避免已观察到的并发限流。已存在源图默认保留；只有明确修改的任务才用 `--force --job ...` 覆盖。429/502/503 可同模型有限重试，其他错误保留日志并说明；不静默换模型。

## 提示词结构

每个任务完整包含以下七部分，不能只写“纸偶风格”：

1. 资产用途：角色、按钮符号、材质、建筑、远景或母题。
2. 世界语言：厚片纸偶、哑光印刷颜料、木刻轮廓和轻纤维。
3. 视角：严格正交侧视；人物统一朝右。
4. 主体：单位功能、体型、武器、阵营形状和颜色。
5. 构图：完整轮廓、空白安全边、格子数、格子顺序。
6. 表面与光线：平、哑、无戏剧高光、无背景投影。
7. 排除项：文字、logo、串格、透视、圆雕、逼真材质、舞台与复杂特效。

完整母提示词位于 `prepare_library.py` 的 `STYLE`，具体任务保存为 `.txt`。当前技能入口只有文本提示，没有已验证的参考图输入参数。因此统一依靠明确描述、参数和生成后对照；不会声称每次调用都实际传入了已选概念图。

### 单位指令示例

```text
用途：折斧兵的完整侧视造型参考与原型整身切图。
主体：宽方朱红纸甲、方印盾、短粗纸臂、折斧、认真而滑稽的纸面孔。
视角：正交侧视朝右，完整脚、手、盾和武器；脚底同一基线。
风格：薄厚度折纸片、木刻轮廓、轻纸纤维、哑光色块。
构图：一格一个角色，格内至少14%安全边，不与邻格相交。
背景：原生透明优先；无法返回透明时使用纯#FF00FF去底背景。
限制：不画地面、投影、棚拍背景、文字、法术光效或第二个士兵。
```

图标只画母题，不生成圆形按钮底、价格、蓝色费用小水滴、冷却数字和名称。背景只画远景，低部留空，不画地面路径、活跃基地、角色或 HUD。材质满格平铺样本，不画单张纸的摄影边框。

## 网格与透明处理

源板顺序是从左到右、从上到下。工具按源图真实宽高分格，不能假定模型遵守请求尺寸。普通人物 3×2，补充统帅 2×1，建筑/道具/材质 3×3，公共 UI 4×4，法术 5×1，特效母题 4×3。

优先读取 PNG 自身 alpha。查看器若只显示透明区域的 RGB，可能呈现看似带背景的源图；必须再用纸底和棋盘底合成判断，不能据此直接判失败。存在原生透明时只清除极低 alpha 噪点并保留抗锯齿，不能从白色里抠出纸脸。

如果没有透明通道且背景为纯品红，再按背景色去底。品红只能是背景，不能成为纸饰；一旦背景渐变、主体颜色混底或难分边界，该资源进入待修状态，不靠强阈值硬删身体。

逐格检查完整轮廓和邻格侵入。人物优先从整张源图的透明连通轮廓选出对应主体，再记录实际内容框；格子仅定位主体，避免截掉跨格的盾或肩甲。内容框用于归一化；足底型素材放在共同基线，图标/母题置中。不是每种角色都在格内同样大：巨人、工人和召唤兵的世界高度来自定义。人物头像另从头肩区域裁切，保留脸和主要盔饰。

## 输出检查

- 在浅纸、暗墨和棋盘底上看透明边缘；不得出现背景块、黑白圈或相邻格碎片。
- 图标查看 192px 原图、48px 操作尺寸和灰度；母题必须各不相同。
- 对源图和候选图记录尺寸、内容框、散列；检查登记表引用均存在。
- 建筑、人物和特效板的整图只用于参考；不能偷懒把网格边界一起加载到游戏。
- 声音候选检查波形、时长、峰值和末端淡出；混音与听感仍在游戏内验收。

失败修订只改有问题的任务。回到主体、相机、边距或透明背景要求，保留源图与原因，不全库反复重生成。如果准备脚本重新运行，它会保留既有检查与导出状态；更改了用途或版式时必须显式重查相关资产。
