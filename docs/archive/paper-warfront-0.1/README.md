# 《纸上兵戈》制作资料入口

版本：0.1.0；2026-10-08。当前状态：方向展开与素材基线建立。用户正在考虑方向 03，本资料作为该方向的工作基准，后续可以按决策记录调整。

游戏定位：侧向滚动的军团实时策略；单位自行行军和交战，玩家分配金币、购买科技、安排招募并选目标施法。Three.js 呈现有薄厚度的纸偶、纸甲、纸城与纸面山河，文字和操作入口由 DOM 呈现。

## 素材与工具入口

- [素材定义](../../../assets/paper-warfront/library-definition.json)：116 个基础资产的名称、功能与画面指令。
- [素材登记表](../../../assets/paper-warfront/library-manifest.json)：状态、来源、网格位置、加工文件、关节蓝图与检查结果。
- [风格参数](../../../assets/paper-warfront/style-tokens.json)：颜色、厚度、操作尺度、动画与生成路线。
- [正式风格基准与引用边界](../../../assets/paper-warfront/art-direction.json)：已检查素材优先，独立概念图仅作探索参考。
- [原型平衡参数](../../../assets/paper-warfront/balance-prototype.json) 与 [科技前置图](../../../assets/paper-warfront/technology.json)：用于后续模拟的初始数据。
- [素材浏览页](../../../assets/paper-warfront/gallery.html)：按阵营、类型和用途查看实际资源；浏览页由加工工具生成。
- [生成任务与提示词](../../../output/imagegen/paper-warfront/jobs.json)：17 张源图的生产计划。
- [加工工具说明](../../../tools/paper-warfront/README.md)：准备、生成、导出和检查命令。

素材库覆盖完整内容范围；成熟度按资产逐项记录。厚片关节蓝图是可用于编码的几何定义，整身人物图用于造型参考、头像和原型占位，最终分件动画仍需通过代码接入验证。
