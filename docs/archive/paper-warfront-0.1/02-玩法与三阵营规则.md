# 玩法与三阵营规则

以下为本项目 0.1 原型设计。对标依据见 [原作拆解](../../剑与勇士-HD-核心体验拆解.md)；价格和时序不声称与原作一致。

## 共同循环与结算

工人采金 → 花金币扩经济、买科技、招募或建造 → 部队自行行军交战 → 玩家选择法术与合法目标 → 交锋改变前线和经济安全 → 再次分配资源 → 摧毁基地。

工人从基地出发，在本方矿点工作，再回交付点交金。三阵营同费用、容量、作业时间和基础移速。工人可被攻击；其安全是推进的战略价值。装饰运金车不独立产生金币。

金币在交付时才入账；工人阵亡时未交付的携带金币丢失。金币以整数保存，法力采用固定精度；献祭收益向下取整后限制在法力上限，不把显示四舍五入值用于结算。

普通作战单位只能按已解锁入口招募。点击时检查金币与生产可用状态，支付并入队；到生产时刻产生单位。解锁支付和招募支付分开。最初原型采用一个基地队列、最多六个待产订单；取消未出生订单返还招募金币，敌人也遵循同一规则。

招募检查存活数加待产订单的上限；工人与作战单位分别计数。召唤、复制和转换也占作战名额，名额不足时不扣费；祭司等待名额时不消费标记。建筑死亡不退款，允许原位置按规则重建。研究确认付款后不可取消，关闭科技图不停止研究。

普通单位依据自身攻击类型与射程选合法目标。近战在接触范围停下攻击，后排在射程内攻击；目标消失后重新获取或继续推进。视觉层的前后错位不改变逻辑距离。巨型攻击前摇可被符合规则的控制打断；普通受击动画不会自动打断模拟。

## 法力与法术

三阵营有同一基础法力上限与基础缓慢恢复。印甲以金币购买永久回法升级；墨骸以单位剩余生命换法力；灯符通过可被摧毁的纸灯台增回法。灯台只在固定建造位出现，不能拖到前线变成可移动区域增益。

| 阵营 | 法术 | 指向与效果 | 边界 |
| --- | --- | --- | --- |
| 印甲 | 补纸 | 单个己方作战单位恢复生命 | 不恢复基地；不超过生命上限 |
| 印甲 | 雷印 | 单个敌方单位直接伤害 | 无投射物反弹；费用较高 |
| 印甲 | 寒纸风 | 指定范围减速 | 不改变基地的生产或资源 |
| 印甲 | 振甲 | 单个己方作战单位限时强化 | 同来源重复施放刷新时长，不叠乘 |
| 印甲 | 落印 | 指定范围高消耗伤害 | 范围预览与结算一致，有清楚落印准备 |
| 墨骸 | 献纸 | 移除己方合法单位，按剩余生命回法 | 禁止工人、建筑、召唤与复制来源单位 |
| 墨骸 | 墨缚 | 限时限制单个敌方作战单位行动 | 状态到时结束，目标仍可被攻击 |
| 墨骸 | 腐墨 | 指定范围施加持续伤害 | 伤害按固定步长结算，重复刷新不指数叠加 |
| 墨骸 | 夺印 | 转换符合条件的敌方作战单位归属 | 禁止工人、基地、召唤与复制单位；记录来源 |
| 墨骸 | 泼墨 | 指定范围爆发打击 | 不额外增加墨水资源或地形伤害 |
| 灯符 | 护符 | 单个己方作战单位限时保护 | 结束状态可见；不保护工人或建筑 |
| 灯符 | 复印 | 复制符合条件的己方作战单位 | 禁止复制复制品、工人、召唤单位和纸巨人 |
| 灯符 | 火签雨 | 指定范围分段落签 | 提前预告区域，不全屏随机轰击 |
| 灯符 | 定字符 | 单个敌方作战单位禁止移动 | 能否攻击单独由状态规则定义；当前允许攻击 |
| 灯符 | 唤纸卫 | 合法地面点召唤限时护卫 | 不能在敌方基地内部生成；有数量和寿命上限 |

拾纸是祭司的单位能力，不是新增第六个手动法术。阵亡标记只有一次消费权；献祭移除不生成可复用阵亡标记。纸骨兵不能再次被祭司复起。复制品死亡不生成标记。普通兵死亡标记暂存 8 秒，祭司按范围和间隔消费一个。

反弹只处理标为 `reflectable` 的飞行投射物；首次反弹立即改归属和目标，反弹计数最多 1。雷印等直接事件不走飞行投射物逻辑。越线突击只选择前方有限距离内的合法落点，不能穿到敌方基地或瞬移到任意屏幕位置。

费用只在确认合法命令时结算一次。命令带序号，重复确认不能重复扣费、重复献祭或消费同一标记。目标在预览后死亡时，命令失败且不扣费；生效延迟型法术在合法确认后遵从自己的区域/目标追踪规则。

## 科技与建筑

三阵营分别拥有科技前置图。先开放基础近战与工人；远程、支援、重型、攻城与高阶法术按支路研究。研究同样消费金币；是否立刻完成由节点配置，最初原型有明确短研究时间。科技图打开时对局继续，暂停由独立操作控制。这是本项目的交互决定。

完整节点数据见 [technology.json](../../../assets/paper-warfront/technology.json)。纸哨是可选固定防御，未进入首个双阵营切片；源图提前提供造型参考。任何建筑破坏后都停止自身贡献，不把外观破坏当作模拟死亡。

## 原型节奏与胜负

初始建议：战线长 56 个设计单位，普通纸兵高 1.8，正交视高约 8.2；基地在 2 与 54，矿点在 6 与 50。开局每方 160 金、40 法力、两个工人。目标时长 4–7 分钟，只作为测试目标。

建议初始基础价：工人 35 金；印甲作战单位 45/60/95/150 金；墨骸 40/55/95/190 金；灯符 50/65/90/110 金。具体生命、攻击、射程和法术成本由 [原型数据](../../../assets/paper-warfront/balance-prototype.json) 统一保存，并用实际对局调节。

基地生命归零立即判定败方，不再处理新命令；同时归零时按同一模拟步记录平局。重开清理实体、标记、状态、资源与队列，保留设置；AI 必须遵守相同费用、冷却、目标和视野规则。没有原作证据的数值与操作细节登记在决策记录中。
